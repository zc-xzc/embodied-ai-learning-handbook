## 二、开源框架

### 2.1 具身智能专用框架

| 框架名称 | 链接 | 简介 | 安装命令 |
|---------|------|------|---------|
| LeRobot | [GitHub](https://github.com/huggingface/lerobot) | HuggingFace 出品的具身智能框架，支持遥操作、数据采集、策略训练（ACT、Diffusion Policy）和评估的全流程 | `pip install lerobot` |
| MuJoCo | [GitHub](https://github.com/google-deepmind/mujoco) | DeepMind 的物理仿真引擎，速度快、精度高，支持 XML 格式的模型定义 | `pip install mujoco` |
| Isaac Lab | [GitHub](https://github.com/isaac-sim/IsaacLab) | NVIDIA 出品的机器人仿真平台，基于 Isaac Sim，支持 GPU 并行仿真，适合大规模 RL 训练 | 参见官方安装文档 |
| RoboSuite | [GitHub](https://github.com/ARISE-Initiative/robosuite) | MuJoCo 上的多任务机器人仿真框架，支持 Franka、Sawyer 等多种机械臂 | `pip install robosuite` |
| ManiSkill | [GitHub](https://github.com/haosulab/ManiSkill) | 大规模机器人操作 benchmark，含丰富的操作任务和评估协议 | `pip install mani-skill` |
| PyBullet | [GitHub](https://github.com/bulletphysics/bullet3) | 轻量级物理仿真引擎，安装简单，适合快速原型开发 | `pip install pybullet` |
| Genesis | [GitHub](https://github.com/Genesis-Embodied-AI/Genesis) | 新一代具身智能仿真平台，支持多种物理求解器和并行仿真 | `pip install genesis-embodied-ai` |
