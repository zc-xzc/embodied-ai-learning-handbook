## 一、BayesVLA：贝叶斯因式分解VLA策略

> 论文：Seeing to Act, Prompting to Specify: A Bayesian Factorization of VLA Policy
> 机构：浙江大学 / UC Berkeley

### 1.1 核心问题

端到端VLA策略存在**模态不平衡**：语言信号被视觉线索"淹没"。

量化证据：LIBERO数据集中语言条件熵 $H(l|v) = 1.6 \times 10^{-9}$，意味着语言几乎不提供额外信息。

### 1.2 贝叶斯分解

$$\pi(a|v,l) \propto \pi(a|v) \cdot L(l|v,a)$$

将策略分解为：
- **视觉-动作先验** $\pi(a|v)$：不依赖语言的动作分布
- **语言条件似然** $L(l|v,a)$：给定视觉和动作，语言指令的似然

### 1.3 两阶段训练

**阶段一（接触前）**：
- 冻结预训练动作基础模型
- 生成抓取候选集
- 仅学习 $\pi(a|v)$

**阶段二（接触后）**：
- 文本感知特征 + 交叉注意力层
- 实现语言动作对齐
- 仅微调注意力层

### 1.4 效果

- 未见物体零样本泛化成功率：38%
- 解决模态不平衡和捷径学习

## 二、WoVR：可靠世界模型

> 论文：World Models as Reliable Simulators for Post-Training VLA Policies with RL
> 机构：清华 / CASIA / Infinigence

### 2.1 核心问题

世界模型"幻觉"：模型在world model中成功(90%)但在real world失败(50%)。

### 2.2 三大幻觉控制机制

**1. 稳定化动作条件世界模型**
- 双通道action注入：additive modulation + cross-attention
- fixed initial frame机制
- 主动注入noise

**2. 关键帧初始化滚动（KIR）**
- 从任务关键中间状态（特别是失败状态）开始预测
- 降低早期误差累积
- 与GRPO loss哲学一致

**3. 策略对齐协同进化（PACE）**
- 低频收集策略新轨迹
- 精化世界模型
- frozen-world-model低频更新范式

### 2.3 推理速度优势

5步采样即达性能基准（OpenSolar需10步，EVAC/Christmas需20-30步）

### 2.4 效果

高接触操作平均成功率91.7%，较基线提升30%。

## 三、RL-Co：虚实协同强化学习

> 论文：Sim Real Beyond Imitation: RL-Based Sim-Real Co-Training for VLA Models
> 机构：清华 / HIT / 北大 / CMU

### 3.1 核心问题

真实世界数据收集成本高，纯模仿学习泛化差，SFT累积误差与灾难性遗忘。

### 3.2 两阶段框架

**第一阶段：SFT暖启动**
- 50条真机 + 1000条仿真replay
- 按概率采样：α概率仿真，(1-α)概率真机
- 联合训练

**第二阶段：带正则的RL微调**

$$L_{total} = L_{RL} + \beta \cdot L_{SFT\_real}$$

- 仿真中用RO持续优化
- 引入SFT正则项防止灾难性遗忘

### 3.3 仿真-真机对齐设计

| 类别 | 要求 |
|------|------|
| 保证相同 | 初始状态、任务定义、环境布局、相机视角 |
| 允许相似 | 运动学大致一致 |
| 不要求一致 | 纹理、背景、光照 |

### 3.4 数据效率

| 方案 | 真机数据 | 成功率 |
|------|----------|--------|
| 纯真机SFT | 200条 | 基准 |
| 纯仿真SFT | 100条 | 低于基准 |
| RL-Co | 20条 | 超越基准 |

### 3.5 泛化验证

未见物品与未见初始状态（扰动±5cm+30°）下性能下降幅度显著小于baseline。

## 四、smart-video-nav：视频生成导航

> 论文：Beyond View Navigation with Video Generation
> 机构：香港大学

### 4.1 核心创新

首次将视频生成模型引入超越视野导航（Beyond View Navigation, BVN）。

### 4.2 架构

```
视频生成模型 (Wan2.1 1.3B) → latent condition冻结
  → diffusion transformer动作头 → 连续动作输出
```

### 4.3 关键技术

**稀疏视频预测**：interval=3效果最优

**两阶段历史压缩**：
- QFormer：时间维度压缩
- VideoFormer：空间维度压缩

**知识蒸馏**：PCM一致性模型，50步→4步，27×加速

**timestep调度优化**：
- 较大T：关注外观和空间信息
- 较小T：聚焦物体纹理细节
- 导航任务增加大T使用频率

### 4.4 数据采集

- 140小时真实世界视频
- 大疆Action 4运动相机 + 电子增稳
- 平均帧长超过100帧

### 4.5 效果

BVN任务成功率达SOTA，是基线的2.5倍。

## 五、技术脉络汇总

### 三条技术脉络

```
1. 结构化建模（BayesVLA）
   先验/似然解耦 → 突破端到端单策略泛化瓶颈

2. RL后训练（RL-Co + WoVR）
   RL-Co：物理仿真器 + 真实正则
   WoVR：学习式世界模型 + 幻觉控制
   互补：共同把VLA从模仿学习推向强化学习

3. 视频/世界生成模型作具身前瞻接口
   VGM成为"通用未来预测引擎"
   效率（稀疏化/蒸馏）与可靠性（幻觉控制）是两大关键
```

### 技术演进路线

```
模仿学习(SFT) → RL后训练 → 世界模型闭环
     ↓              ↓            ↓
  BayesVLA       RL-Co        WoVR
  (架构解耦)    (虚实协同)    (幻觉控制)
```
