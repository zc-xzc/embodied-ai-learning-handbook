# 操作综述

> 本文件综述机器人操作（Manipulation）的核心问题、表示方法、策略类型、执行方式和评测指标。

---

## 一、机器人操作问题定义

### 1.1 什么是机器人操作

机器人操作（Robot Manipulation）是指机器人通过机械臂和末端执行器（夹爪、吸盘、灵巧手等）与物体进行物理交互，完成抓取、放置、组装、推拉等任务的能力。

操作问题的形式化定义：
```
给定：
- 初始环境状态 s_0（物体位置、机器人位姿等）
- 任务目标 G（如"把红色方块放到碗里"）
- 机器人能力约束（关节限位、力矩限制等）

求：
- 策略 π: O → A（从观测到动作的映射）
- 使得机器人执行策略后，环境状态变化满足目标 G
```

### 1.2 操作任务的分类

```
操作任务分类
├── 按交互方式
│   ├── 非接触操作（拾取放置 Pick-and-Place）
│   ├── 接触操作（推、拉、擦、插入）
│   └── 工具使用（锤钉子、用勺子舀）
│
├── 按物体特性
│   ├── 刚体操作（方块、杯子）
│   ├── 柔性体操作（布料、绳索、食物）
│   └── 颗粒/流体操作（沙子、水）
│
├── 按任务复杂度
│   ├── 单步任务（抓取一个物体）
│   ├── 多步任务（组装多个零件）
│   └── 长序列任务（做一顿饭）
│
└── 按精度要求
    ├── 粗操作（搬运箱子）
    └── 精操作（插入 USB、拧螺丝）
```

### 1.3 操作的难点

1. **接触动力学复杂性**：机器人与物体接触时的力交互高度非线性
2. **高维动作空间**：7-DOF 机械臂 + 灵巧手的动作空间可达 20+ 维
3. **多模态感知**：需要融合视觉、触觉、力觉等多种信息
4. **物体多样性**：不同形状、材质、重量的物体需要不同的策略
5. **遮挡与部分可观测**：操作过程中手会遮挡物体
6. **误差累积**：长序列操作中，小误差会逐步累积

## 二、操作表示方法

### 2.1 关节空间表示

直接在关节角度空间中表示动作：

```python
import numpy as np

class JointSpaceAction:
    """关节空间动作表示"""
    def __init__(self, num_joints=7):
        self.num_joints = num_joints
    
    def create_action(self, joint_positions, gripper=0.0):
        """
        joint_positions: 各关节目标角度 (num_joints,)
        gripper: 夹爪开合度 [0, 1]
        """
        action = np.concatenate([joint_positions, [gripper]])
        return action
    
    def get_action_dim(self):
        return self.num_joints + 1  # 关节 + 夹爪

# 示例：7-DOF 机械臂 + 夹爪
action_repr = JointSpaceAction(num_joints=7)
action = action_repr.create_action(
    joint_positions=np.array([0.0, 0.5, 0.0, -1.2, 0.0, 1.0, 0.0]),
    gripper=1.0  # 闭合夹爪
)
print(f"关节空间动作 (维度={len(action)}): {action}")
```

**优点**：直接控制每个关节，无 IK 计算
**缺点**：不同机器人之间不通用，难以理解"末端在做什么"

### 2.2 笛卡尔空间表示

在末端执行器的位姿空间中表示动作：

```python
class CartesianSpaceAction:
    """笛卡尔空间动作表示"""
    def __init__(self):
        pass
    
    def create_action(self, position, orientation, gripper=0.0):
        """
        position: 末端位置 (x, y, z)
        orientation: 末端姿态（四元数 [w, x, y, z] 或欧拉角）
        gripper: 夹爪开合度 [0, 1]
        """
        action = {
            "position": np.array(position),
            "orientation": np.array(orientation),
            "gripper": gripper
        }
        return action

# 示例
action_repr = CartesianSpaceAction()
action = action_repr.create_action(
    position=[0.3, 0.1, 0.5],
    orientation=[1.0, 0.0, 0.0, 0.0],  # 四元数（无旋转）
    gripper=0.5
)
print(f"笛卡尔空间动作: {action}")
```

**优点**：跨机器人通用，语义清晰
**缺点**：需要 IK 求解，可能遇到奇异点

### 2.3 增量动作表示

最常用的方式：输出相对于当前位置的增量：

```python
class DeltaAction:
    """增量动作表示（最常用）"""
    def __init__(self):
        pass
    
    def create_action(self, delta_pos, delta_rot, gripper_action):
        """
        delta_pos: 位置增量 (dx, dy, dz) 通常在 [-1, 1] 范围
        delta_rot: 旋转增量 (droll, dpitch, dyaw) 通常在 [-1, 1] 范围
        gripper_action: 夹爪动作 (1=闭合, -1=张开, 0=不变)
        """
        action = np.array([
            delta_pos[0], delta_pos[1], delta_pos[2],   # dx, dy, dz
            delta_rot[0], delta_rot[1], delta_rot[2],    # droll, dpitch, dyaw
            gripper_action                                  # gripper
        ])
        return action

# 这是 OpenVLA、RT-1 等模型的标准动作格式
action_repr = DeltaAction()
action = action_repr.create_action(
    delta_pos=[0.1, 0.0, -0.2],  # 向前、不动、向下
    delta_rot=[0.0, 0.0, 0.0],   # 无旋转
    gripper_action=1.0            # 闭合夹爪
)
print(f"增量动作 (7维): {action}")
```

### 2.4 轨迹参数化

将动作表示为参数化的轨迹：

```python
class TrajectoryParametrization:
    """轨迹参数化表示"""
    
    @staticmethod
    def bezier_trajectory(control_points, num_steps=50):
        """贝塞尔曲线轨迹"""
        t = np.linspace(0, 1, num_steps)
        n = len(control_points) - 1
        
        # 伯恩斯坦多项式
        from scipy.special import comb
        trajectory = np.zeros((num_steps, len(control_points[0])))
        for i in range(n + 1):
            coeff = comb(n, i) * (t ** i) * ((1 - t) ** (n - i))
            trajectory += np.outer(coeff, control_points[i])
        
        return trajectory
    
    @staticmethod
    def b_spline_trajectory(knots, degree=3, num_steps=50):
        """B 样条轨迹"""
        from scipy.interpolate import BSpline
        t = np.linspace(0, len(knots) - degree - 1, num_steps)
        spline = BSpline(range(len(knots)), knots, degree)
        return spline(t)

# 示例：3 阶贝塞尔曲线
control_points = np.array([
    [0.0, 0.0, 0.0],  # 起点
    [0.1, 0.2, 0.1],  # 控制点1
    [0.3, 0.2, 0.1],  # 控制点2
    [0.4, 0.0, 0.0],  # 终点
])
traj = TrajectoryParametrization.bezier_trajectory(control_points)
print(f"轨迹形状: {traj.shape}")  # (50, 3)
```

## 三、策略类型

### 3.1 确定性策略

```python
class DeterministicPolicy:
    """确定性策略：相同输入 → 相同输出"""
    def __init__(self, obs_dim=10, action_dim=7):
        import torch.nn as nn
        self.net = nn.Sequential(
            nn.Linear(obs_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, action_dim),
            nn.Tanh()  # 输出限制在 [-1, 1]
        )
    
    def predict(self, obs):
        return self.net(obs)

# 适用场景：BC、监督学习训练的策略
# 问题：无法处理多模态动作分布（同一观测可能有多种合理动作）
```

### 3.2 随机策略

```python
class StochasticPolicy:
    """随机策略：输出高斯分布"""
    def __init__(self, obs_dim=10, action_dim=7):
        import torch.nn as nn
        self.net = nn.Sequential(
            nn.Linear(obs_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 2 * action_dim)  # 输出 mean 和 log_std
        )
    
    def predict(self, obs):
        import torch
        out = self.net(obs)
        mean, log_std = out.chunk(2, dim=-1)
        std = torch.exp(log_std)
        # 从分布中采样
        action = mean + std * torch.randn_like(mean)
        return action

# 适用场景：SAC、PPO 等 RL 算法
# 问题：高斯分布仍然是单模态的
```

### 3.3 生成式策略

```python
class GenerativePolicy:

    def __init__(self, obs_dim=10, action_dim=7, horizon=16):
        self.obs_dim = obs_dim

        self.horizon = horizon
    
    def predict(self, obs, num_samples=1):
        """
        生成式策略可以从同一观测生成多种不同的合理动作
        """
        # Diffusion: 从噪声开始去噪
        # VAE: 从隐空间采样后解码
        # Flow Matching: 从噪声流到动作
        pass

# 适用场景：Diffusion Policy, ACT (VAE), π0 (Flow Matching)
# 优势：能处理多模态分布（如向左抓或向右抓都合理）
```

### 3.4 策略类型对比

| 特性 | 确定性 | 随机（高斯） | 生成式 |
|------|--------|-------------|--------|
| 多模态分布 | 不支持 | 不支持 | 支持 |
| 训练难度 | 简单 | 中等 | 较难 |
| 推理速度 | 最快 | 快 | 较慢 |
| 代表方法 | BC (MSE) | SAC, PPO | Diffusion Policy, ACT |
| 适用场景 | 简单任务 | RL 控制任务 | 复杂操作任务 |

## 四、执行方式

### 4.1 开环执行

```python
def open_loop_execution(policy, env, num_steps=50):
    """开环执行：一次性预测所有动作，依次执行，不使用新观测"""
    # 1. 获取初始观测
    obs = env.reset()
    
    # 2. 一次性预测全部动作
    action_sequence = policy.predict_all(obs, horizon=num_steps)
    
    # 3. 依次执行，不更新观测
    for step in range(num_steps):
        action = action_sequence[step]
        obs, reward, done, info = env.step(action)
        # 注意：这里不使用新的 obs 来重新预测
        
        if done:
            break
    
    return info

# 优点：计算量小（只推理一次）
# 缺点：无法应对环境变化和误差累积
```

### 4.2 闭环执行

```python
def closed_loop_execution(policy, env, num_steps=50):
    """闭环执行：每步根据当前观测重新预测动作"""
    obs = env.reset()
    
    for step in range(num_steps):
        # 每步都根据当前观测预测
        action = policy.predict(obs)
        obs, reward, done, info = env.step(action)
        
        if done:
            break
    
    return info

# 优点：能应对环境变化，鲁棒性好
# 缺点：计算量大（每步都推理）
```

### 4.3 Receding Horizon 执行（Action Chunking 专用）

```python
def receding_horizon_execution(policy, env, chunk_size=10, execute_steps=5, max_steps=200):
    """
    Receding Horizon 执行：预测 chunk_size 步，只执行前 execute_steps 步，然后重新预测
    这是 ACT 和 Diffusion Policy 的标准执行方式
    """
    obs = env.reset()
    step = 0
    
    while step < max_steps:
        # 预测一个 action chunk
        action_chunk = policy.predict_chunk(obs, horizon=chunk_size)
        
        # 只执行前 execute_steps 步
        for i in range(min(execute_steps, chunk_size)):
            action = action_chunk[i]
            obs, reward, done, info = env.step(action)
            step += 1
            
            if done or step >= max_steps:
                return info
    
    return info

# 优点：兼顾开环的效率和闭环的鲁棒性
# 参数选择：execute_steps 通常为 chunk_size 的一半
```

### 4.4 执行方式对比

| 方式 | 推理频率 | 鲁棒性 | 延迟 | 适用场景 |
|------|---------|--------|------|---------|
| 开环 | 1次 | 低 | 最低 | 简单、确定性任务 |
| 闭环 | 每步 | 高 | 最高 | 动态、复杂任务 |
| Receding Horizon | 每 k 步 | 中高 | 中 | Action Chunk 策略 |

## 五、评测指标

### 5.1 核心评测指标

```python
import numpy as np
from collections import defaultdict

class ManipulationEvaluator:
    """操作任务评测器"""
    
    def __init__(self):
        self.results = defaultdict(list)
    
    def evaluate_episode(self, episode_info):
        """评估单个 episode"""
        # 1. 成功率
        success = episode_info.get("success", False)
        self.results["success"].append(success)
        
        # 2. 完成时间
        completion_time = episode_info.get("steps", float('inf'))
        self.results["completion_time"].append(completion_time)
        
        # 3. 轨迹质量
        trajectory = episode_info.get("trajectory", [])
        if len(trajectory) > 1:
            # 轨迹长度（实际走过的路径长度）
            path_length = sum(
                np.linalg.norm(trajectory[i+1] - trajectory[i])
                for i in range(len(trajectory) - 1)
            )
            self.results["path_length"].append(path_length)
            
            # 轨迹平滑度（加加速度 jerk 的均值）
            if len(trajectory) > 2:
                velocities = np.diff(trajectory, axis=0)
                accelerations = np.diff(velocities, axis=0)
                jerks = np.diff(accelerations, axis=0)
                avg_jerk = np.mean(np.linalg.norm(jerks, axis=1))
                self.results["avg_jerk"].append(avg_jerk)
        
        # 4. 能效
        energy = episode_info.get("energy", 0)
        self.results["energy"].append(energy)
        
        # 5. 碰撞次数
        collisions = episode_info.get("collisions", 0)
        self.results["collisions"].append(collisions)
    
    def compute_metrics(self):
        """计算汇总指标"""
        metrics = {
            "success_rate": np.mean(self.results["success"]),
            "avg_completion_time": np.mean(self.results["completion_time"]),
            "avg_path_length": np.mean(self.results["path_length"]) if self.results["path_length"] else 0,
            "avg_jerk": np.mean(self.results["avg_jerk"]) if self.results["avg_jerk"] else 0,
            "avg_energy": np.mean(self.results["energy"]),
            "avg_collisions": np.mean(self.results["collisions"]),
        }
        return metrics
    
    def print_report(self):
        """打印评测报告"""
        metrics = self.compute_metrics()
        print("=" * 50)
        print("操作任务评测报告")
        print("=" * 50)
        for key, value in metrics.items():
            print(f"  {key}: {value:.4f}" if isinstance(value, float) else f"  {key}: {value}")
```

## 七、总结与展望

机器人操作是具身智能中最核心、也最具挑战性的问题之一。当前的技术趋势：

1. **从专用到通用**：从针对单一任务的策略，向多任务通用策略发展（VLA 模型）
2. **从确定性到生成式**：从 MSE 回归到 Diffusion/Flow Matching，建模多模态分布
3. **从开环到闭环**：从一次性执行到实时感知反馈
4. **从小数据到大数据**：Open X-Embodiment 等大规模数据集推动泛化
5. **从仿真到真机**：Sim2Real 技术不断进步，缩小域间隙

未来关键方向：
- 长序列自主操作
- 触觉引导的精细操作
- 语言引导的零样本泛化
- 自主数据采集与持续学习
