## 一、世界模型概念

### 1.1 什么是世界模型

世界模型（World Model）是智能体内部对环境动态的内部表征，它能够：

1. **理解世界**：编码环境的物理规律、因果关系
2. **预测未来**：给定当前状态和动作，预测未来的状态变化
3. **支持决策**：在"想象的"环境中进行规划和学习，无需与真实环境交互

形式化定义：
```
世界模型 M: (s_t, a_t) → s_{t+1}
    给定当前状态 s_t 和动作 a_t，预测下一时刻状态 s_{t+1}

更一般的形式：
    M: (s_t, a_t, a_{t+1}, ..., a_{t+H}) → (s_{t+1}, s_{t+2}, ..., s_{t+H})
    预测未来 H 步的状态序列
```

### 1.2 理解世界 vs 预测未来

世界模型有两个层次的能力：

```
层次1：理解世界 (Understanding)
  - 物理常识：物体受重力下落、碰撞会弹开
  - 空间关系：物体之间的相对位置
  - 因果关系：推一个物体会让它移动
  - 恒常性：物体被遮挡后仍然存在

层次2：预测未来 (Prediction)
  - 短期预测：下一帧图像/状态
  - 长期预测：未来多步的轨迹
  - 反事实预测：如果采取不同动作会怎样
  - 条件生成：给定条件下的未来场景
```

## 二、发展脉络

### 2.1 World Models (2018)

Ha & Schmidhuber 提出的开创性工作：

```
架构：
  1. Vision (V)：VAE 将图像编码为紧凑的隐变量
  2. Memory (M)：LSTM/RNN 预测未来隐状态
  3. Controller (C)：简单的线性策略在隐空间中决策

训练流程：
  1. 用随机策略收集数据
  2. 训练 VAE 编码图像
  3. 训练 RNN 预测隐状态转移
  4. 在"梦境"（dream）中训练控制器
```

```python
import torch
import torch.nn as nn

class WorldModel_Ha2018(nn.Module):
    """简化版 World Models (Ha & Schmidhuber, 2018)"""
    def __init__(self, latent_dim=32, hidden_dim=256, action_dim=3):
        super().__init__()
        
        # V: 视觉编码器 (VAE)
        self.encoder = nn.Sequential(
            nn.Linear(64 * 64 * 3, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, latent_dim * 2)  # mean + log_var
        )
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 64 * 64 * 3)
        )
        
        # M: 记忆/转移模型 (RNN)
        self.rnn = nn.LSTM(latent_dim + action_dim, hidden_dim, batch_first=True)
        
        # C: 控制器 (线性策略)
        self.controller = nn.Linear(hidden_dim + latent_dim, action_dim)
    
    def encode(self, x):
        """编码图像为隐变量"""
        h = self.encoder(x)
        mean, log_var = h.chunk(2, dim=-1)
        z = mean + torch.randn_like(mean) * torch.exp(0.5 * log_var)
        return z, mean, log_var
    
    def predict_next(self, z, action, hidden):
        """预测下一步隐状态"""
        rnn_input = torch.cat([z, action], dim=-1).unsqueeze(1)
        out, hidden = self.rnn(rnn_input, hidden)
        return out.squeeze(1), hidden
    
    def act(self, z, rnn_out):
        """控制器决策"""
        combined = torch.cat([z, rnn_out], dim=-1)
        return torch.tanh(self.controller(combined))
```

### 2.2 Dreamer (2020)

Dreamer（Dream to Control）引入了基于世界模型的 Actor-Critic 训练：

```
关键创新：
  1. 使用 RSSM（Recurrent State-Space Model）作为世界模型
  2. 在世界模型中通过梯度反向传播训练 Actor 和 Critic
  3. 不需要真实环境交互来训练策略（仅需要训练世界模型时交互）
```

```python
class RSSM(nn.Module):
    """RSSM: Recurrent State-Space Model (Dreamer 核心)"""
    def __init__(self, latent_dim=30, action_dim=5, hidden_dim=200):
        super().__init__()
        # 确定性状态转移
        self.cell = nn.GRUCell(hidden_dim, hidden_dim)
        # 先验：从确定性状态预测隐状态
        self.prior = nn.Linear(hidden_dim, 2 * latent_dim)
        # 后验：从确定性状态和观测编码预测隐状态
        self.posterior = nn.Linear(hidden_dim + latent_dim, 2 * latent_dim)
    
    def forward(self, prev_state, prev_action, obs_embed):
        """一步前向传播"""
        # 确定性状态转移
        h = self.cell(torch.cat([prev_state['h'], prev_action], dim=-1))
        
        # 先验分布
        prior_mean, prior_std = self.prior(h).chunk(2, dim=-1)
        prior_std = torch.softplus(prior_std) + 0.1
        
        # 后验分布
        post_mean, post_std = self.posterior(torch.cat([h, obs_embed], dim=-1)).chunk(2, dim=-1)
        post_std = torch.softplus(post_std) + 0.1
        
        # 从后验采样
        z = post_mean + post_std * torch.randn_like(post_mean)
        
        return {
            'h': h, 'z': z,
            'prior_mean': prior_mean, 'prior_std': prior_std,
            'post_mean': post_mean, 'post_std': post_std,
        }
```

### 2.3 DreamerV2 (2021)

```
关键改进：
  1. 离散隐状态（用分类分布代替高斯）
  2. 在 Atari 55 个游戏上达到人类水平
  3. 更稳定的长程预测
```

### 2.4 DreamerV3 (2023)

DreamerV3 是目前最通用的世界模型 RL 方法：

```
关键改进：
  1. 无需超参数调优即可在多种领域工作（Atari、DMC、Crafter、Minecraft）
  2. 使用 symmetric logarithmic (symlog) 预测处理不同尺度的信号
  3. 免归一化设计
  4. 首个在 Minecraft 中收集钻石的算法
```

```python
class DreamerV3Config:

    # Actor-Critic

### 2.5 发展脉络总结

```
World Models (2018)
  └─→ Dreamer (2020): RSSM + Actor-Critic in imagination
        └─→ DreamerV2 (2021): 离散隐状态
              └─→ DreamerV3 (2023): 通用免调参
                    └─→ 当前方向：视频世界模型、3D 世界模型、VLA 中的世界模型

## 三、在机器人中的应用

### 3.1 模型预测控制（Model-Predictive Control with World Models）

```python
class WorldModelMPC:
    """使用世界模型进行 MPC"""
    def __init__(self, world_model, horizon=10, num_samples=1000):
        self.model = world_model
        self.horizon = horizon
        self.num_samples = num_samples
    
    def plan(self, current_state, goal):
        """规划最优动作序列"""
        best_action = None
        best_score = -float('inf')
        
        # 采样多条动作轨迹
        for _ in range(self.num_samples):
            # 随机采样动作序列
            actions = torch.randn(self.horizon, self.action_dim)
            
            # 用世界模型想象轨迹
            total_reward = 0
            state = current_state
            for t in range(self.horizon):
                state = self.model.predict(state, actions[t])
                total_reward += self.reward(state, goal)
            
            # 只取第一个动作（receding horizon）
            if total_reward > best_score:
                best_score = total_reward
                best_action = actions[0]
        
        return best_action
    
    def reward(self, state, goal):
        """简单奖励：状态到目标的负距离"""
        return -torch.norm(state - goal)
```

### 3.2 数据增强

```python
class WorldModelDataAugmentation:
    """使用世界模型生成合成数据"""
    def __init__(self, world_model):
        self.model = world_model
    
    def generate_synthetic_trajectories(self, initial_states, num_steps=50):
        """从初始状态生成合成轨迹"""
        synthetic_data = []
        
        for init_state in initial_states:
            trajectory = [init_state]
            state = init_state
            
            for _ in range(num_steps):
                # 随机或策略选择动作
                action = self.sample_action(state)
                # 用世界模型预测下一步
                next_state = self.model.predict(state, action)
                trajectory.append((state, action, next_state))
                state = next_state
            
            synthetic_data.append(trajectory)
        
        return synthetic_data
    
    def sample_action(self, state):
        """采样动作（可用随机或学习策略）"""
        return torch.randn(self.action_dim) * 0.3
```

### 3.3 Sim2Real 中的应用

```
世界模型在 Sim2Real 中的作用：
1. 在仿真中训练世界模型
2. 在真实环境中用少量数据微调世界模型
3. 在微调后的世界模型中训练策略
4. 策略部署到真实环境

优势：
- 减少真实环境中的试错（安全性）
- 世界模型可以补偿仿真和真实的差异
- 可以在模型中测试危险动作
```

### 3.4 视频预测世界模型

```python
"""
视频预测作为世界模型
将"预测下一帧图像"作为世界模型的目标
"""
class VideoPredictionWorldModel(nn.Module):
    """基于视频预测的世界模型"""
    def __init__(self, frame_channels=3, latent_dim=128):
        super().__init__()
        # 编码器：将当前帧 + 动作编码为隐状态
        self.encoder = nn.Sequential(
            nn.Conv2d(frame_channels, 32, 4, stride=2),
            nn.ReLU(),
            nn.Conv2d(32, 64, 4, stride=2),
            nn.ReLU(),
            nn.Conv2d(64, 128, 4, stride=2),
            nn.ReLU(),
        )
        # 动作条件
        self.action_embed = nn.Linear(7, 64)
        # 转移模型
        self.transition = nn.LSTMCell(128 * 8 * 8 + 64, 512)
        # 解码器：从隐状态解码为下一帧
        self.decoder = nn.Sequential(
            nn.ConvTranspose2d(512, 128, 4, stride=2),
            nn.ReLU(),
            nn.ConvTranspose2d(128, 64, 4, stride=2),
            nn.ReLU(),
            nn.ConvTranspose2d(64, 32, 4, stride=2),
            nn.ReLU(),
            nn.ConvTranspose2d(32, frame_channels, 3, stride=1),
            nn.Sigmoid()
        )
    
    def predict_next_frame(self, frame, action, hidden):
        """预测下一帧"""
        # 编码当前帧
        enc = self.encoder(frame).flatten(1)
        # 动作嵌入
        act = self.action_embed(action)
        # 转移
        combined = torch.cat([enc, act], dim=-1)
        hidden = self.transition(combined, hidden)
        # 解码
        next_frame = self.decoder(hidden[0].view(-1, 512, 1, 1))
        return next_frame, hidden
```

## 四、与 VLA 的关系

### 4.1 世界模型增强 VLA

```
当前趋势：将世界模型与 VLA 结合

方式1：世界模型作为数据增强器
  - 用世界模型生成合成轨迹
  - 扩充 VLA 的训练数据

方式2：世界模型作为规划器
  - VLA 提供候选动作
  - 世界模型评估和选择最优动作

方式3：世界模型作为 VLA 的内部模块
  - VLA 内部嵌入世界模型
  - 在预测动作前先"想象"未来

方式4：世界模型辅助 RL 微调
  - 用世界模型离线训练
  - 减少 VLA 在线 RL 的试错
```

### 4.2 代表性工作

```
1. Genie (Google DeepMind, 2024)
   - 从视频学习可控的世界模型
   - 可以生成可交互的虚拟环境

2. Sora (OpenAI, 2024)
   - 视频生成模型具有世界模型特性
   - 能理解物理规律（虽然不完美）

3. UniSim (2023)
   - 通用世界模拟器
   - 用于机器人策略训练

4. GenRM / VLM 作为世界模型
   - 用视觉语言模型作为奖励模型
   - 评估动作的好坏
```

## 五、未来方向

### 5.1 当前挑战

1. **长期预测准确性**：预测步数增加，误差累积严重
2. **高维状态预测**：预测高分辨率图像比隐状态更难
3. **多模态未来**：未来可能有多种合理发展，难以建模
4. **物理精确性**：需要精确建模接触动力学等复杂物理
5. **计算效率**：世界模型的前向计算需要快速

### 5.2 前沿方向

```
方向1：3D 世界模型
  - 在 3D 空间中预测（而非 2D 图像）
  - 更好的空间理解
  - 代表：3D 世界模型、NeRF-based 模型

方向2：大规模预训练世界模型
  - 从海量视频数据学习通用世界知识
  - 迁移到机器人任务
  - 代表：视频基础模型

方向3：层次化世界模型
  - 高层：语义级预测（"把杯子放桌上"）
  - 低层：物理级预测（具体轨迹）
  - 结合 LLM 的规划能力

方向4：交互式世界模型
  - 可以"进入"世界模型中交互
  - 类似游戏引擎，但学习得到
  - 代表：Genie

方向5：世界模型 + VLA
  - VLA 中内嵌世界模型
  - 实现"思考后再行动"
  - 类似 System 2 思考
```
