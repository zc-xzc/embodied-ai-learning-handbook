## 一、人形机器人运动控制概述

### 1.1 运动控制的核心问题

人形机器人运动控制（Humanoid Locomotion Control）是指控制双足（或四足）机器人在各种地形上稳定行走、跑跳、上下楼梯等运动的能力。

核心挑战：
- **高自由度**：人形机器人通常有 20-40+ 个关节
- **欠驱动系统**：双脚不固定在地面上，是浮基系统
- **动态平衡**：需要持续保持重心投影在支撑多边形内
- **接触切换**：行走过程中脚不断接触和离开地面
- **多目标约束**：稳定性、能效、自然性、鲁棒性

### 1.2 控制目标

```
运动控制的多层目标：

1. 稳定性（最高优先级）
   - ZMP（零力矩点）在支撑多边形内
   - 不摔倒
   
2. 跟踪性
   - 跟踪参考运动（步态、速度、方向）
   - 关节级跟踪误差小
   
3. 鲁棒性
   - 抗外力干扰能力
   - 适应不同地形（平地、斜坡、楼梯、不平地面）
   
4. 能效
   - 低能耗
   - 接近人类步态的效率
   
5. 自然性
   - 运动外观接近人类
   - 平滑、不僵硬
```

## 二、基于模型的控制

### 2.1 MPC（模型预测控制）

MPC 是人形机器人最成功的基于模型的控制方法之一：

```
MPC 核心思想：
  在每个控制周期，利用机器人的简化动力学模型，
  在线优化未来 N 步的控制序列，使代价函数最小化，
  只执行第一步控制，下一周期重新优化（receding horizon）。
```

```python
import numpy as np
from scipy.optimize import minimize

class SimpleMPC:
    """简化的倒立摆模型 MPC（人形机器人简化模型）"""
    def __init__(self, dt=0.01, horizon=10):
        self.dt = dt
        self.horizon = horizon
        # 状态: [com_x, com_x_dot, zmp_x]
        # 简化为线性倒立摆模型 (LIPM)
        self.g = 9.81
        self.z_c = 0.8  # 质心高度（常数）
    
    def dynamics(self, state, action):
        """线性倒立摆动力学"""
        com_x, com_x_dot, zmp_x = state
        # com_x_dot_dot = g / z_c * (com_x - zmp_x)
        com_x_ddot = self.g / self.z_c * (com_x - zmp_x)
        
        next_com_x = com_x + com_x_dot * self.dt
        next_com_x_dot = com_x_dot + com_x_ddot * self.dt
        next_zmp_x = action  # 控制输入是 ZMP 位置
        
        return np.array([next_com_x, next_com_x_dot, next_zmp_x])
    
    def cost_function(self, actions, current_state, reference):
        """MPC 代价函数"""
        state = current_state.copy()
        cost = 0
        
        for t in range(self.horizon):
            # 跟踪参考轨迹的代价
            cost += 10.0 * (state[0] - reference[t]) ** 2
            # 控制量变化平滑性
            if t > 0:
                cost += 1.0 * (actions[t] - actions[t-1]) ** 2
            # ZMP 约束惩罚
            if abs(actions[t]) > 0.15:  # 假设脚长 0.3m
                cost += 100.0 * (abs(actions[t]) - 0.15) ** 2
            
            state = self.dynamics(state, actions[t])
        
        return cost
    
    def solve(self, current_state, reference):
        """求解 MPC 优化问题"""
        # 初始猜测
        x0 = np.zeros(self.horizon)
        
        # 约束条件
        bounds = [(-0.15, 0.15)] * self.horizon  # ZMP 在脚掌范围内
        
        result = minimize(
            self.cost_function, x0,
            args=(current_state, reference),
            method='SLSQP',
            bounds=bounds
        )
        
        return result.x[0]  # 只返回第一步动作

# 使用示例
mpc = SimpleMPC(dt=0.01, horizon=10)
state = np.array([0.0, 0.0, 0.0])  # 初始状态
reference = np.zeros(10)  # 参考轨迹（原地保持）

for step in range(100):
    action = mpc.solve(state, reference)
    state = mpc.dynamics(state, action)
    if step % 20 == 0:
        print(f"Step {step}: com_x={state[0]:.4f}, zmp_x={state[2]:.4f}")
```

### 2.2 LQR（线性二次型调节器）

```python
class LQRController:
    """LQR 控制器"""
    def __init__(self, Q, R, A, B):
        """
        Q: 状态代价矩阵
        R: 控制代价矩阵
        A, B: 线性系统矩阵 x_{t+1} = A x_t + B u_t
        """
        from scipy.linalg import solve_discrete_are
        self.Q = Q
        self.R = R
        self.A = A
        self.B = B
        
        # 求解 Riccati 方程
        P = solve_discrete_are(A, B, Q, R)
        # LQR 增益
        self.K = np.linalg.inv(R + B.T @ P @ B) @ B.T @ P @ A
    
    def control(self, state, target=0):
        """计算控制输入"""
        return -self.K @ (state - target)

# 示例：一维倒立摆 LQR
dt = 0.01
g = 9.81
l = 0.8  # 摆长

# 线性化模型 [theta, theta_dot]
A = np.array([[1, dt],
              [g/l * dt, 1]])
B = np.array([[0], [dt]])

Q = np.diag([10.0, 1.0])  # 角度误差比角速度更重要
R = np.array([[0.1]])      # 控制代价

lqr = LQRController(Q, R, A, B)
state = np.array([0.1, 0.0])  # 初始倾斜 0.1 rad

for step in range(100):
    u = lqr.control(state)
    state = A @ state + B.flatten() * u
    if step % 20 == 0:
        print(f"Step {step}: theta={np.degrees(state[0]):.2f}°, u={u[0]:.4f}")
```

## 三、基于学习的控制

### 3.1 RL 控制步态

```python
"""
用强化学习训练人形机器人步态
"""
import torch
import torch.nn as nn

class LocomotionPolicy(nn.Module):
    """人形机器人运动控制策略"""
    def __init__(self, obs_dim=70, action_dim=12):
        super().__init__()
        # 观测: 本体感知（关节角、速度、IMU、历史）+ 指令（目标速度、方向）
        self.actor = nn.Sequential(
            nn.Linear(obs_dim, 512),
            nn.ELU(),
            nn.Linear(512, 256),
            nn.ELU(),
            nn.Linear(256, 128),
            nn.ELU(),
            nn.Linear(128, action_dim)
        )
        # 动作标准差（可学习）
        self.log_std = nn.Parameter(torch.zeros(action_dim))
    
    def forward(self, obs):
        mean = self.actor(obs)
        std = torch.exp(self.log_std)
        return mean, std

# 奖励函数设计
class LocomotionReward:
    """步态控制奖励函数"""
    def __init__(self):
        self.weights = {
            "linear_velocity": 1.0,      # 跟踪目标线速度
            "angular_velocity": 0.5,      # 跟踪目标角速度
            "linear_velocity_z": -2.0,    # 惩罚垂直方向速度（不跳跃）
            "angular_velocity_xy": -0.05, # 惩罚 roll/pitch 角速度
            "orientation": -1.0,          # 保持身体水平
            "energy": -0.0001,            # 能耗惩罚
            "joint_accel": -2.5e-7,       # 关节加速度惩罚（平滑）
            "action_rate": -0.01,         # 动作变化率惩罚
            "collision": -10.0,           # 碰撞惩罚
            "termination": -10.0,         # 摔倒惩罚
            "stand_still": 1.0,           # 静止时稳定
        }
    
    def compute(self, obs, action, info):
        reward = 0.0
        
        # 线速度跟踪
        target_vx = obs["command"][0]
        actual_vx = obs["base_lin_vel"][0]
        reward += self.weights["linear_velocity"] * torch.exp(-2.0 * (target_vx - actual_vx)**2)
        
        # 保持水平
        upright = obs["base_orientation"][2]  # z 方向
        reward += self.weights["orientation"] * upright
        
        # 能耗
        torque = obs["joint_torques"]
        reward += self.weights["energy"] * torch.sum(torque**2)
        
        # 摔倒检测
        if info.get("fallen", False):
            reward += self.weights["termination"]
        
        return reward
```

### 3.2 模仿学习控制步态

```python
"""
从人类运动捕捉数据学习步态
"""
class MotionImitationPolicy:
    """运动模仿策略"""
    def __init__(self, motion_data):
        """
        motion_data: 人体运动捕捉数据（关节角度序列）
        """
        self.reference_motion = motion_data  # (T, num_joints)
    
    def tracking_reward(self, robot_state, frame_idx):
        """跟踪参考运动的奖励"""
        ref = self.reference_motion[frame_idx]
        
        # 关节角度跟踪
        joint_pos_error = torch.sum((robot_state["joint_pos"] - ref)**2)
        
        # 关节速度跟踪（如果有）
        if "joint_vel" in ref:
            joint_vel_error = torch.sum((robot_state["joint_vel"] - ref["joint_vel"])**2)
        else:
            joint_vel_error = 0
        
        reward = torch.exp(-2.0 * joint_pos_error) + 0.5 * torch.exp(-0.1 * joint_vel_error)
        return reward
```

## 四、运动跟踪策略：Teacher-Student 框架

### 4.1 Teacher-Student 框架详解

```
Teacher-Student 框架在人形机器人运动控制中的应用：

Teacher（训练时）:
  - 输入：本体感知 + 特权信息（地形高度图、精确摩擦系数等）
  - 在仿真中用 RL 训练
  - 利用特权信息做出更好的决策

Student（部署时）:
  - 输入：仅本体感知 + 历史信息（可从传感器获取）
  - 通过蒸馏学习 Teacher 的策略
  - 推断特权信息（隐式估计地形和物理参数）

优势：
  - Teacher 训练更容易（有特权信息辅助）
  - Student 部署更容易（不需要特权传感器）
  - Student 通过历史信息"记住"地形特征
```

```python
import torch
import torch.nn as nn

class TeacherPolicy(nn.Module):
    """Teacher: 使用特权信息"""
    def __init__(self, proprio_dim=70, priv_dim=30, action_dim=12):
        super().__init__()
        input_dim = proprio_dim + priv_dim
        self.net = nn.Sequential(
            nn.Linear(input_dim, 512),
            nn.ELU(),
            nn.Linear(512, 256),
            nn.ELU(),
            nn.Linear(256, action_dim)
        )
    
    def forward(self, proprio, priv_info):
        x = torch.cat([proprio, priv_info], dim=-1)
        return self.net(x)

class StudentPolicy(nn.Module):
    """Student: 仅使用可观测信息 + 历史编码"""
    def __init__(self, proprio_dim=70, hidden_dim=256, action_dim=12, history_len=10):
        super().__init__()
        # 用 LSTM 编码历史信息（隐式估计地形等特权信息）
        self.history_encoder = nn.LSTM(proprio_dim, hidden_dim, batch_first=True)
        # 策略网络
        self.actor = nn.Sequential(
            nn.Linear(proprio_dim + hidden_dim, 512),
            nn.ELU(),
            nn.Linear(512, 256),
            nn.ELU(),
            nn.Linear(256, action_dim)
        )
        self.log_std = nn.Parameter(torch.zeros(action_dim))
    
    def forward(self, proprio_history):
        # proprio_history: (batch, seq_len, proprio_dim)
        _, (hidden, _) = self.history_encoder(proprio_history)
        hidden = hidden.squeeze(0)  # (batch, hidden_dim)
        current_proprio = proprio_history[:, -1, :]  # 最新观测
        
        x = torch.cat([current_proprio, hidden], dim=-1)
        mean = self.actor(x)
        std = torch.exp(self.log_std)
        return mean, std

def teacher_student_distillation(teacher, student, dataloader, epochs=100):
    """蒸馏训练"""
    optimizer = torch.optim.Adam(student.parameters(), lr=1e-3)
    criterion = nn.MSELoss()
    
    for epoch in range(epochs):
        for proprio_history, priv_info in dataloader:
            # Teacher 预测（有特权信息）
            current_proprio = proprio_history[:, -1, :]
            with torch.no_grad():
                teacher_action = teacher(current_proprio, priv_info)
            
            # Student 预测（无特权信息）
            mean, std = student(proprio_history)
            
            # 蒸馏损失
            loss = criterion(mean, teacher_action)
            
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
        
        if (epoch + 1) % 10 == 0:
            print(f"Epoch {epoch+1}/{epochs}, Distill Loss: {loss.item():.6f}")
```

### 5.2 Sim2Real 流程

```
人形机器人运动控制 Sim2Real 标准流程：

1. 仿真训练阶段
   a. 在仿真中定义机器人模型（URDF/USD）
   b. 实施域随机化
   c. 用 RL（通常是 PPO）训练 Teacher 策略
   d. 蒸馏为 Student 策略

2. 验证阶段
   a. 在高保真仿真中测试
   b. 逐步减少随机化，测试稳定性
   c. 加入延迟和噪声模拟真机

3. 真机部署
   a. 导出策略为 ONNX/TorchScript
   b. 在真机上用 C++ 或 Python 部署
   c. 安全监测器监控状态
   d. 急停机制

4. 迭代改进
   a. 收集真机数据
   b. 系统辨识（调整仿真参数）
   c. 重新训练
```
