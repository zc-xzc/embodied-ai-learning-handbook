## 一、具身智能定义与发展历程

### 1.1 什么是具身智能

具身智能（Embodied AI / Embodied Intelligence）是指智能体通过物理身体与环境进行交互，在"感知-决策-执行"的闭环中学习和完成任务的智能范式。

与传统 AI 的核心区别：
- **传统 AI**：在虚拟空间处理数据（如文本、图像），输出预测或生成结果
- **具身 AI**：在物理（或仿真）空间中行动，输出动作并改变环境状态，同时接收新的感知

具身智能的核心闭环：
```
感知 (Perception) → 决策 (Decision) → 执行 (Action) → 环境变化 → 新的感知 → ...
```

### 1.2 发展历程

| 时期 | 里程碑 | 意义 |
|------|--------|------|
| 1940s-1950s | 维纳《控制论》 | 提出"感知-决策-执行"闭环思想 |
| 1960s | Shakey 机器人（SRI） | 首个能推理和行动的移动机器人 |
| 1980s | 罗德尼·布鲁克斯 "无表征智能" | 行为主义机器人学，反对纯符号推理 |
| 1990s | 强化学习理论成熟（Sutton & Barto） | MDP 框架确立 |
| 2013 | DQN 玩 Atari 游戏 | 深度学习与 RL 结合 |
| 2015-2019 | OpenAI Five、AlphaGo | 深度 RL 的成功 |
| 2017 | Transformer 提出 | 为 VLA 奠定基础 |
| 2018 | Domain Randomization（OpenAI Hand） | Sim2Real 重大突破 |
| 2020 | Dreamer / 世界模型 | 基于模型的 RL |
| 2022 | RT-1（Google） | 首个大规模 Transformer 机器人策略 |
| 2023 | RT-2 / Diffusion Policy / ACT | VLA 和扩散策略兴起 |
| 2024 | OpenVLA / π0 / GR00T | 开源 VLA 模型和通用策略 |
| 2025+ | 人形机器人爆发 | Unitree G1、Tesla Optimus 等量产 |

| 术语 | 英文 | 简要解释 |

### 2.2 学习方法

| 术语 | 英文 | 简要解释 |
|------|------|---------|
| 模仿学习 | Imitation Learning (IL) | 从专家演示中学习策略 |

| DAgger | Dataset Aggregation | 通过迭代采集数据解决 BC 分布偏移问题 |
| 生成对抗模仿学习 | Generative Adversarial Imitation Learning (GAIL) | 用 GAN 框架从演示中学习，无需显式奖励函数 |
| 强化学习 | Reinforcement Learning (RL) | 通过试错和奖励信号学习最优策略 |
| 在线强化学习 | Online RL | 在与环境的实时交互中学习 |
| 离线强化学习 | Offline RL | 从固定数据集中学习，不与环境交互 |
| 离线到在线 | Offline-to-Online RL | 先离线学习再在线微调 |
| 课程学习 | Curriculum Learning | 从简单任务逐步过渡到复杂任务 |
| 自主学习 | Autonomous Learning | 机器人在无人工干预下自主探索和学习 |

## 三、感知-决策-控制-评测全景框架

### 3.1 全景框架文字描述

具身智能系统可以划分为四个核心模块，形成完整的"感知→决策→控制→评测"闭环：

```
┌─────────────────────────────────────────────────────────────────┐
│                    具身智能系统全景架构                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌──────────────┐    ┌──────────────┐    ┌──────────────┐     │
│  │   感知模块    │───→│   决策模块    │───→│   控制模块    │     │
│  │ Perception   │    │  Decision    │    │  Control     │     │
│  └──────┬───────┘    └──────────────┘    └──────┬───────┘     │
│         │                                       │              │
│         │         ┌──────────────┐              │              │
│         └─────────│   评测模块    │←─────────────┘              │
│                   │ Evaluation   │                             │
│                   └──────────────┘                             │
│                          ↑                                     │
│                    ┌─────┴─────┐                               │
│                    │  环境反馈  │                               │
│                    └───────────┘                               │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 感知模块（Perception）

**输入**：原始传感器数据（RGB 图像、深度图、点云、关节编码器、IMU、触觉传感器等）

**核心组件**：
- **视觉编码器**：CLIP、SigLIP、DINOv2 等提取视觉特征
- **语言理解**：LLM 或文本编码器处理语言指令
- **本体感知**：关节角度、速度、力矩等机器人自身状态
- **多模态融合**：将视觉、语言、本体感知信息融合为统一表示

**输出**：环境状态估计、任务理解、物体位姿等

### 3.3 决策模块（Decision）

**输入**：感知模块输出的状态表示 + 任务指令

**核心方法**：
- **VLA 模型**：端到端从感知到动作（RT-2、OpenVLA、π0）
- **Diffusion Policy**：扩散模型生成动作序列
- **RL 策略**：基于学习的策略网络
- **规划器**：符号化或层次化的任务规划

**输出**：目标动作或动作序列（关节角度、末端轨迹、夹爪指令等）

### 3.4 控制模块（Control）

**输入**：决策模块输出的目标动作

**核心方法**：
- **位置/速度控制**：直接发送关节目标值
- **力矩控制**：控制关节力矩，实现精细力控
- **阻抗控制**：控制机器人与环境交互的柔顺性
- **MPC**：在线优化有限步控制序列
- **轨迹跟踪**：PD/PID 控制器跟踪参考轨迹

**输出**：电机控制指令

### 3.5 评测模块（Evaluation）

**核心指标**：
- **成功率**（Success Rate）：任务完成的比例
- **完成时间**（Completion Time）：完成任务所需时间
- **轨迹质量**（Trajectory Quality）：轨迹的平滑度、效率
- **泛化性**（Generalization）：在未见场景中的表现
- **鲁棒性**（Robustness）：面对干扰和噪声的稳定性

**评测方式**：
- 仿真评测（大规模、可重复）
- 真机评测（真实但成本高）
- 人工评测（主观但直观）

## 四、关键概念深入理解

### 4.1 动作空间

动作空间定义了机器人可以执行的所有动作的集合：

```
动作空间类型
├── 离散动作空间
│   ├── 关节级别：每个关节离散为有限档位
│   └── Token 级别：将连续动作离散化为 token（RT-1、OpenVLA）
│
├── 连续动作空间
│   ├── 关节空间：直接输出关节角度/速度/力矩
│   ├── 笛卡尔空间：输出末端执行器位姿
│   └── 混合空间：关节+夹爪（连续+离散）
│
└── 序列动作空间
    └── Action Chunk：一次输出多步动作（ACT、Diffusion Policy）
```

### 4.2 观测空间

```
观测空间组成
├── 视觉观测
│   ├── RGB 图像（单目/多目）
│   ├── 深度图
│   └── 点云
│
├── 本体感知
│   ├── 关节角度
│   ├── 关节速度
│   ├── 关节力矩
│   └── 末端位姿
│
├── 语言指令
│   └── 自然语言任务描述
│
└── 触觉/力觉
    ├── 力矩传感器
    └── 触觉传感器（GelSight 等）
```

### 4.3 策略类型

```python
"""
三种主要策略类型对比
"""

# 1. 确定性策略：给定观测，输出固定动作
class DeterministicPolicy:
    def __init__(self):
        self.network = MLP(obs_dim, action_dim)
    
    def predict(self, obs):
        return self.network(obs)  # 每次相同输入得到相同输出

# 2. 随机策略：输出动作分布
class StochasticPolicy:
    def __init__(self):
        self.network = MLP(obs_dim, 2 * action_dim)  # 输出均值和方差
    
    def predict(self, obs):
        mean, log_std = self.network(obs).chunk(2, dim=-1)
        std = torch.exp(log_std)
        return torch.normal(mean, std)  # 从分布中采样
```
