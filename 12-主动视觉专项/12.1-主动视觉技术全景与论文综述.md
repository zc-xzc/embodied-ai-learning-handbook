## 一、主动视觉核心概念

### 1.1 什么是主动视觉

主动视觉是指智能体**主动改变视角或传感器配置**以获取更好感知信息的范式。区别于被动观察，主动视觉强调"感知-行动闭环"：

```
当前视角 → 不确定性评估 → 视点规划(NBV) → 移动到新视角 → 更新感知
```

### 1.2 两大技术路线

| 路线 | 含义 | 代表工作 |
|------|------|----------|
| 具身for 3D | 让机器人主动采集数据做3D重建 | Auto3R, Recon VLA |
| 3D for 具身 | 用3D感知增强机器人操作能力 | Active VLA, 3D-VLA |

### 1.3 "具身for 3D" vs "3D for 具身"

**具身for 3D**：机器人怎么寻找角度，拍更好的画面
- 核心：主动重建，NBV视角规划
- 目标：让机器人把3D这件事干好

**3D for 具身**：3D怎么辅助机器人
- 核心：坐标系转换，精准定位
- 目标：告诉机器人在哪里，怎么抓取

## 二、NBV（Next-Best-View）算法

### 2.1 NBV算法演进

```
基于信息增益的贪心搜索
  ↓
基于不确定性的体素方法
  ↓
学习型NBV（ reinforcement learning）
  ↓
大模型引导的NBV（VLM-based）
```

### 2.2 不确定性量化

两类不确定性：
- **偶然不确定性**（Aleatoric）：数据本身的噪声
- **认知不确定性**（Epistemic）：模型对数据的不确定

3DGS输出不确定性图 → 规划NBV → "哪里不准看哪里"

### 2.3 重建质量自检闭环

```
3D重建 → 质量评估 → 不确定性图 → NBV规划 → 补扫 → 更新重建
```

## 三、三篇核心主动视觉论文

### 3.1 Auto3R：双支路不确定性量化

- **核心**：主动3D重建的双支路框架
- **创新**：同时量化几何和语义不确定性
- **应用**：机器人自主探索未知场景

### 3.2 Recon VLA：扩散变压器隐式空间引导

- **核心**：用扩散模型的隐式空间引导视角规划
- **创新**：将VLA与主动重建结合
- **优势**：生成式先验提升稀疏视角下重建质量

### 3.3 Active VLA：3D Zoom-in高精度建模

- **核心**：VLA模型主动调整相机焦距和视角
- **创新**：分层精度建模（粗扫+精扫）
- **应用**：高精度操作任务

## 五、CanViT：首个主动视觉基础模型

### 5.1 核心定位

CanViT提出首个主动视觉基础模型（Active Vision Foundation Model, AVFM）。

### 5.2 关键创新

- 统一架构处理主动视觉任务
- 预训练+微调范式
- 跨场景泛化能力

## 六、事件相机在主动视觉中的应用

### 6.1 事件相机优势

| 特性 | 传统相机 | 事件相机 |
|------|----------|----------|
| 触发方式 | 全局帧 | 像素级异步 |
| 动态范围 | ~60dB | >120dB |
| 延迟 | 毫秒级 | 微秒级 |
| 功耗 | 高 | 极低 |
| 运动模糊 | 有 | 无 |

### 6.2 应用场景

- 高速运动追踪
- HDR场景感知
- 低功耗机器人视觉
- 眼动分析

## 七、主动视觉四大未解问题

1. **严重遮挡实时NBV**：遮挡场景下的实时视角规划仍具挑战
2. **跨体形通用策略**：不同机器人形态的主动视觉策略迁移
3. **事件相机闭环集成**：事件相机与主动视觉的深度融合
4. **评估标准化**：缺乏统一的主动视觉评估基准

## 八、主动视觉闭环：DA3 → VGGT → 3DGS → DreamZero → NEOVERSE

```
DA3深度感知 → VGGT通用建模 → 3DGS补扫 → DreamZero仿真 → NEOVERSE 4D预测
```

### 8.1 DA3：深度-射线表征

$$P = O + d \cdot D$$

天生支持跨视角对齐，单相机精准避障。

### 8.2 VGGT：1.2B参数通用Transformer

通用3D重建模型，单前向传播完成多视角重建。

### 8.3 DreamZero：世界动作模型

- 7-DoF动作编码为"动作图像"
- 44k小时视频习得物理常识
- 零样本跨具身策略迁移

### 8.4 NEOVERSE：4D世界模型

- 4D高斯基元建模动态物体
- "点-形-质"分层生成
- 无位姿前向重建
