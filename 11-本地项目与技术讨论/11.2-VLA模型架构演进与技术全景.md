## 一、VLA模型核心架构

### 1.1 端到端VLA基本结构

VLA（Vision-Language-Action）将感知、推理、控制整合进统一神经网络：

```
视觉编码器 (DINOv2/CLIP)  ──┐
                             ├──→ 语言解码器 (LLaMA-2) ──→ 动作解码器
语言指令 ──────────────────┘
```

消除传统模块化系统（Perception → Planning → Control）的信息传递损失。

### 1.2 核心模型谱系

| 模型 | 参数量 | 核心特点 | 数据需求 |
|------|--------|----------|----------|
| ACT | 80M | 端到端动作专家，快速验证 | 50条demo |
| Diffusion Policy | - | 扩散建模多峰动作分布 | Zarr格式 |
| SmolVLA | 450M | 轻量VLA，单A100 4h训练 | 中等 |
| OpenVLA-OFT | 7B | 生产级，8×A100 | 大规模 |
| GR00T N1.7 | - | 前沿基础模型 | 大规模 |
| InternVLA-A1 | 3B | 理解+想象+执行一体化 | 63万条仿真轨迹 |
| BayesVLA | - | 贝叶斯分解解耦 | LIBERO基准 |
| AutoVLA | - | 动作Token化+快慢思考 | - |

## 二、BayesVLA：贝叶斯因式分解

### 2.1 核心思想

将端到端VLA策略解耦为"视觉-动作先验"与"语言条件似然"：

$$\pi(a|v,l) \propto \pi(a|v) \cdot L(l|v,a)$$

### 2.2 两阶段训练

**阶段一（接触前）**：冻结预训练动作基础模型，生成抓取候选集
- 仅学习视觉-动作先验 π(a|v)
- 不引入语言信号

**阶段二（接触后）**：文本感知特征 + 交叉注意力层实现语言动作对齐
- 仅微调注意力层
- 解决语言信号被视觉线索"淹没"的模态不平衡问题

### 2.3 模态不平衡量化

LIBERO数据集中语言条件熵极低：$H(l|v) = 1.6 \times 10^{-9}$

这意味着语言信号几乎不提供额外信息，端到端模型会走"捷径"忽略语言。

### 2.4 效果

- 未见物体零样本泛化成功率：38%
- 解决语言信号被视觉"淹没"问题

## 三、AutoVLA：动作Token化与快慢思考

### 3.1 动作Token化

将连续物理轨迹 (Δx, Δy, Δθ) 通过K-Disk聚类离散化：

```
连续轨迹 → K-Disk聚类 → 2048个Action Token → Next-token预测
```

将控制问题转化为语言模型的Next-token预测问题。

### 3.2 快慢思考双系统

| 模式 | 触发条件 | 过程 |
|------|----------|------|
| 快思考 | 简单场景 | 直接输出动作 |
| 慢思考 | 复杂场景 | Chain-of-Thought场景分析 → 输出动作 |

### 3.3 GRPO强化微调

混合奖励函数：

$$r = r_{Driving} - \lambda_r \times r_{CoT}$$

惩罚冗余推理步骤，提升规划成功率。

## 四、InternVLA-A1：理解-想象-执行一体化

### 4.1 三模块统一架构

```
Understanding (Qwen3-VL)  ──→  场景理解
        │
Generation (未来图像预测) ──→  任务推演
        │
Action (控制指令输出)    ──→  鲁棒执行
```

### 4.2 核心优势

可将海量"无动作标签"人类视频数据与真机、仿真数据进行高效异构混合训练。

### 4.3 消融实验

去掉Generation Expert模块后平均成功率从77.0%暴跌至57.6%，证明"想象"能力的必要性。

### 4.4 InternData-A1数据集

- 63万条轨迹，7433.9小时，401.4M帧
- 覆盖70种任务
- 纯合成数据，单条成本仅2分钱
- Zero-shot Sim2Real：10个真实任务成功率50%~90%

## 五、smart-video-nav：视频生成+动作头解耦

### 5.1 架构

先训练视频生成模型 → 其latent condition作为条件冻结 → 供给下游diffusion transformer动作头 → 输出连续动作

### 5.2 关键技术

- **稀疏视频预测**：interval=3效果最优
- **两阶段历史压缩**：QFormer时间压缩 + VideoFormer空间压缩
- **知识蒸馏**：PCM一致性模型，50步→4步，速度提升近十倍
- **自主采集**：140小时真实世界视频，大疆Action 4
