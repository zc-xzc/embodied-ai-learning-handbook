## 一、核心方向选择讨论

### 1.1 3D vs 机器人（0410会议）

**黄老师提出两个方向**：

| 方向 | 含义 | 与硬件关系 |
|------|------|-----------|
| 主动重建 | 让机器人把3D做好 | 中等 |
| 3D辅助机器人 | 采集数据帮机器人干活 | 强 |

**关键判断**：
- "机器人不太需要3D，但3D需要机器人"
- "3D纯算法做下来会发现没啥意思"
- "要做硬件相关，就做素材（数据采集），就做纯机器人"

### 1.2 最终方向确定

**VLA + 3D视觉核心方向**：
- 用3D感知增强VLA框架中的视觉理解能力
- 机器人抓取场景中3D视觉提升遮挡识别精度
- 全流程工程能力：机器人控制 + 3D视觉算法 + 大模型部署

### 1.3 核心要求（0424/核心要求全景拆解）

```
VLA解决"懂不懂" → 物理控制解决"稳不稳" → 协同感知解决"全不全"
```

三层闭环体系。

## 二、VLA技术讨论精华

### 2.1 VLA仿真物理问题（0723会议）

**PPT求解器穿模 vs IPC精度**：
- PPT（Position-Based Dynamics）速度快但可能穿模
- IPC（Incremental Potential Contact）精度高但慢
- 仿真物理精度影响Sim2Real效果

### 2.2 Action Chunking与门控加速

- Action Chunking：一次预测多步动作，减少推理频率
- 门控加速：简单动作用大chunk，复杂动作用小chunk
- 卡顿问题：chunk边界处可能出现动作不连续

### 2.3 世界模型路径

- Test-time training：不建议做（0723结论）
- 学习式世界模型（WoVR）：替代物理引擎
- 前训练/后训练分离：解决Sim2Real Gap

### 2.4 产业共识

**回归"真人真机数据"**：
- 仿真数据有上限
- 真机数据是最终护城河
- Infra和数据工程比算法更重要

## 三、机器人控制讨论

### 3.1 底盘控制架构（0723会议）

```
SDK + NUC 分布式架构
  → 放弃ROS（延迟问题）
  → 位置/速度信号控制
```

### 3.2 VR遥操作全身控制（0603会议）

**多进程架构解决50Hz瓶颈**：
- 视觉进程：10Hz
- 控制进程：50Hz
- 通信进程：异步

### 3.3 Sim-to-Real深度矛盾（0603会议）

**核心发现**：仿真越好真机反而越差

原因分析：
- 域随机化(DR)过大→概率性异常
- 仿真过于逼真→过拟合仿真分布
- 纹理/光照差异无法完全消除

解决方案：
- 前训练/后训练分离
- 仿真-真机对齐设计

### 3.4 无本体训练路线

清华UniDex + egocentric数据做后训练的差异化策略。

## 四、数据采集工程讨论

### 4.1 采集难点（0416会议）

- 多模态同步：视觉/动作/语言时间戳对齐
- 语言标注质量：自然语言描述准确性
- FPS与数据大小：高帧率vs存储成本

### 4.2 遥操作设备选型

| 设备 | 优势 | 问题 |
|------|------|------|
| Pico VR | 沉浸感 | 通讯接口不稳定 |
| 动捕手套 | 精细手指 | 相对姿态保真度 |
| MR设备 | 虚实对齐 | 生态不成熟 |

### 4.3 数据协议定义

```
视觉帧 + 关节角度 + 语言指令 + 时间戳
  → LeRobot v3格式存储
  → MCAP多模态记录
```

## 五、主动视觉讨论

### 5.1 延迟测量（0723会议14/15）

- 视频逐帧对比法
- 30fps下每帧约33ms
- 动作速度影响延迟感知
- 延迟更依赖环境而非动作类型

### 5.2 主动视觉硬件

- 事件相机：微秒级延迟，低功耗
- 主动视角调整：VLA主动控制相机

### 5.3 表征学习

- 3D表征与VLA融合
- DA3深度-射线表征
- 3DGS不确定性图引导NBV
