## 一、核心工程主张

本文档是VLA闭环落地最核心的工程实施指南。主张先跑通"遥操作采集 → 数据标准化 → 质检 → 训练 → 部署 → 回放修正"全链条，再追求单点优化。

### 1.1 统一主干技术栈

| 组件 | 选型 | 理由 |
|------|------|------|
| 框架 | LeRobot | 覆盖录制、标准化、训练、评测全流程 |
| 数据格式 | LeRobot v3 (Parquet+MP4+metadata) | 社区标准，导出兼容RLDS和robomimic HDF5 |
| 训练硬件 | 单A100 (SmolVLA 4h) / 8×A100 (OpenVLA-OFT) | 分层配置 |

### 1.2 模型分层路线

```
ACT (80M参数/50条demo)          ← 快速验证
  ↓
Diffusion Policy                ← 多峰动作分布
  ↓
SmolVLA (450M/单A100 4h)       ← 轻量VLA
  ↓
OpenVLA-OFT (7B/8×A100)        ← 生产级VLA
  ↓
GR00T N1.7                      ← 前沿基础模型
```

## 二、数据采集六步工序

### 2.1 采集流程

1. **任务定义**：选择简单抓取任务（如杯子抓取放置）
2. **硬件校准**：相机标定 + 手眼标定 + 关节零位校准
3. **遥操作录制**：VR设备/动捕手套/主从控制
4. **时间戳同步**：NTP/PTP协议，确保视觉与动作信号对齐
5. **数据存储**：LeRobot v3格式，视频+动作+语言标注
6. **质量审核**：三层质检（自动/半自动/人工）

### 2.2 数据标准"一主两导出"

```
LeRobot v3 (主格式)
  ├── Parquet (结构化动作数据)
  ├── MP4 (视频帧)
  └── metadata.json (任务元信息)
      │
      ├── 导出RLDS (TFDS兼容)
      └── 导出robomimic HDF5 (仿真兼容)
```

### 2.3 三层质检体系

| 层级 | 方法 | 检查内容 |
|------|------|----------|
| L1自动 | 脚本检测 | 帧率一致性、动作范围、时间戳连续性 |
| L2半自动 | 可视化工具 | 轨迹回放、关节角曲线、异常片段标记 |
| L3人工 | 专家审核 | 动作流畅性、任务完成度、语言标注准确性 |

## 三、训练流水线

### 3.1 ACT快速验证

- 参数量：80M
- 数据需求：50条demo
- 训练时间：单GPU约1小时
- 目标：验证数据采集质量和基本闭环

### 3.2 Diffusion Policy

- 核心优势：建模多峰动作分布
- 数据格式：Zarr
- 关键参数：50步DDPM采样 / 4步DDIM加速

### 3.3 SmolVLA轻量VLA

- 参数量：450M
- 训练：单A100约4小时
- 适合场景：快速迭代验证VLA架构

### 3.4 OpenVLA-OFT生产级

- 参数量：7B
- 训练：8×A100
- 特点：支持语言指令条件化

## 四、部署与回放修正

### 4.1 部署流程

1. 模型导出为ONNX格式
2. 边缘设备推理（Jetson ORIN / NUC）
3. 实时控制频率：50Hz（控制） / 10Hz（推理）

### 4.2 回放修正闭环

```
部署执行 → 记录执行轨迹 → 与示教轨迹对比
  → 标记偏差片段 → 补充采集修正数据 → 重新训练
```

## 五、关键工程决策

### 5.1 采集系统优先级

项目启动阶段，**数据采集系统跑通优先级高于科研**。明确人员分工：
- 数据采集线：负责硬件调试、遥操作录制
- 训练线：负责模型训练和评测
- Infra线：负责存储、算力、部署基础设施

### 5.2 任务选择

首次跑通选择**简单抓取任务**：
- 大机械臂 + 简单物体（杯子/方块）
- 采集七八十条数据
- 验证存储与训练环路
- 微调部署

### 5.3 技术卡点

- Pico VR通讯接口稳定性
- 数据协议定义（动作/视觉/语言同步）
- 运控系统优化（关节角映射、速度规划）
