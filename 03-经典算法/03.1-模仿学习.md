## 一、Behavior Cloning (BC) 原理与实现

### 1.1 BC 核心思想

行为克隆（Behavior Cloning）是最简单的模仿学习方法，将策略学习转化为监督学习问题：

```
给定专家演示数据 D = {(o_1, a_1), (o_2, a_2), ..., (o_N, a_N)}
  其中 o_i 是观测，a_i 是专家动作

BC 目标：学习策略 π_θ 使得 π_θ(o) ≈ a

损失函数：L(θ) = (1/N) Σ ||π_θ(o_i) - a_i||²  (MSE)
```

### 1.2 BC 完整实现

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import Dataset, DataLoader
import numpy as np

class BCDataset(Dataset):
    """BC 数据集"""
    def __init__(self, observations, actions):
        self.observations = torch.FloatTensor(observations)
        self.actions = torch.FloatTensor(actions)
    
    def __len__(self):
        return len(self.observations)
    
    def __getitem__(self, idx):
        return self.observations[idx], self.actions[idx]

class BCPolicy(nn.Module):
    """BC 策略网络"""
    def __init__(self, obs_dim, action_dim, hidden_dim=256):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(obs_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, action_dim),
            nn.Tanh()  # 动作范围 [-1, 1]
        )
    
    def forward(self, obs):
        return self.net(obs)

class BCTrainer:
    """BC 训练器"""
    def __init__(self, policy, lr=1e-3, device='cuda'):
        self.policy = policy.to(device)
        self.optimizer = optim.Adam(policy.parameters(), lr=lr)
        self.criterion = nn.MSELoss()
        self.device = device
    
    def train(self, dataloader, epochs=100):
        self.policy.train()
        for epoch in range(epochs):
            total_loss = 0
            for obs_batch, action_batch in dataloader:
                obs_batch = obs_batch.to(self.device)
                action_batch = action_batch.to(self.device)
                
                pred_actions = self.policy(obs_batch)
                loss = self.criterion(pred_actions, action_batch)
                
                self.optimizer.zero_grad()
                loss.backward()
                self.optimizer.step()
                
                total_loss += loss.item()
            
            if (epoch + 1) % 10 == 0:
                avg_loss = total_loss / len(dataloader)
                print(f"Epoch {epoch+1}/{epochs}, Loss: {avg_loss:.6f}")
    
    def predict(self, obs):
        self.policy.eval()
        with torch.no_grad():
            obs_tensor = torch.FloatTensor(obs).unsqueeze(0).to(self.device)
            action = self.policy(obs_tensor)
        return action.cpu().numpy().flatten()

# 模拟训练
np.random.seed(42)
obs_data = np.random.randn(1000, 10).astype(np.float32)
# 模拟专家策略：动作 = 线性变换 + 噪声
action_data = (0.5 * obs_data[:, :4] + 0.1 * np.random.randn(1000, 4)).astype(np.float32)

dataset = BCDataset(obs_data, action_data)
dataloader = DataLoader(dataset, batch_size=64, shuffle=True)

policy = BCPolicy(obs_dim=10, action_dim=4)
trainer = BCTrainer(policy, lr=1e-3)
trainer.train(dataloader, epochs=50)

# 测试
test_obs = np.random.randn(5, 10).astype(np.float32)
for i in range(5):
    pred = trainer.predict(test_obs[i])
    print(f"测试 {i}: 预测动作 = {np.round(pred, 4)}")
```

### 1.3 BC 的问题：分布偏移

```
分布偏移（Distribution Shift）问题：

训练时：
  策略看到的观测来自专家轨迹的分布
  P_train(o) = P_expert(o)

部署时：
  策略自己的动作导致不同的观测分布
  P_deploy(o) ≠ P_expert(o)

问题：
  策略在小错误上偏离专家轨迹 →
  到达训练时未见过的状态 →
  策略不知道如何处理 →
  更大的错误 → 恶性循环

这就是"复合误差"（Compounding Error）：
  每步小误差 ε，T 步后误差 O(Tε) 而非 O(√Tε)
```

## 二、DAgger 算法

### 2.1 DAgger 原理

```
DAgger (Dataset Aggregation):
  通过迭代采集数据解决分布偏移问题

流程：
  1. 用初始专家数据训练策略 π_1
  2. 用 π_1 执行任务，收集新轨迹
  3. 在新轨迹的每个状态，询问专家给出动作
  4. 将新数据加入数据集
  5. 重新训练策略 π_2
  6. 重复 2-5

关键：策略看到的状态分布逐渐接近部署时的分布
```

### 2.2 DAgger 实现

```python
class DAggerTrainer:
    """DAgger 训练器"""
    def __init__(self, policy, expert_policy, lr=1e-3):
        self.policy = policy
        self.expert = expert_policy
        self.optimizer = optim.Adam(policy.parameters(), lr=lr)
        self.criterion = nn.MSELoss()
        
        # 累积数据集
        self.all_observations = []
        self.all_actions = []
    
    def collect_data(self, env, num_episodes=10):
        """用当前策略收集数据，用专家标注"""
        self.policy.eval()
        
        for ep in range(num_episodes):
            obs = env.reset()
            done = False
            
            while not done:
                # 当前策略执行
                with torch.no_grad():
                    obs_tensor = torch.FloatTensor(obs).unsqueeze(0)
                    action = self.policy(obs_tensor).numpy().flatten()
                
                # 执行动作
                next_obs, reward, done, info = env.step(action)
                
                # 专家标注（关键区别！）
                expert_action = self.expert(obs)
                
                # 加入数据集
                self.all_observations.append(obs)
                self.all_actions.append(expert_action)
                
                obs = next_obs
        
        print(f"收集了 {len(self.all_observations)} 条数据")
    
    def train(self, epochs=50, batch_size=64):
        """在累积数据集上训练"""
        dataset = BCDataset(
            np.array(self.all_observations),
            np.array(self.all_actions)
        )
        dataloader = DataLoader(dataset, batch_size=batch_size, shuffle=True)
        
        self.policy.train()
        for epoch in range(epochs):
            total_loss = 0
            for obs_batch, action_batch in dataloader:
                pred = self.policy(obs_batch)
                loss = self.criterion(pred, action_batch)
                
                self.optimizer.zero_grad()
                loss.backward()
                self.optimizer.step()
                total_loss += loss.item()
            
            if (epoch + 1) % 10 == 0:
                print(f"DAgger Epoch {epoch+1}/{epochs}, Loss: {total_loss/len(dataloader):.6f}")
    
    def iterate(self, env, num_iterations=5, episodes_per_iter=10, epochs_per_iter=50):
        """DAgger 迭代"""
        for i in range(num_iterations):
            print(f"\n--- DAgger 迭代 {i+1}/{num_iterations} ---")
            self.collect_data(env, episodes_per_iter)
            self.train(epochs_per_iter)
```

## 三、GAIL 生成对抗模仿学习

### 3.1 GAIL 原理

```
GAIL (Generative Adversarial Imitation Learning):
  用 GAN 框架从专家演示中学习

核心组件：
  1. 生成器（Generator）：策略 π_θ，生成动作
  2. 判别器（Discriminator）：D_φ，区分专家动作和策略动作

训练目标：
  判别器：最大化 log(D(o,a)) + log(1 - D(o, π(o)))
  生成器：最小化 log(1 - D(o, π(o)))  ← 等价于最大化 log(D(o, π(o)))

最终：策略生成的轨迹与专家轨迹不可区分
```

### 3.2 GAIL 实现

```python
class Discriminator(nn.Module):
    """GAIL 判别器"""
    def __init__(self, obs_dim, action_dim, hidden_dim=128):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(obs_dim + action_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 1),
            nn.Sigmoid()
        )
    
    def forward(self, obs, action):
        x = torch.cat([obs, action], dim=-1)
        return self.net(x)

class GAIL:
    """GAIL 训练器"""
    def __init__(self, policy, obs_dim, action_dim, lr=1e-3):
        self.policy = policy  # 策略（生成器）
        self.discriminator = Discriminator(obs_dim, action_dim)
        
        self.policy_optimizer = optim.Adam(self.policy.parameters(), lr=lr)
        self.disc_optimizer = optim.Adam(self.discriminator.parameters(), lr=lr)
        
        self.bce = nn.BCELoss()
    
    def train_discriminator(self, expert_obs, expert_actions, policy_obs, policy_actions):
        """训练判别器"""
        batch_size = expert_obs.shape[0]
        
        # 专家标签 = 1，策略标签 = 0
        expert_labels = torch.ones(batch_size, 1)
        policy_labels = torch.zeros(batch_size, 1)
        
        # 专家数据
        expert_pred = self.discriminator(expert_obs, expert_actions)
        loss_expert = self.bce(expert_pred, expert_labels)
        
        # 策略数据
        policy_pred = self.discriminator(policy_obs, policy_actions)
        loss_policy = self.bce(policy_pred, policy_labels)
        
        loss = loss_expert + loss_policy
        
        self.disc_optimizer.zero_grad()
        loss.backward()
        self.disc_optimizer.step()
        
        return loss.item()
    
    def train_policy(self, obs):
        """训练策略（生成器）：欺骗判别器"""
        actions = self.policy(obs)
        
        # 判别器判断策略动作
        pred = self.discriminator(obs, actions)
        
        # 策略希望判别器认为是专家（标签=1）
        loss = self.bce(pred, torch.ones_like(pred))
        
        self.policy_optimizer.zero_grad()
        loss.backward()
        self.policy_optimizer.step()
        
        return loss.item()
```

## 四、ACT (Action Chunking Transformer)

### 4.1 ACT 核心思想

```
ACT (Action Chunking Transformer):
  ALOHA 系统的核心算法

关键创新：
  1. Action Chunking: 一次预测多步动作（而非单步）
  2. CVAE (条件变分自编码器): 处理多模态动作分布
  3. Transformer 架构: Encoder-Decoder 结构

为什么 Action Chunking 有效：
  - 减少决策频率：每 k 步才决策一次
  - 减少累积误差：预测的序列是"规划"好的
  - 平滑执行：chunk 内动作是连贯的
```

### 4.2 ACT 实现

```python
class ACTPolicy(nn.Module):
    """ACT (Action Chunking Transformer) 简化实现"""
    def __init__(self, obs_dim, action_dim, chunk_size=10, 
                 embed_dim=512, num_heads=8, num_layers=4, latent_dim=32):
        super().__init__()
        self.chunk_size = chunk_size
        self.latent_dim = latent_dim
        
        # 输入嵌入
        self.obs_embed = nn.Linear(obs_dim, embed_dim)
        self.action_embed = nn.Linear(action_dim, embed_dim)
        self.pos_enc = nn.Parameter(torch.randn(1, chunk_size + 1, embed_dim) * 0.02)
        
        # VAE 编码器
        self.encoder = nn.TransformerEncoder(
            nn.TransformerEncoderLayer(
                d_model=embed_dim, nhead=num_heads,
                dim_feedforward=embed_dim * 4, batch_first=True, dropout=0.1
            ),
            num_layers=num_layers
        )
        self.encoder_mu = nn.Linear(embed_dim, latent_dim)
        self.encoder_logvar = nn.Linear(embed_dim, latent_dim)
        
        # VAE 解码器
        self.latent_to_embed = nn.Linear(latent_dim, embed_dim)
        self.decoder = nn.TransformerDecoder(
            nn.TransformerDecoderLayer(
                d_model=embed_dim, nhead=num_heads,
                dim_feedforward=embed_dim * 4, batch_first=True, dropout=0.1
            ),
            num_layers=num_layers
        )
        
        # 动作输出头
        self.action_head = nn.Linear(embed_dim, action_dim)
    
    def encode(self, obs, actions=None):
        """VAE 编码"""
        obs_embed = self.obs_embed(obs).unsqueeze(1)  # (B, 1, C)
        
        if actions is not None:
            # 训练时：用观测和动作编码
            action_embed = self.action_embed(actions)  # (B, chunk, C)
            enc_input = torch.cat([obs_embed, action_embed], dim=1)  # (B, chunk+1, C)
            enc_input = enc_input + self.pos_enc[:, :enc_input.size(1)]
            
            enc_out = self.encoder(enc_input)
            mu = self.encoder_mu(enc_out[:, 0])
            logvar = self.encoder_logvar(enc_out[:, 0])
        else:
            # 推理时：只用观测
            enc_input = obs_embed + self.pos_enc[:, :1]
            enc_out = self.encoder(enc_input)
            mu = torch.zeros(obs.shape[0], self.latent_dim, device=obs.device)
            logvar = torch.zeros_like(mu)
        
        return mu, logvar, enc_out
    
    def decode(self, z, obs, actions=None):
        """VAE 解码"""
        z_embed = self.latent_to_embed(z).unsqueeze(1)  # (B, 1, C)
        
        if actions is not None:
            # Teacher forcing: 用真实动作的嵌入
            action_embed = self.action_embed(actions)
            dec_input = torch.cat([z_embed, action_embed[:, :-1]], dim=1)
        else:
            # 推理: 用查询 token
            queries = torch.randn(obs.shape[0], self.chunk_size, z_embed.shape[-1], device=obs.device)
            dec_input = torch.cat([z_embed, queries], dim=1)
        
        # 简化：用编码器输出作为 memory
        obs_embed = self.obs_embed(obs).unsqueeze(1)
        memory = obs_embed.expand(-1, self.chunk_size + 1, -1)
        
        dec_out = self.decoder(dec_input, memory)
        actions_pred = self.action_head(dec_out)
        return actions_pred
    
    def forward(self, obs, actions=None):
        """前向传播"""
        mu, logvar, _ = self.encode(obs, actions)
        
        # 重参数化采样
        if actions is not None:
            z = mu + torch.exp(logvar / 2) * torch.randn_like(mu)
        else:
            z = torch.zeros_like(mu)  # 推理时用先验（z=0）
        
        pred_actions = self.decode(z, obs, actions)
        return pred_actions, mu, logvar
    
    def predict_action(self, obs):
        """推理：预测动作序列"""
        self.eval()
        with torch.no_grad():
            obs_tensor = torch.FloatTensor(obs).unsqueeze(0)
            pred_actions, _, _ = self.forward(obs_tensor)
        return pred_actions.squeeze(0).numpy()

# ACT 损失函数
def act_loss(pred_actions, target_actions, mu, logvar, kl_weight=10.0):
    """
    ACT 损失 = MSE 重建损失 + KL 散度
    """
    # 重建损失
    recon_loss = F.mse_loss(pred_actions, target_actions)
    
    # KL 散度
    kl_loss = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp()) / mu.shape[0]
    
    total_loss = recon_loss + kl_weight * kl_loss
    return total_loss, recon_loss, kl_loss

# 测试
act = ACTPolicy(obs_dim=14, action_dim=7, chunk_size=10)
obs = torch.randn(8, 14)
actions = torch.randn(8, 10, 7)

pred, mu, logvar = act(obs, actions)
loss, recon, kl = act_loss(pred, actions, mu, logvar)
print(f"ACT 损失: {loss.item():.4f} (重建: {recon.item():.4f}, KL: {kl.item():.4f})")
print(f"预测动作形状: {pred.shape}")  # (8, 10, 7)
```

```python
import pybullet as p
import pybullet_data
import numpy as np
import torch
import torch.nn as nn
import torch.optim as optim
from collections import deque

class SimpleGraspEnv:
    """简化的 PyBullet 抓取环境"""
    def __init__(self, render=False):
        self.render = render
        if render:
            self.client = p.connect(p.GUI)
        else:
            self.client = p.connect(p.DIRECT)
        p.setAdditionalSearchPath(pybullet_data.getDataPath())
        
        self.obs_dim = 10  # 简化观测
        self.action_dim = 4  # dx, dy, dz, gripper
    
    def reset(self):
        p.resetSimulation(self.client)
        p.setGravity(0, 0, -9.81, self.client)
        
        # 加载地面
        p.loadURDF("plane.urdf", physicsClientId=self.client)
        
        # 加载机械臂（简化）
        # 实际中应加载完整的机械臂 URDF
        self.robot = p.loadURDF("franka_panda/panda.urdf", 
                                useFixedBase=True, physicsClientId=self.client)
        
        # 加载物体
        self.object = p.createMultiBody(
            baseMass=0.1,
            baseShape=p.GEOM_BOX,
            baseHalfExtents=[0.03, 0.03, 0.03],
            basePosition=[0.5, 0.0, 0.05],
            physicsClientId=self.client
        )
        
        return self._get_obs()
    
    def _get_obs(self):
        """获取观测"""
        # 简化：关节角度 + 物体位置
        joint_states = p.getJointStates(self.robot, range(7), physicsClientId=self.client)
        joint_pos = [js[0] for js in joint_states]
        
        obj_pos, _ = p.getBasePositionAndOrientation(self.object, physicsClientId=self.client)
        
        obs = np.array(joint_pos[:7] + list(obj_pos)[:3], dtype=np.float32)
        return obs[:self.obs_dim]  # 截取到 obs_dim
    
    def step(self, action):
        """执行动作"""
        # 简化的动作执行
        # 实际中需要更复杂的控制逻辑
        for _ in range(10):  # 10 步物理仿真
            p.stepSimulation(physicsClientId=self.client)
        
        obs = self._get_obs()
        success = self._check_success()
        done = success
        reward = 1.0 if success else 0.0
        
        return obs, reward, done, {"success": success}
    
    def _check_success(self):
        """检查是否抓取成功"""
        obj_pos, _ = p.getBasePositionAndOrientation(self.object, physicsClientId=self.client)
        return obj_pos[2] > 0.1  # 物体被举起
    
    def close(self):
        p.disconnect(self.client)

# 生成模拟专家数据
def generate_expert_data(num_episodes=100, episode_len=50):
    """模拟专家数据（实际中通过遥操作采集）"""
    observations = []
    actions = []
    
    for ep in range(num_episodes):
        for step in range(episode_len):
            obs = np.random.randn(10).astype(np.float32)
            # 模拟专家策略
            action = np.array([
                0.1 * (0.5 - obs[7]),  # 向物体 x 方向移动
                0.1 * (0.0 - obs[8]),  # 向物体 y 方向移动
                -0.05,                  # 向下移动
                1.0 if step > 25 else 0.0  # 后半段闭合夹爪
            ], dtype=np.float32)
            
            observations.append(obs)
            actions.append(action)
    
    return np.array(observations), np.array(actions)
```

## 六、常见问题总结

### 6.1 分布偏移

```
问题：训练时看到的状态分布 ≠ 部署时的状态分布

解决方案：
  1. DAgger：迭代收集策略轨迹并标注
  2. 数据增强：增加训练数据多样性
  3. 噪声注入：训练时给观测加噪声
  4. 域随机化：在仿真中随机化环境
```

### 6.2 复合误差

```
问题：小误差逐步累积成大误差

解决方案：
  1. Action Chunking: 减少决策频率
  2. 闭环执行：实时反馈修正
  3. Receding Horizon: 预测多步但只执行几步
  4. 多模态策略：如 Diffusion Policy
```

### 6.3 多模态动作分布

```
问题：同一观测可能有多种合理动作
  例如：从左边或右边绕过障碍物都可以

单模态策略（MSE 训练）的问题：
  会取两种动作的平均值（可能不合理）

解决方案：
  1. ACT (CVAE): 隐变量建模多模态
  2. Diffusion Policy: 扩散模型天然支持多模态
  3. GMM 策略: 混合高斯模型
```
