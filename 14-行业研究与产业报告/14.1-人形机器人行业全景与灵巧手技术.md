## 二、灵巧手技术路线

### 2.1 四大传动路线对比

| 路线 | 优点 | 缺点 | 代表 |
|------|------|------|------|
| 腱绳传动 | 柔性、轻量、远距离驱动 | 控制复杂 | 特斯拉Gen3 |
| 连杆传动 | 刚性好、精度高 | 体积大 | 兆威 |
| 直驱 | 响应快、无间隙 | 体积大、成本高 | 部分研究用 |
| 人工肌肉 | 生物启发 | 技术不成熟 | 实验室 |

**产业共识**：腱绳传动被认定为"终极解"。

### 2.2 特斯拉灵巧手演进

**Gen 2.5拆解**：
- 17个线性执行器（微型滚珠丝杠）
- 支撑22DOF
- 腱绳颜色编码：红(屈肌)/蓝(外展)/黑(内收)/绿(拇指)

**Gen 3升级**：
- 可能从空心杯电机转向无刷直流电机降本
- Dyneema纤维 + 不锈钢丝混合方案

### 2.3 灵巧手企业布局

| 企业 | DOF | 特点 |
|------|-----|------|
| 灵心巧手 | 42 | 最高DOF |
| 特斯拉Gen-3 | 22 | 腱绳+线性执行器 |
| 宇树 | 16 | 直驱方案 |
| 智元 | - | 模块化设计 |
| 兆威 | - | 连杆传动 |

## 三、电机技术演进

### 3.1 电机方案对比

| 类型 | 扭矩密度 | 成本 | 适用部位 |
|------|----------|------|----------|
| 空心杯电机 | 中 | 高 | 灵巧手(传统) |
| 无刷直流电机 | 中 | 中 | 灵巧手(Gen3趋势) |
| 轴向磁通电机 | 高30-50% | 中高 | 下一代方向 |
| 无框力矩电机 | 高 | 高 | 关节模组 |

### 3.2 轴向磁通电机优势

- 扭矩密度高30-50%
- 材料用量降60%
- 适合薄型关节应用

### 3.3 关注标的

伟创电气、鸣志电器、兆威机电、雷赛智能、步科股份

## 五、机器人运动系统

### 5.1 人形机器人运动指标

| 指标 | 要求 |
|------|------|
| 全身DOF | >=30 |
| 单臂负载 | >=5kg |
| 移动速度 | >=1.5m/s |

### 5.2 关节峰值力矩（1.8m机器人）

| 关节 | 峰值力矩 |
|------|----------|
| 髋/膝 | 396Nm |
| 腰 | 315Nm |
| 踝 | 208Nm |

### 5.3 减速器方案收敛

```
上肢 → 谐波减速器（精度高、体积小）
下肢 → 行星减速器（承载力大）
未来 → 80-90%采用行星模组
```

### 5.4 关节模组扭矩密度

达57.8 Nm/kg。

## 七、产业投资主线

1. **灵巧手技术路线收敛**：腱绳传动为终极解，电机从空心杯转向无刷直流
2. **关节模组与运控**：上肢谐波、下肢行星，扭矩密度持续提升
3. **感知系统**：六维力传感器国产化空间大（<10%）
4. **具身智能软件数据**：仿真数据成为核心底座
5. **产业投资与国产化**：丝杠、减速器、传感器是核心投资方向
