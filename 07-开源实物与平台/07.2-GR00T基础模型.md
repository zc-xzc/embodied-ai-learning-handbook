## 1. NVIDIA Isaac GR00T 概述

### 1.1 项目定位

Isaac GR00T 是 NVIDIA 推出的通用人形机器人基础模型平台，核心目标是：

- **跨形态泛化**（Cross-embodiment）：同一模型可适配不同硬件平台
- **多模态输入**：融合视频序列、自然语言指令和本体感觉状态
- **开源开放**：模型权重与代码在 GitHub / Hugging Face 开源
- **完整工具链**：从数据采集、训练到部署的全流程支持

### 1.2 平台组成

```
┌─────────────────────────────────────────────────────────────┐
│                    Isaac GR00T 平台                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │

│  │  数据管道    │  │  基础模型    │  │  仿真框架            │ │
│  │  (Data      │  │  (Foundation │  │  (Isaac Sim +       │ │
```

### 1.3 输入与输出

| 类型 | 说明 |
|------|------|
| **输入 1** | 来自机载摄像头的视频序列（多视角图像流） |
| **输入 2** | 自然语言指令（如 "pick up the red cup"） |
| **输入 3** | 机器人本体感觉状态（关节位置、速度等） |
| **输出** | 动作片段（Action Chunk）—— 预测未来多步关节相对运动 |

通过预测未来多个时间步的动作，模型实现平滑的全身控制，支持稳定的移动和协调的双臂操作。

### 1.4 训练数据来源

GR00T 模型利用三类混合数据源：

1. **互联网规模人体视频**：用于世界知识学习
2. **真实遥操作数据**：用于物理对齐
3. **合成数据**：由 NVIDIA Isaac Sim 和 Cosmos 生成，用于安全扩展

### 2.3 N1.6 关键改进

GR00T N1.6 相比 N1.5 的主要变化：

1. **扩展机体覆盖**：新增 AgiBot Genie-1 和 Fourier GR-1 的训练数据
2. **专门双臂操作数据集**：引入 YAM（Yet Another Manipulation）数据集
3. **开源推理模型**：可直接下载用于推理，无需从零训练
4. **模型规模升级**：从 2B 参数扩展到 3B 参数
5. **改进的泛化能力**：在更多任务和环境中表现更好

### 2.4 N1.7 早期体验版

GR00T N1.7 是当前最新的早期体验版本：

**支持的内容**：
- 访问预训练模型权重和参考代码
- 使用自定义数据微调或执行推理
- 用于实验、原型开发和科研

**不支持的内容**：
- 商业支持的生产级部署
- 功能集稳定的全面验证版本
- NVIDIA 产品级技术支持

### 3.2 VLA 模型架构（N1.6+）

GR00T N1.6 采用 Vision-Language-Action (VLA) 统一架构：

```
┌──────────┐   ┌──────────┐   ┌──────────────┐
│  视觉编码器 │   │ 语言编码器  │   │ 本体感觉编码器 │
│ (Vision   │   │(Language  │   │(Proprioception│
│  Encoder) │   │ Encoder)  │   │  Encoder)     │
└─────┬─────┘   └─────┬─────┘   └───────┬───────┘
      │               │                 │
      ▼               ▼                 ▼
┌─────────────────────────────────────────────┐
│         多模态融合层 (Multimodal Fusion)       │
│    ┌─────────────────────────────────────┐   │
│    │     Transformer 主干网络              │   │
│    │  (Cross-Attention + Self-Attention)  │   │
│    └─────────────────────────────────────┘   │
└──────────────────────┬──────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────┐
│         动作解码器 (Action Decoder)            │
│                                              │
│  • 动作片段生成 (Action Chunking)             │
│  • 多步预测 (Horizon = 16 / 32)              │
│  • 平滑插值                                   │
└──────────────────────────────────────────────┘
```

### 3.3 关键设计要点

```python
# GR00T 模型核心设计概念（伪代码）

class GR00TModel:
    """GR00T VLA 模型核心结构"""
    
    def __init__(self, config):
        # 视觉编码器：基于 Vision Transformer
        self.vision_encoder = VisionTransformer(
            img_size=224,
            patch_size=16,
            embed_dim=1024,
            depth=24,
            num_heads=16,
        )
        
        # 语言编码器：基于预训练 LLM
        self.language_encoder = LanguageModel.from_pretrained(
            config.language_model_name  # 如 "meta-llama/Llama-3.2-3B"
        )
        
        # 本体感觉编码器
        self.proprioception_encoder = MLP(
            input_dim=config.state_dim,    # 关节数量
            hidden_dims=[512, 512],
            output_dim=1024,
        )
        
        # 多模态融合 Transformer
        self.fusion_transformer = TransformerDecoder(
            embed_dim=1024,
            num_layers=12,
            num_heads=16,
            cross_attention=True,
        )
        
        # 动作解码器
        self.action_decoder = ActionHead(
            embed_dim=1024,
            action_dim=config.action_dim,   # 动作维度
            horizon=config.horizon,         # 预测步数
            num_inference_steps=10,         # 扩散去噪步数
        )
    
    def forward(self, video, language, state):
        """
        前向传播
        
        Args:
            video: [B, T, C, H, W] 视频帧序列
            language: [B, L] 语言 token 序列
            state: [B, D] 本体感觉状态
        
        Returns:
            action_chunk: [B, H, A] 动作片段
        """
        # 1. 编码各模态
        visual_features = self.vision_encoder(video)
        language_features = self.language_encoder(language)
        proprio_features = self.proprioception_encoder(state)
        
        # 2. 多模态融合
        fused_features = self.fusion_transformer(
            query=proprio_features,
            context=torch.cat([visual_features, language_features], dim=1),
        )
        
        # 3. 动作解码
        action_chunk = self.action_decoder(fused_features)
        
        return action_chunk
```

### 3.4 动作片段（Action Chunking）

GR00T 采用 Action Chunking 技术，一次预测未来多步动作：

| 参数 | 说明 | 典型值 |
|------|------|--------|
| `horizon` | 预测步数 | 16-32 |
| `action_dim` | 动作维度（关节数） | 7-37（取决于机器人） |
| `control_freq` | 控制频率 | 30-50 Hz |
| `receding_horizon` | 滑动窗口控制 | 每隔 N 步重新预测 |

```python
# Action Chunking 控制循环示例

class ActionChunkController:
    """基于动作片段的控制器"""
    
    def __init__(self, model, horizon=16, action_freq=30):
        self.model = model
        self.horizon = horizon
        self.action_freq = action_freq
        
        self.action_buffer = []
        self.current_step = 0
    
    def predict(self, observation, instruction):
        """预测新的动作片段"""
        with torch.no_grad():
            action_chunk = self.model(
                video=observation['video'],
                language=observation['instruction'],
                state=observation['state'],
            )
        
        # action_chunk: [horizon, action_dim]
        self.action_buffer = action_chunk.cpu().numpy()
        self.current_step = 0
    
    def get_action(self, observation, instruction):
        """获取当前动作"""
        # 如果缓冲区空了，重新预测
        if self.current_step >= len(self.action_buffer):
            self.predict(observation, instruction)
        
        action = self.action_buffer[self.current_step]
        self.current_step += 1
        
        return action
    
    def run(self, env, instruction, max_steps=1000):
        """运行控制循环"""
        for step in range(max_steps):
            obs = env.get_observation()
            action = self.get_action(obs, instruction)
            env.step(action)
```

```python
#!/usr/bin/env python3
"""GR00T 数据准备脚本：将原始示教数据转换为 GR00T 格式"""

import json
import numpy as np
import h5py
from pathlib import Path
import cv2
import pandas as pd
import pyarrow as pa
import pyarrow.parquet as pq

class GR00TDataPreparator:
    """将 HDF5 示教数据转换为 GR00T/LeRobot 格式"""
    
    def __init__(self, output_dir, robot_type="unitree_g1", fps=30):
        self.output_dir = Path(output_dir)
        self.robot_type = robot_type
        self.fps = fps
        
        # 创建目录结构
        (self.output_dir / "meta").mkdir(parents=True, exist_ok=True)
        (self.output_dir / "data" / "train").mkdir(parents=True, exist_ok=True)
        (self.output_dir / "videos" / "train").mkdir(parents=True, exist_ok=True)
    
    def convert_hdf5_to_gr00t(self, hdf5_files, task_description="pick up the object"):
        """
        将 HDF5 文件列表转换为 GR00T 数据集
        
        Args:
            hdf5_files: HDF5 文件路径列表
            task_description: 任务描述文本
        """
        all_episodes = []
        
        for ep_idx, hdf5_path in enumerate(hdf5_files):
            print(f"处理 Episode {ep_idx}: {hdf5_path}")
            
            # 读取 HDF5 数据
            with h5py.File(hdf5_path, 'r') as f:
                actions = f['action'][:]           # [T, action_dim]
                states = f['state'][:]             # [T, state_dim]
                images = f['image'][:]             # [T, num_cam, H, W, C]
                
                num_frames = actions.shape[0]
            
            # 保存视频
            video_dir = self.output_dir / "videos" / "train" / f"episode_{ep_idx:06d}"
            video_dir.mkdir(parents=True, exist_ok=True)
            
            cam_names = ['cam_head', 'cam_left_wrist', 'cam_right_wrist']
            video_paths = []
            
            for cam_idx, cam_name in enumerate(cam_names):
                video_path = video_dir / f"{cam_name}.mp4"
                self._save_video(images[:, cam_idx], str(video_path), self.fps)
                video_paths.append(str(video_path))
            
            # 创建 Parquet 表格数据
            records = []
            for frame_idx in range(num_frames):
                timestamp = frame_idx / self.fps
                record = {
                    'frame_index': frame_idx,
                    'timestamp': timestamp,
                    'episode_index': ep_idx,
                    'index': len(all_episodes) * num_frames + frame_idx,
                    'observation.state': states[frame_idx].tolist(),
                    'action': actions[frame_idx].tolist(),
                    'annotation.language.instruction': task_description,
                }
                
                # 视频路径引用
                for cam_name, vpath in zip(cam_names, video_paths):
                    record[f'observation.images.{cam_name}_path'] = vpath
                    record[f'observation.images.{cam_name}_timestamp'] = timestamp
                
                records.append(record)
            
            df = pd.DataFrame(records)
            parquet_path = self.output_dir / "data" / "train" / f"episode_{ep_idx:06d}.parquet"
            df.to_parquet(parquet_path, index=False)
            
            all_episodes.append({
                'episode_index': ep_idx,
                'num_frames': num_frames,
                'task': task_description,
            })
        
        # 保存元信息
        self._save_meta_info(all_episodes, actions.shape[1], states.shape[1])
        
        print(f"转换完成！共 {len(all_episodes)} 个 episodes")
    
    def _save_video(self, frames, output_path, fps):
        """将帧序列保存为视频"""
        height, width = frames[0].shape[:2]
        fourcc = cv2.VideoWriter_fourcc(*'mp4v')
        writer = cv2.VideoWriter(output_path, fourcc, fps, (width, height))
        
        for frame in frames:
            if frame.dtype != np.uint8:
                frame = (frame * 255).astype(np.uint8)
            if frame.shape[2] == 3:
                frame = cv2.cvtColor(frame, cv2.COLOR_RGB2BGR)
            writer.write(frame)
        
        writer.release()
    
    def _save_meta_info(self, episodes, action_dim, state_dim):
        """保存元信息文件"""
        # info.json
        info = {
            "codebase_version": "v2.1",
            "robot_type": self.robot_type,
            "fps": self.fps,
            "num_episodes": len(episodes),
            "total_frames": sum(ep['num_frames'] for ep in episodes),
            "features": {
                "observation.state": {
                    "dtype": "float32",
                    "shape": [state_dim],
                },
                "action": {
                    "dtype": "float32",
                    "shape": [action_dim],
                },
            },
        }
        
        with open(self.output_dir / "meta" / "info.json", 'w') as f:
            json.dump(info, f, indent=2)
        
        # episodes.jsonl
        with open(self.output_dir / "meta" / "episodes.jsonl", 'w') as f:
            for ep in episodes:
                f.write(json.dumps(ep) + '\n')
        
        # tasks.jsonl
        with open(self.output_dir / "meta" / "tasks.jsonl", 'w') as f:
            tasks = set(ep['task'] for ep in episodes)
            for task in tasks:
                f.write(json.dumps({"task": task}) + '\n')


# 使用示例
if __name__ == "__main__":
    preparator = GR00TDataPreparator(
        output_dir="./datasets/gr00t_pick_place",
        robot_type="unitree_g1",
        fps=30,
    )
    
    # 假设有 30 条示教数据
    hdf5_files = [f"./raw_data/episode_{i:03d}.hdf5" for i in range(30)]
    preparator.convert_hdf5_to_gr00t(hdf5_files, "pick up the red cup and place it on the plate")
```

### 5.5 微调训练配置

```python
#!/usr/bin/env python3
"""GR00T 微调训练脚本"""

import torch
import argparse
from pathlib import Path
from transformers import TrainingArguments, Trainer
from accelerate import Accelerator

class GR00TFineTuner:
    """GR00T 模型微调器"""
    
    def __init__(self, config_path: str):
        self.config = self._load_config(config_path)
        self.accelerator = Accelerator(
            mixed_precision='bf16' if torch.cuda.is_bf16_supported() else 'fp16',
        )
        
        # 设备
        self.device = self.accelerator.device
        print(f"使用设备: {self.device}")
        if torch.cuda.is_available():
            print(f"GPU: {torch.cuda.get_device_name()}")
            print(f"显存: {torch.cuda.get_device_properties(0).total_mem / 1e9:.1f} GB")
    
    def _load_config(self, config_path):
        """加载配置"""
        import yaml
        with open(config_path, 'r') as f:
            return yaml.safe_load(f)
    
    def load_pretrained_model(self):
        """加载预训练 GR00T 模型"""
        from gr00t.model.gr00t import GR00TModel
        
        model_path = self.config['model']['pretrained_path']
        print(f"加载预训练模型: {model_path}")
        
        self.model = GR00TModel.from_pretrained(
            model_path,
            torch_dtype=torch.bfloat16,
            device_map="auto",
        )
        
        # 冻结部分参数（可选）
        if self.config['training'].get('freeze_vision_encoder', True):
            for param in self.model.vision_encoder.parameters():
                param.requires_grad = False
            print("已冻结视觉编码器参数")
        
        # 统计可训练参数
        total_params = sum(p.numel() for p in self.model.parameters())
        trainable_params = sum(p.numel() for p in self.model.parameters() if p.requires_grad)
        print(f"总参数: {total_params:,}")
        print(f"可训练参数: {trainable_params:,} ({trainable_params/total_params*100:.1f}%)")
        
        return self.model
    
    def prepare_dataset(self):
        """准备数据集"""
        from gr00t.data.dataset import GR00TDataset
        from torch.utils.data import DataLoader
        
        dataset_path = self.config['data']['dataset_path']
        print(f"加载数据集: {dataset_path}")
        
        # 训练集
        train_dataset = GR00TDataset(
            dataset_path=dataset_path,
            split="train",
            horizon=self.config['model']['horizon'],
            image_size=tuple(self.config['model']['image_size']),
        )
        
        # 验证集
        val_dataset = GR00TDataset(
            dataset_path=dataset_path,
            split="val",
            horizon=self.config['model']['horizon'],
            image_size=tuple(self.config['model']['image_size']),
        ) if self.config['data'].get('val_split', 0.1) > 0 else None
        
        # DataLoader
        self.train_dataloader = DataLoader(
            train_dataset,
            batch_size=self.config['training']['batch_size'],
            num_workers=self.config['training'].get('num_workers', 8),
            shuffle=True,
            pin_memory=True,
            drop_last=True,
        )
        
        self.val_dataloader = DataLoader(
            val_dataset,
            batch_size=self.config['training']['batch_size'],
            num_workers=self.config['training'].get('num_workers', 8),
            shuffle=False,
            pin_memory=True,
        ) if val_dataset else None
        
        print(f"训练集: {len(train_dataset)} 样本")
        if val_dataset:
            print(f"验证集: {len(val_dataset)} 样本")
        
        return train_dataset
    
    def setup_optimizer(self):
        """设置优化器和学习率调度"""
        # 分层学习率
        param_groups = [
            {
                'params': [p for n, p in self.model.named_parameters() 
                          if 'vision_encoder' in n and p.requires_grad],
                'lr': self.config['training']['learning_rate'] * 0.1,
                'weight_decay': 0.01,
            },
            {
                'params': [p for n, p in self.model.named_parameters() 
                          if 'language_encoder' in n and p.requires_grad],
                'lr': self.config['training']['learning_rate'] * 0.5,
                'weight_decay': 0.01,
            },
            {
                'params': [p for n, p in self.model.named_parameters() 
                          if 'action_decoder' in n and p.requires_grad],
                'lr': self.config['training']['learning_rate'],
                'weight_decay': 0.0,
            },
        ]
        
        self.optimizer = torch.optim.AdamW(
            param_groups,
            lr=self.config['training']['learning_rate'],
        )
        
        # 余弦退火调度
        from torch.optim.lr_scheduler import CosineAnnealingWarmRestarts
        self.scheduler = CosineAnnealingWarmRestarts(
            self.optimizer,
            T_0=self.config['training'].get('warmup_steps', 1000),
            T_mult=2,
        )
        
        # 梯度缩放
        from torch.cuda.amp import GradScaler
        self.scaler = GradScaler(enabled=self.config['training'].get('use_amp', True))
    
    def train(self):
        """训练循环"""
        print("开始微调训练...")
        
        num_epochs = self.config['training']['num_epochs']
        log_interval = self.config['training'].get('log_interval', 10)
        save_interval = self.config['training'].get('save_interval', 500)
        eval_interval = self.config['training'].get('eval_interval', 1000)
        
        global_step = 0
        best_val_loss = float('inf')
        
        for epoch in range(num_epochs):
            self.model.train()
            epoch_loss = 0
            
            for batch_idx, batch in enumerate(self.train_dataloader):
                # 准备数据
                batch = {k: v.to(self.device) for k, v in batch.items()}
                
                # 前向 + 损失
                with self.accelerator.autocast():
                    loss = self.model.compute_loss(batch)
                
                # 反向传播
                self.optimizer.zero_grad()
                self.scaler.scale(loss).backward()
                
                # 梯度裁剪
                self.scaler.unscale_(self.optimizer)
                torch.nn.utils.clip_grad_norm_(
                    self.model.parameters(),
                    self.config['training'].get('max_grad_norm', 1.0),
                )
                
                self.scaler.step(self.optimizer)
                self.scaler.update()
                self.scheduler.step()
                
                epoch_loss += loss.item()
                global_step += 1
                
                # 日志
                if global_step % log_interval == 0:
                    lr = self.scheduler.get_last_lr()[0]
                    print(f"Epoch {epoch+1}/{num_epochs} | Step {global_step} | "
                          f"Loss: {loss.item():.6f} | LR: {lr:.2e}")
                    
                    # WandB 日志
                    if self.config.get('use_wandb', False):
                        import wandb
                        wandb.log({
                            'train/loss': loss.item(),
                            'train/learning_rate': lr,
                            'train/epoch': epoch,
                        }, step=global_step)
                
                # 保存检查点
                if global_step % save_interval == 0:
                    self._save_checkpoint(global_step, epoch)
                
                # 评估
                if global_step % eval_interval == 0 and self.val_dataloader:
                    val_loss = self._evaluate()
                    if val_loss < best_val_loss:
                        best_val_loss = val_loss
                        self._save_checkpoint(global_step, epoch, best=True)
            
            avg_loss = epoch_loss / len(self.train_dataloader)
            print(f"Epoch {epoch+1} 完成 | 平均损失: {avg_loss:.6f}")
        
        # 保存最终模型
        self._save_checkpoint(global_step, num_epochs, final=True)
        print(f"训练完成！最佳验证损失: {best_val_loss:.6f}")
    
    def _evaluate(self):
        """验证集评估"""
        self.model.eval()
        total_loss = 0
        
        with torch.no_grad():
            for batch in self.val_dataloader:
                batch = {k: v.to(self.device) for k, v in batch.items()}
                loss = self.model.compute_loss(batch)
                total_loss += loss.item()
        
        avg_loss = total_loss / len(self.val_dataloader)
        print(f"  验证损失: {avg_loss:.6f}")
        
        if self.config.get('use_wandb', False):
            import wandb
            wandb.log({'val/loss': avg_loss}, step=global_step)
        
        self.model.train()
        return avg_loss
    
    def _save_checkpoint(self, step, epoch, best=False, final=False):
        """保存检查点"""
        output_dir = Path(self.config['output_dir'])
        output_dir.mkdir(parents=True, exist_ok=True)
        
        if final:
            ckpt_dir = output_dir / "final"
        elif best:
            ckpt_dir = output_dir / "best"
        else:
            ckpt_dir = output_dir / f"checkpoint-{step}"
        
        ckpt_dir.mkdir(parents=True, exist_ok=True)
        
        # 保存模型
        self.model.save_pretrained(ckpt_dir)
        
        # 保存训练状态
        torch.save({
            'step': step,
            'epoch': epoch,
            'optimizer': self.optimizer.state_dict(),
            'scheduler': self.scheduler.state_dict(),
        }, ckpt_dir / "training_state.pt")
        
        print(f"检查点已保存: {ckpt_dir}")
    
    def run(self):
        """运行完整微调流程"""
        self.load_pretrained_model()
        self.prepare_dataset()
        self.setup_optimizer()
        self.train()


# 微调配置文件示例 (config.yaml)
```

### 5.6 LoRA 微调（轻量级）

对于显存有限的情况，可使用 LoRA 进行参数高效微调：

```python
#!/usr/bin/env python3
"""GR00T LoRA 微调"""

from peft import LoraConfig, get_peft_model, TaskType
import torch

def setup_lora_finetuning(model, r=16, lora_alpha=32, lora_dropout=0.1):
    """
    为 GR00T 模型配置 LoRA 微调
    
    Args:
        model: 预训练 GR00T 模型
        r: LoRA 秩
        lora_alpha: LoRA 缩放因子
        lora_dropout: LoRA dropout
    """
    lora_config = LoraConfig(
        task_type=TaskType.CAUSAL_LM,
        r=r,
        lora_alpha=lora_alpha,
        lora_dropout=lora_dropout,
        # 目标模块
        target_modules=[
            "q_proj", "k_proj", "v_proj", "o_proj",  # Attention
            "gate_proj", "up_proj", "down_proj",       # MLP
        ],
        bias="none",
    )
    
    model = get_peft_model(model, lora_config)
    model.print_trainable_parameters()
    
    # 输出示例:
    # trainable params: 12,582,912 || all params: 3,012,345,678 || trainable%: 0.42
    
    return model


# 使用示例
if __name__ == "__main__":
    from gr00t.model.gr00t import GR00TModel
    
    # 加载预训练模型
    model = GR00TModel.from_pretrained(
        "./checkpoints/gr00t-n1.6-3b",
        torch_dtype=torch.bfloat16,
        device_map="auto",
    )
    
    # 应用 LoRA
    model = setup_lora_finetuning(model, r=16, lora_alpha=32)
    
    # 此时只需要 ~12M 参数可训练（vs 3B 全参数）
    # 可以在单张 24GB GPU 上训练
```

### 7.3 推理脚本

```python
#!/usr/bin/env python3
"""GR00T 模型推理脚本"""

import torch
import numpy as np
from pathlib import Path

class GR00TInference:
    """GR00T 模型推理"""
    
    def __init__(self, model_path, device='cuda'):
        self.device = torch.device(device)
        
        # 加载模型
        from gr00t.model.gr00t import GR00TModel
        self.model = GR00TModel.from_pretrained(
            model_path,
            torch_dtype=torch.bfloat16,
            device_map=device,
        )
        self.model.eval()
        
        # 动作缓冲区
        self.action_buffer = []
        self.buffer_idx = 0
        
        # 配置
        self.horizon = 16
        self.n_action_steps = 8
        
        print(f"GR00T 模型已加载: {model_path}")
    
    @torch.no_grad()
    def predict(self, images, state, instruction):
        """
        预测动作片段
        
        Args:
            images: dict of camera_name -> np.ndarray [H, W, 3]
            state: np.ndarray [state_dim]
            instruction: str
        
        Returns:
            action_chunk: np.ndarray [horizon, action_dim]
        """
        # 预处理图像
        image_tensors = {}
        for cam_name, img in images.items():
            img = torch.from_numpy(img).float() / 255.0
            img = img.permute(2, 0, 1)  # HWC -> CHW
            img = img.unsqueeze(0).to(self.device)
            image_tensors[cam_name] = img
        
        # 预处理状态
        state_tensor = torch.from_numpy(state).float().unsqueeze(0).to(self.device)
        
        # 推理
        action_chunk = self.model(
            images=image_tensors,
            state=state_tensor,
            language=instruction,
        )
        
        return action_chunk.cpu().numpy()[0]  # [horizon, action_dim]
    
    def get_action(self, observation, instruction):
        """获取当前动作（带缓冲区）"""
        if self.buffer_idx >= len(self.action_buffer):
            # 重新预测
            images = observation['images']
            state = observation['state']
            self.action_buffer = self.predict(images, state, instruction)
            self.buffer_idx = 0
        
        action = self.action_buffer[self.buffer_idx]
        self.buffer_idx += 1
        
        return action
    
    def reset(self):
        """重置缓冲区"""
        self.action_buffer = []
        self.buffer_idx = 0


# 使用示例
if __name__ == "__main__":
    # 初始化推理
    inference = GR00TInference(
        model_path="./outputs/gr00t_finetune/best",
        device='cuda',
    )
    
    # 模拟环境
    instruction = "pick up the red cup and place it on the plate"
    
    for step in range(1000):
        # 获取观测
        observation = {
            'images': {
                'cam_head': get_camera_image('head'),
                'cam_left_wrist': get_camera_image('left_wrist'),
                'cam_right_wrist': get_camera_image('right_wrist'),
            },
            'state': get_robot_state(),  # np.ndarray [37]
        }
        
        # 获取动作
        action = inference.get_action(observation, instruction)
        
        # 执行动作
        robot.step(action)
```

## 8. 与 LeRobot 数据格式的转换

### 8.1 格式对比

| 特性 | GR00T 格式 | LeRobot Dataset v2.1 |
|------|-----------|---------------------|
| 表格存储 | Parquet | Parquet |
| 视频存储 | MP4 (H.264) | MP4 (H.264) |
| 元信息 | info.json + modality.json | info.json + features |
| Episode 管理 | episodes.jsonl | episodes.jsonl |
| 任务描述 | tasks.jsonl | tasks.jsonl |
| 数据统计 | stats.json | stats.json |

GR00T 格式本质上是 LeRobot Dataset v2.1 的超集，增加了 `modality.json` 等配置文件。

### 8.2 LeRobot → GR00T 转换

```python
#!/usr/bin/env python3
"""LeRobot Dataset → GR00T 格式转换"""

import json
import shutil
from pathlib import Path

def convert_lerobot_to_gr00t(lerobot_dir, gr00t_dir):
    """
    将 LeRobot Dataset 转换为 GR00T 格式
    
    Args:
        lerobot_dir: LeRobot 数据集目录
        gr00t_dir: GR00T 输出目录
    """
    lerobot_dir = Path(lerobot_dir)
    gr00t_dir = Path(gr00t_dir)
    
    # 创建 GR00T 目录结构
    (gr00t_dir / "meta").mkdir(parents=True, exist_ok=True)
    (gr00t_dir / "data").mkdir(parents=True, exist_ok=True)
    (gr00t_dir / "videos").mkdir(parents=True, exist_ok=True)
    
    # 1. 复制数据文件（Parquet 格式兼容）
    if (lerobot_dir / "data").exists():
        shutil.copytree(
            lerobot_dir / "data",
            gr00t_dir / "data",
            dirs_exist_ok=True,
        )
    
    # 2. 复制视频文件
    if (lerobot_dir / "videos").exists():
        shutil.copytree(
            lerobot_dir / "videos",
            gr00t_dir / "videos",
            dirs_exist_ok=True,
        )
    
    # 3. 转换 info.json
    with open(lerobot_dir / "meta" / "info.json", 'r') as f:
        info = json.load(f)
    
    # 添加 GR00T 特有字段
    info["codebase_version"] = "v2.1"
    info["gr00t_compatible"] = True
    
    with open(gr00t_dir / "meta" / "info.json", 'w') as f:
        json.dump(info, f, indent=2)
    
    # 4. 生成 modality.json
    modality = {
        "video": {"keys": []},
        "state": {"keys": []},
        "action": {"keys": []},
        "language": {"keys": []},
    }
    
    for key in info.get("features", {}):
        if "image" in key or "video" in key:
            modality["video"]["keys"].append(key)
        elif "state" in key:
            modality["state"]["keys"].append(key)
        elif key == "action":
            modality["action"]["keys"].append(key)
        elif "language" in key or "instruction" in key:
            modality["language"]["keys"].append(key)
    
    with open(gr00t_dir / "meta" / "modality.json", 'w') as f:
        json.dump(modality, f, indent=2)
    
    # 5. 复制其他元文件
    for meta_file in ["episodes.jsonl", "tasks.jsonl", "stats.json"]:
        src = lerobot_dir / "meta" / meta_file
        if src.exists():
            shutil.copy2(src, gr00t_dir / "meta" / meta_file)
    
    print(f"转换完成: {lerobot_dir} -> {gr00t_dir}")
    print(f"  视频模态: {modality['video']['keys']}")
    print(f"  状态模态: {modality['state']['keys']}")
    print(f"  动作模态: {modality['action']['keys']}")


# 使用示例
if __name__ == "__main__":
    convert_lerobot_to_gr00t(
        lerobot_dir="./datasets/lerobot_aloha",
        gr00t_dir="./datasets/gr00t_aloha",
    )
```

### 8.4 双向转换工具

```python
#!/usr/bin/env python3
"""GR00T ↔ LeRobot 双向格式转换工具"""

import argparse
import json
import shutil
from pathlib import Path

class FormatConverter:
    """数据格式双向转换器"""
    
    SUPPORTED_DIRECTIONS = ["lerobot2gr00t", "gr00t2lerobot"]
    
    def __init__(self):
        pass
    
    def convert(self, input_dir, output_dir, direction):
        """
        执行格式转换
        
        Args:
            input_dir: 输入数据集目录
            output_dir: 输出数据集目录
            direction: 转换方向
        """
        if direction not in self.SUPPORTED_DIRECTIONS:
            raise ValueError(f"不支持的方向: {direction}")
        
        input_dir = Path(input_dir)
        output_dir = Path(output_dir)
        
        print(f"转换方向: {direction}")
        print(f"输入: {input_dir}")
        print(f"输出: {output_dir}")
        
        # 检查输入
        if not (input_dir / "meta" / "info.json").exists():
            raise FileNotFoundError(f"未找到 info.json: {input_dir / 'meta' / 'info.json'}")
        
        # 复制基础数据（Parquet 和视频格式兼容）
        output_dir.mkdir(parents=True, exist_ok=True)
        (output_dir / "meta").mkdir(exist_ok=True)
        (output_dir / "data").mkdir(exist_ok=True)
        (output_dir / "videos").mkdir(exist_ok=True)
        
        # 复制数据
        for subdir in ["data", "videos"]:
            src = input_dir / subdir
            if src.exists():
                shutil.copytree(src, output_dir / subdir, dirs_exist_ok=True)
        
        # 处理元信息
        with open(input_dir / "meta" / "info.json", 'r') as f:
            info = json.load(f)
        
        if direction == "lerobot2gr00t":
            # LeRobot → GR00T
            info["codebase_version"] = "v2.1"
            info["gr00t_compatible"] = True
            
            # 生成 modality.json
            self._generate_modality_json(info, output_dir / "meta" / "modality.json")
            
        else:
            # GR00T → LeRobot
            info.pop("gr00t_compatible", None)
        
        with open(output_dir / "meta" / "info.json", 'w') as f:
            json.dump(info, f, indent=2)
        
        # 复制其他元文件
        for meta_file in ["episodes.jsonl", "tasks.jsonl", "stats.json"]:
            src = input_dir / "meta" / meta_file
            if src.exists():
                shutil.copy2(src, output_dir / "meta" / meta_file)
        
        # 验证
        self._verify(output_dir)
        print("转换完成并验证通过！")
    
    def _generate_modality_json(self, info, output_path):
        """生成 GR00T 的 modality.json"""
        modality = {
            "video": {"keys": []},
            "state": {"keys": []},
            "action": {"keys": []},
            "language": {"keys": []},
        }
        
        for key in info.get("features", {}):
            key_lower = key.lower()
            if "image" in key_lower or "video" in key_lower:
                modality["video"]["keys"].append(key)
            elif "state" in key_lower:
                modality["state"]["keys"].append(key)
            elif key == "action":
                modality["action"]["keys"].append(key)
            elif "language" in key_lower or "instruction" in key_lower:
                modality["language"]["keys"].append(key)
        
        with open(output_path, 'w') as f:
            json.dump(modality, f, indent=2)
        
        print(f"生成 modality.json:")
        for mod, config in modality.items():
            if config["keys"]:
                print(f"  {mod}: {config['keys']}")
    
    def _verify(self, dataset_dir):
        """验证数据集完整性"""
        required_files = [
            "meta/info.json",
        ]
        
        for f in required_files:
            if not (dataset_dir / f).exists():
                raise FileNotFoundError(f"验证失败：缺少文件 {f}")
        
        print("验证通过")


if __name__ == "__main__":
    parser = argparse.ArgumentParser(description="GR00T ↔ LeRobot 格式转换")
    parser.add_argument("--input", required=True, help="输入数据集目录")
    parser.add_argument("--output", required=True, help="输出数据集目录")
    parser.add_argument("--direction", required=True, 
                        choices=["lerobot2gr00t", "gr00t2lerobot"],
                        help="转换方向")
    
    args = parser.parse_args()
    
    converter = FormatConverter()
    converter.convert(args.input, args.output, args.direction)
```
