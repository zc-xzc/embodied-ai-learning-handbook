## 一、岗位类型分类总览

基于 Xbotics-Embodied-AI-Job 项目收录的 100+ 份岗位 JD（Job Description），具身智能行业的岗位可分为以下六大类：

| 岗位大类 | 细分方向 | 岗位数量占比 | 核心职责 |
|----------|----------|-------------|----------|
| **具身智能算法工程师** | VLA方向、RL方向、操作方向 | ~35% | 设计和实现机器人学习算法，包括VLA模型、RL策略、模仿学习等 |
| **运动控制工程师** | 全身控制、locomotion、力控 | ~15% | 人形/四足机器人运动控制算法，包括MPC、WBC、RL locomotion |
| **仿真算法工程师** | 仿真环境、Sim2Real、场景构建 | ~10% | 搭建仿真训练环境、Sim2Real迁移、场景生成 |
| **数据工程师** | 数据采集、标注、处理pipeline | ~10% | 遥操作数据采集系统、数据处理pipeline、数据质量保证 |
| **感知算法工程师** | 视觉感知、多模态融合、SLAM | ~15% | 目标检测、6D姿态估计、场景理解、多传感器融合 |
| **硬件工程师** | 结构设计、电子电气、系统集成 | ~15% | 机器人本体设计、关节模组开发、传感器集成、系统调试 |

**统计说明：** 上述比例为基于100+份JD的估算分布，实际市场可能因公司类型（整机 vs 算法）有所不同。

## 二、各类岗位详细分析

### 2.1 具身智能算法工程师

这是当前具身智能行业需求量最大、薪资最高的岗位类型。

#### 2.1.1 VLA 方向

**岗位描述：**
负责 Vision-Language-Action 大模型的设计、训练和部署，实现机器人从自然语言指令到物理操作的端到端能力。

**典型 JD 摘录：**
> "负责具身智能VLA大模型的研发，包括模型架构设计、数据训练、Sim2Real迁移，实现机器人在真实场景中的通用操作能力。"

**技能要求矩阵：**

| 技能类别 | 技能项 | 要求级别 | 说明 |
|----------|--------|----------|------|
| **编程语言** | Python | 必须 | 熟练使用，能独立开发复杂系统 |
| | C++ | 推荐 | 部署和推理优化需要 |
| | CUDA/Triton | 加分 | GPU编程优化 |
| **深度学习框架** | PyTorch | 必须 | 熟练使用，理解底层原理 |
| | JAX | 加分 | 部分团队使用 |
| **大模型技术** | Transformer | 必须 | 深入理解架构和训练方法 |
| | VLM (CLIP, LLaVA等) | 必须 | 理解视觉-语言模型原理 |
| | Pre-training/SFT/RLHF | 必须 | 大模型训练全流程 |
| | Distributed Training | 推荐 | DeepSpeed, Megatron等 |
| **机器人学习** | Imitation Learning | 必须 | BC, DAgger, ACT, Diffusion Policy |
| | Reinforcement Learning | 推荐 | PPO, SAC, Offline RL |
| | VLA Models | 必须 | RT-1, RT-2, OpenVLA, π0 |
| **机器人系统** | ROS/ROS2 | 推荐 | 机器人通信框架 |
| | 仿真环境 | 推荐 | Isaac Sim/Lab, MuJoCo |
| | 机器人硬件 | 加分 | 了解机械臂/人形机器人 |

**学历要求：** 硕士及以上，博士优先
**经验要求：** 1-3年相关经验（实习经验可计），博士应届可接受
**典型公司：** 智元机器人、银河通用、穹彻智能、Physical Intelligence、Figure AI、NVIDIA

#### 2.1.2 RL 方向

**岗位描述：**
负责机器人强化学习算法的设计与实现，包括仿真训练、Sim2Real迁移、奖励函数设计等。

**典型 JD 摘录：**
> "负责机器人强化学习算法的研发，包括奖励函数设计、训练框架搭建、Sim2Real迁移，实现机器人在复杂环境中的自主学习和适应能力。"

**技能要求矩阵：**

| 技能类别 | 技能项 | 要求级别 | 说明 |
|----------|--------|----------|------|
| **编程语言** | Python | 必须 | RL算法实现 |
| | C++ | 推荐 | 部署和推理 |
| **RL框架** | Stable-Baselines3 | 推荐 | 标准RL算法库 |
| | RLlib | 加分 | 分布式RL |
| | Isaac Lab / rsl-rl | 推荐 | 机器人RL专用 |
| | CleanRL | 加分 | 单文件RL实现 |
| **RL算法** | On-policy (PPO) | 必须 | 最常用的机器人RL算法 |
| | Off-policy (SAC, TD3) | 必须 | 样本效率高 |
| | Offline RL (CQL, AWAC) | 推荐 | 从离线数据学习 |
| | Model-based RL | 加分 | 世界模型方向 |
| **仿真环境** | Isaac Sim/Lab | 必须 | GPU加速RL训练 |
| | MuJoCo | 推荐 | 经典物理仿真 |
| | Genesis | 加分 | 新型仿真环境 |
| **Sim2Real** | Domain Randomization | 必须 | 经典Sim2Real技术 |
| | System Identification | 推荐 | 系统参数辨识 |
| | Reality Gap分析 | 推荐 | 理解和缩小gap |

**学历要求：** 硕士及以上
**经验要求：** 有RL项目经验（课程项目/论文/实习均可）
**典型公司：** 宇树科技、逐际动力、星动纪元、Boston Dynamics

## 四、学历与经验要求统计

### 4.1 学历要求分布

基于 100+ 份 JD 的统计：

| 学历要求 | 占比 | 适用岗位 |
|----------|------|----------|
| **博士优先/必须** | ~25% | VLA大模型、RL前沿研究、世界模型 |
| **硕士及以上** | ~50% | 算法工程师（各方向）、感知工程师 |
| **本科及以上** | ~20% | 仿真工程师、数据工程师、硬件工程师 |
| **不限/经验优先** | ~5% | 部分工程化岗位 |

**关键发现：**
- 算法岗（尤其VLA方向）对学历要求最高，博士有明显优势
- 工程/系统岗更看重实际经验，本科+强项目经验也有竞争力
- 顶级公司（如Physical Intelligence、Figure）倾向于招博士
- 国内创业公司更灵活，强项目经验可弥补学历

### 4.2 经验要求分布

| 经验要求 | 占比 | 典型岗位 |
|----------|------|----------|
| **应届/0-1年** | ~15% | 实习转正、校招 |
| **1-3年** | ~35% | 中级工程师 |
| **3-5年** | ~30% | 高级工程师 |
| **5年以上** | ~15% | 技术负责人/架构师 |
| **10年+/行业老兵** | ~5% | CTO/首席科学家 |

**关键发现：**
- 由于具身智能是新领域，大部分岗位对经验要求相对灵活
- 论文/开源项目/竞赛经历可有效替代工作经验
- 有机器人/自动驾驶/RL背景的候选人更受青睐
- "3-5年"是黄金经验区间，既有深度又不过于资深

## 八、岗位趋势与变化

### 8.1 2024-2025 岗位趋势

1. **VLA算法岗位爆发式增长**：2024年起VLA方向岗位数量增长最快，几乎所有头部公司都在招VLA工程师
2. **运动控制需求稳定**：人形机器人公司对运动控制人才需求持续旺盛
3. **数据工程师成为新兴岗位**：随着数据驱动范式确立，数据相关岗位从2024年开始大量出现
4. **仿真岗位从辅助变核心**：Sim2Real成为标准pipeline，仿真工程师从边缘走向核心
5. **硬件工程师需求分化**：高端硬件（关节模组、灵巧手）需求增长，普通组装类需求下降
6. **全栈工程师受青睐**：能同时做算法+系统+部署的"T型人才"最受追捧

### 8.2 技能需求变化

| 技能 | 2023年需求 | 2025年需求 | 趋势 |
|------|-----------|-----------|------|
| VLA大模型 | 低 | 极高 | ↑↑↑ |
| 强化学习 | 中 | 高 | ↑↑ |
| 模仿学习 | 中 | 高 | ↑↑ |
| 仿真/Sim2Real | 中 | 高 | ↑↑ |
| 运动控制 | 高 | 高 | → |
| 感知(传统) | 高 | 中 | ↓ |
| ROS | 高 | 中 | → |
| 大模型训练 | 低 | 高 | ↑↑↑ |
| 数据工程 | 低 | 中高 | ↑↑ |

### 8.3 对求职者的建议

1. **算法方向**：重点学习VLA模型（RT系列、OpenVLA、π0）、模仿学习（ACT、Diffusion Policy）、RL（PPO、SAC）
2. **运动控制方向**：深入MPC/WBC，同时学习RL locomotion，Sim2Real是加分项
3. **仿真方向**：掌握Isaac Lab，了解MuJoCo和Genesis，能搭建完整Sim2Real pipeline
4. **数据方向**：学习遥操作系统（ALOHA等），掌握数据处理pipeline
5. **全栈发展**：算法+系统+部署能力，是未来最有竞争力的方向
6. **持续学习**：具身智能领域变化极快，保持论文跟踪和代码实践
