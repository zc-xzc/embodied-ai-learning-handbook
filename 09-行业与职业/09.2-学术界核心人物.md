### 1.1 机器人操作与学习

#### 王鹤（北京大学）

| 维度 | 详情 |
|------|------|
| **所属机构** | 北京大学计算机学院、北京大学通用人工智能研究所 |
| **研究方向** | 具身智能、6D物体姿态估计、机器人操作、VLA大模型 |
| **代表性工作** | 
  - Embodied AI 综述（"Embodied AI: A Survey"）
  - GigaPose（6D姿态估计）
  - PoseCNN（早期物体姿态估计工作）
  - Galaxy 通用机器人操作大模型 |
| **个人主页** | https://hughw.github.io |
| **实验室** | 北京大学具身智能实验室 |
| **产业关联** | 银河通用（Galbot）联合创始人 |

**学术贡献概述：**
王鹤是国内具身智能领域最具影响力的学者之一。他早期的工作在6D物体姿态估计方面奠定了基础（PoseCNN 是该领域的经典工作），后来转向具身智能全栈研究。他发表的具身智能综述论文是该领域被引最高的综述之一，为社区提供了系统性的知识框架。近年来，他致力于通用机器人操作大模型（VLA）的研究和产业化。

## 二、国外学者

### 2.1 模仿学习与操作

#### Pieter Abbeel（UC Berkeley）

| 维度 | 详情 |
|------|------|
| **所属机构** | UC Berkeley, EECS |
| **研究方向** | 强化学习、模仿学习、机器人操作 |
| **代表性工作** | 
  - **BC (Behavioral Cloning)**：早期模仿学习奠基工作
  - **DAgger (Dataset Aggregation)**：交互式模仿学习经典算法
  - **Deep RL for Robotics**：深度RL在机器人上的开创性应用
  - **BCO (Behavior Cloning from Observation)**：从观察中模仿
  - LLM驱动的奖励设计 |
| **个人主页** | https://people.eecs.berkeley.edu/~pabbeel |
| **实验室** | Berkeley Robot Learning Lab |
| **产业关联** | Covariant 联合创始人, Skild AI 顾问 |

**学术贡献概述：**
Pieter Abbeel 是机器人学习领域最具影响力的学者之一。DAgger 算法是模仿学习领域的里程碑，解决了分布偏移问题。他的实验室培养了众多机器人学习领域的领军人物（包括 Sergey Levine, Chelsea Finn, Tianhe Yu 等）。近年来他关注 LLM + Robotics 的交叉方向。

## 五、学术追踪建议

### 5.1 论文追踪渠道

1. **Google Scholar**：关注上述学者的主页，设置引用提醒
2. **arXiv**：订阅 cs.RO, cs.LG, cs.AI, cs.CV 分类
3. **Twitter/X**：关注学者的社交账号，获取最新工作发布
4. **Paper Digest**：每日机器人领域论文摘要
5. **Papers with Code**：追踪带代码的论文
6. **Semantic Scholar**：利用 AI 推荐相关论文

### 5.2 核心会议

| 会议 | 领域 | 时间(通常) | 重要性 |
|------|------|-----------|--------|
| **CoRL** | 机器人学习 | 11月 | ★★★★★ |
| **RSS** | 机器人科学 | 7月 | ★★★★★ |
| **ICRA** | 机器人与自动化 | 5月 | ★★★★☆ |
| **IROS** | 智能机器人与系统 | 10月 | ★★★★☆ |
| **NeurIPS** | 神经信息处理 | 12月 | ★★★★☆ |
| **ICML** | 机器学习 | 7月 | ★★★★☆ |
| **ICLR** | 学习表征 | 5月 | ★★★★☆ |
| **CVPR/ICCV/ECCV** | 计算机视觉 | 6月/交替 | ★★★☆☆ |

### 5.3 学术社交建议

1. **参加 Workshop**：CoRL、RSS、ICRA 的具身智能 Workshop 是结识同行的好机会
2. **开源贡献**：为知名开源项目（如 LeRobot, Isaac Lab）贡献代码，增加学术曝光
3. **论文复现**：复现核心论文并分享，建立学术信誉
4. **Twitter/X 学术圈**：积极分享自己的工作，参与学术讨论
5. **暑期学校**：参加 RLDM、CoRL 暑期学校等活动

### 5.4 导师选择建议

选择导师时需考虑以下因素：

| 因素 | 考虑要点 |
|------|----------|
| **研究方向匹配** | 导师的核心方向是否与你的兴趣一致 |
| **实验室资源** | 是否有足够的机器人硬件、GPU、数据等资源 |
| **论文产出** | 实验室近年顶会论文数量和质量 |
| **产业联系** | 是否有企业合作，便于实习和就业 |
| **指导风格** | Hands-on vs Hands-off，找到适合自己的风格 |
| **毕业去向** | 毕业生的就业去向（学术界/工业界） |
| **资金支持** | 是否提供充足的RA/TA支持 |
