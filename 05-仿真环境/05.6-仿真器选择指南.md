## 2. 按任务类型的推荐选择

### 2.1 任务推荐矩阵

| 任务类型 | 首选 | 次选 | 理由 |
|---------|:---:|:---:|------|
| **大规模 RL 训练** | Isaac Sim | Genesis | GPU 并行能力强，单 GPU 数千环境 |
| **快速原型开发** | MuJoCo | PyBullet | 轻量级、启动快、API 简洁 |
| **高保真传感器模拟** | Isaac Sim | Genesis | RTX 光线追踪渲染、物理级传感器 |
| **ROS 生态集成** | Gazebo | Isaac Sim | 原生 ROS 支持、丰富插件 |
| **移动机器人导航** | Gazebo | Isaac Sim | Nav2 集成、真实场景建模 |
| **机械臂操作** | Isaac Sim | MuJoCo | 精确接触仿真、丰富模型库 |
| **人形机器人** | Isaac Sim | MuJoCo | G1/H1 官方支持、高保真物理 |
| **柔体/可变形物体** | Genesis | Isaac Sim | 唯一支持统一柔体仿真 |
| **流体仿真** | Genesis | - | 唯一支持流体仿真 |
| **可微分仿真** | Genesis | Isaac Sim | 原生可微分、梯度优化 |
| **合成数据生成** | Isaac Sim | Genesis | 内置 SDG 管线、域随机化 |
| **Sim2Real** | Isaac Sim | MuJoCo | 域随机化、物理参数调节 |
| **低资源环境** | PyBullet | MuJoCo | 无需 GPU、资源占用低 |
| **教学/入门** | PyBullet | MuJoCo | 安装简单、文档丰富 |
| **VR 遥操作** | PyBullet | Isaac Sim | 原生 VR 支持 |
| **多机器人协作** | Isaac Sim | Gazebo | 并行仿真、多智能体支持 |

### 2.3 具体场景推荐

#### 场景 1：训练 VLA 模型

```
推荐: Isaac Sim + Isaac Lab
理由:
  - GPU 并行仿真 (4096+ 环境)
  - 高质量相机渲染 (RTX)
  - 内置域随机化
  - 合成数据生成管线
  - 与 LeRobot/GR00T 集成
```

#### 场景 2：人形机器人遥操作

```
推荐: MuJoCo
理由:
  - 快速物理仿真 (2000+ Hz)
  - G1/H1 官方模型支持
  - 低延迟仿真
  - 精确接触动力学
  - 轻量级部署
```

#### 场景 3：自主导航研究

```
推荐: Gazebo + ROS 2
理由:
  - Nav2 导航栈原生集成
  - 丰富的环境模型库
  - 传感器插件完善
  - 社区资源丰富
  - 真实场景映射
```

#### 场景 4：灵巧手抓取

```
推荐: Isaac Sim 或 MuJoCo
理由:
  - 精确的接触力计算
  - 多关节机器人支持
  - 柔体抓取物体仿真
  - 视觉观测生成
```

#### 场景 5：快速算法验证

```
推荐: PyBullet
理由:
  - 一行安装 (pip install pybullet)
  - 丰富的内置模型
  - 简洁 API
  - 无需 GPU
  - 快速启动
```

### 3.7 选择建议总结

```
最终建议:

1. 如果你有 RTX GPU 且做研究/产品开发:
   → 首选 Isaac Sim (功能最全面)

2. 如果你需要快速验证算法或教学:
   → 首选 MuJoCo 或 PyBullet (轻量高效)

3. 如果你需要 ROS 生态:
   → 首选 Gazebo (原生集成)

4. 如果你需要柔体/流体/可微分仿真:
   → 首选 Genesis (独特能力)

5. 如果你不确定:
   → 从 MuJoCo 开始 (最低门槛，最高物理精度)
```
