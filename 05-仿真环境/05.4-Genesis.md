## 1. Genesis 仿真器介绍

### 1.1 概述

Genesis 是一个通用机器人仿真平台，由斯坦福大学、CMU、MIT 等研究机构联合开发。它旨在提供一个统一的、可扩展的机器人仿真框架，特别关注以下方面：

- **物理仿真的多样性**：支持刚体、柔体、流体、可变形体的统一仿真
- **高性能并行**：基于 JAX/PyTorch 的 GPU 加速，支持大规模并行仿真
- **多后端支持**：可切换不同物理引擎后端
- **Python 原生**：完全用 Python 实现，易于扩展和调试
- **可微分仿真**：支持可微分物理仿真，便于梯度优化
- **照片级渲染**：支持多种渲染后端

### 1.2 核心特性

| 特性 | 说明 |
|------|------|
| 统一物理引擎 | 刚体、柔体、流体、可变形体统一仿真 |
| GPU 并行 | 基于 JAX 的向量化并行，支持数千环境同时仿真 |
| 可微分仿真 | 支持自动微分，可用于系统辨识和策略优化 |
| 多渲染后端 | 支持光栅化和光线追踪渲染 |
| 材质系统 | 支持程序化材质生成和 PBR 材质 |
| 域随机化 | 内置物理参数和视觉域随机化 |
| 数据生成 | 内置合成数据生成管线 |

### 1.3 设计理念

Genesis 的设计哲学是"一个框架解决所有仿真需求"：

```
┌──────────────────────────────────────────┐
│           Genesis 架构                    │
├──────────────────────────────────────────┤
│  应用层                                    │
│  ├── RL Training (强化学习训练)            │
│  ├── Data Generation (数据生成)            │
│  ├── Differentiable Sim (可微分仿真)       │
│  └── Sim2Real (仿真到真实)                │
├──────────────────────────────────────────┤
│  API 层                                   │
│  ├── Scene API (场景管理)                 │
│  ├── Entity API (实体管理)                │
│  ├── Sensor API (传感器管理)              │
│  └── Viewer API (可视化)                  │
├──────────────────────────────────────────┤
│  物理后端                                  │
│  ├── Rigid Body (刚体物理)                │
│  ├── Soft Body (柔体物理)                 │
│  ├── Fluid (流体仿真)                     │
│  └── Deformable (可变形体)                │
├──────────────────────────────────────────┤
│  计算后端                                  │
│  ├── JAX (GPU/TPU 加速)                   │
│  ├── PyTorch (GPU 加速)                   │
│  └── NumPy (CPU 后备)                     │
└──────────────────────────────────────────┘
```

## 2. 安装与配置

### 2.1 系统要求

| 组件 | 最低要求 | 推荐配置 |
|------|---------|---------|
| GPU | 任意 CUDA GPU | RTX 3090/4090 (24GB) |
| CUDA | 11.8+ | 12.1+ |
| Python | 3.9+ | 3.10 或 3.11 |
| RAM | 16GB | 64GB+ |
| OS | Ubuntu 20.04+ / Windows 10+ | Ubuntu 22.04 |

### 2.2 安装

#### 方式一：pip 安装（推荐）

```bash
# 创建 conda 环境
conda create -n genesis python=3.10 -y
conda activate genesis

# 安装 Genesis
pip install genesis-world

# 或者从 GitHub 安装最新版
pip install git+https://github.com/Genesis-Embodied-AI/Genesis.git
```

#### 方式二：从源码安装

```bash
# 克隆仓库
git clone https://github.com/Genesis-Embodied-AI/Genesis.git
cd Genesis

# 安装依赖
pip install -r requirements.txt

# 安装 Genesis
pip install -e .

# 验证安装
python -c "import genesis; print('Genesis version:', genesis.__version__)"
```

#### 方式三：Docker 安装

```bash
# 构建镜像
docker build -t genesis-sim .

# 运行容器
docker run --gpus all -it --rm \
  -v $(pwd):/workspace \
  genesis-sim
```

| **GPU 并行** | 原生支持 | 支持 | 不支持 | 不支持 | 不支持 |
| **渲染质量** | 高 | 极高（RTX） | 中等 | 低 | 中等 |
| **安装难度** | 简单 | 复杂 | 简单 | 极简 | 中等 |
| **学习曲线** | 中等 | 陡峭 | 平缓 | 平缓 | 中等 |
| **柔体仿真** | 支持 | 支持 | 有限 | 不支持 | 不支持 |
| **流体仿真** | 支持 | 不支持 | 不支持 | 不支持 | 不支持 |
| **可微分仿真** | 支持 | 有限 | 不支持 | 不支持 | 不支持 |
| **ROS 集成** | 有限 | 有限 | 无 | 无 | 原生支持 |
| **社区规模** | 成长中 | 大 | 大 | 中 | 大 |
| **资源占用** | 中等 | 高 | 低 | 低 | 中等 |
| **开源协议** | MIT | EULA | Apache 2.0 | Zlib | Apache 2.0 |

### 3.2 性能对比

| 指标 | Genesis | Isaac Sim | MuJoCo | PyBullet |
|------|:---:|:---:|:---:|:---:|
| 单环境仿真速度 | 500-1000 Hz | 200-500 Hz | 2000-5000 Hz | 500-1000 Hz |
| 并行环境数 (RTX 4090) | ~10000 | ~8192 | ~100 (CPU) | ~100 (CPU) |
| 渲染 FPS | 60-120 | 30-60 | 30-60 | 30-60 |
| 内存/环境 | ~5MB | ~10MB | ~1MB | ~2MB |
| 启动时间 | ~3s | ~30s | ~1s | ~1s |

### 3.3 适用场景对比

| 场景 | 推荐仿真器 | 原因 |
|------|---------|------|
| 大规模 RL 训练 | Genesis / Isaac Sim | GPU 并行能力强 |
| 快速原型开发 | MuJoCo / PyBullet | 轻量、快速启动 |
| 高保真传感器模拟 | Isaac Sim | RTX 光线追踪渲染 |
| ROS 集成 | Gazebo | 原生 ROS 支持 |

| 可微分仿真 | Genesis | 原生可微分支持 |

| 合成数据生成 | Isaac Sim / Genesis | 高质量渲染 + 域随机化 |

## 4. 基本使用示例

### 4.1 创建场景与加载机器人

```python
# 文件: genesis_basic.py
import genesis as gs
import numpy as np

# 初始化
gs.init(backend=gs.gpu, logging_level="info")

# 创建场景
scene = gs.Scene(
    sim_options=gs.options.SimOptions(
        dt=0.01,           # 仿真步长
        substeps=2,        # 子步数
        gravity=(0, 0, -9.81),
    ),
    rendering_options=gs.options.RenderingOptions(
        shadow=False,
        plane_reflection=False,
    ),
    show_viewer=True,
    viewer_options=gs.options.ViewerOptions(
        camera_pos=(3, -1, 2),
        camera_lookat=(0, 0, 0.5),
        camera_fov=45,
    ),
)

# 添加地面
ground = scene.add_entity(gs.morphs.Plane())

# 添加 Franka 机械臂
franka = scene.add_entity(
    gs.morphs.URDF(
        file="urdf/franka_panda/panda.urdf",
        pos=(0, 0, 0),
        fixed=True,
    ),
)

# 添加一个可操作物体
cube = scene.add_entity(
    gs.morphs.Box(
        size=(0.05, 0.05, 0.05),
        pos=(0.5, 0, 0.1),
        rgba=(0.8, 0.2, 0.2, 1.0),
    ),
)

# 构建场景
scene.build()

# 获取机器人信息
print(f"关节数: {franka.n_dofs}")
print(f"关节名: {franka.dofs_names}")

# 设置控制模式
franka.set_dofs_kp(np.array([100] * franka.n_dofs))  # 位置控制
franka.set_dofs_kv(np.array([5] * franka.n_dofs))    # 阻尼

# 设置初始关节位置
home_pos = np.array([0, -0.5, 0, -2.5, 0, 2.0, 0.7, 0.0, 0.0])
franka.set_dofs_position(home_pos)

# 仿真循环
for i in range(2000):
    # PD 控制：保持初始位置
    target = home_pos.copy()
    franka.control_dofs_position(target)
    
    # 推进仿真
    scene.step()
    
    if i % 100 == 0:
        joint_pos = franka.get_dofs_position()
        cube_pos = cube.get_pos()
        print(f"Step {i}: Joint pos = {joint_pos[:3]}, Cube pos = {cube_pos}")
```

### 4.2 并行环境仿真

```python
# 文件: genesis_parallel.py
import genesis as gs
import numpy as np

gs.init(backend=gs.gpu)

# 创建多个并行场景
n_envs = 1000

scene = gs.Scene(
    sim_options=gs.options.SimOptions(
        dt=0.01,
        substeps=2,
    ),
    show_viewer=False,  # 无头模式
)

# 添加地面
scene.add_entity(gs.morphs.Plane())

# 添加多个机器人（向量化）
robots = []
for i in range(n_envs):
    robot = scene.add_entity(
        gs.morphs.URDF(
            file="urdf/franka_panda/panda.urdf",
            pos=(0, i * 2.0, 0),  # 错开排列
            fixed=True,
        ),
    )
    robots.append(robot)

# 构建场景
scene.build()

print(f"并行环境数: {n_envs}")
print(f"仿真开始...")

# 批量控制
for step in range(1000):
    for robot in robots:
        # 每个机器人执行不同的轨迹
        t = step * 0.01
        target = np.array([
            0.5 * np.sin(t + robot.idx * 0.1),
            -0.5,
            0,
            -2.5,
            0,
            2.0,
            0.7,
            0.0,
            0.0,
        ])
        robot.control_dofs_position(target)
    
    scene.step()
    
    if step % 100 == 0:
        print(f"Step {step}: FPS = {1.0 / scene.dt:.0f}")

print("仿真完成")
```

### 4.3 传感器与渲染

```python
# 文件: genesis_sensors.py
import genesis as gs
import numpy as np

gs.init(backend=gs.gpu)

# 创建带传感器的场景
scene = gs.Scene(
    sim_options=gs.options.SimOptions(dt=0.01),
    show_viewer=True,
)

ground = scene.add_entity(gs.morphs.Plane())

    pos=(1.5, -1.5, 1.5),
    lookat=(0, 0, 0.5),
    fov=45,
    resolution=(640, 480),
)

# 构建
scene.build()

# 仿真与渲染
for i in range(500):
    scene.step()
    
    if i % 10 == 0:
        # 获取 RGB 和深度图像

        # 保存图像
        if i == 100:
            import imageio
            imageio.imwrite("frame_rgb.png", rgb)
            imageio.imwrite("frame_depth.png", (depth * 1000).astype(np.uint16))
            print("图像已保存")
```

### 4.4 强化学习训练示例

```python
# 文件: genesis_rl.py
import genesis as gs
import numpy as np
import torch

gs.init(backend=gs.gpu)

# 自定义 RL 环境
class GenesisRLEnv:
    """Genesis 强化学习环境"""
    
    def __init__(self, n_envs=1000):
        self.n_envs = n_envs
        
        self.scene = gs.Scene(
            sim_options=gs.options.SimOptions(dt=0.01, substeps=2),
            show_viewer=False,
        )
        
        # 场景元素
        self.scene.add_entity(gs.morphs.Plane())
        
        self.robots = []
        for i in range(n_envs):
            robot = self.scene.add_entity(
                gs.morphs.URDF(
                    file="urdf/franka_panda/panda.urdf",
                    pos=(0, i * 2.0, 0),
                    fixed=True,
                ),
            )
            self.robots.append(robot)
        
        self.scene.build()
        
        # 获取维度信息
        self.obs_dim = 20  # 观测维度
        self.action_dim = 9  # 动作维度（7关节+2夹爪）
    
    def reset(self):
        """重置所有环境"""
        observations = []
        for robot in self.robots:
            robot.set_dofs_position(np.zeros(self.action_dim))
            obs = self._get_obs(robot)
            observations.append(obs)
        return np.array(observations)
    
    def step(self, actions):
        """执行一步"""
        for i, robot in enumerate(self.robots):
            robot.control_dofs_position(actions[i])
        
        self.scene.step()
        
        observations = []
        rewards = []
        dones = []
        
        for robot in self.robots:
            obs = self._get_obs(robot)
            reward = self._compute_reward(robot)
            done = self._check_done(robot)
            
            observations.append(obs)
            rewards.append(reward)
            dones.append(done)
        
        return (
            np.array(observations),
            np.array(rewards),
            np.array(dones),
            {},
        )
    
    def _get_obs(self, robot):
        """获取观测"""
        joint_pos = robot.get_dofs_position()
        joint_vel = robot.get_dofs_velocity()
        return np.concatenate([joint_pos, joint_vel])
    
    def _compute_reward(self, robot):
        """计算奖励"""
        # 简化：惩罚关节偏离目标
        target = np.zeros(self.action_dim)
        joint_pos = robot.get_dofs_position()
        return -np.sum((joint_pos - target) ** 2)
    
    def _check_done(self, robot):
        """检查是否结束"""
        return False


# 训练循环
env = GenesisRLEnv(n_envs=100)

obs = env.reset()
for episode in range(100):
    for step in range(200):
        # 随机动作（实际应使用策略网络）
        actions = np.random.uniform(-0.1, 0.1, (env.n_envs, env.action_dim))
        
        obs, rewards, dones, info = env.step(actions)
        
        if step % 50 == 0:
            print(f"Episode {episode}, Step {step}: avg_reward = {rewards.mean():.4f}")
    
    obs = env.reset()
```

### 4.5 柔体仿真示例

```python
# 文件: genesis_soft_body.py
import genesis as gs
import numpy as np

gs.init(backend=gs.gpu)

scene = gs.Scene(
    sim_options=gs.options.SimOptions(
        dt=0.005,
        substeps=4,
    ),
    show_viewer=True,
)

# 地面
scene.add_entity(gs.morphs.Plane())

# 添加柔体（可变形物体）
soft_cube = scene.add_entity(
    gs.morphs.SoftBox(
        size=(0.2, 0.2, 0.2),
        pos=(0, 0, 0.5),
        E=5e4,    # 杨氏模量
        nu=0.4,   # 泊松比
        rho=500,  # 密度
    ),
)

# 添加刚体对比
rigid_cube = scene.add_entity(
    gs.morphs.Box(
        size=(0.2, 0.2, 0.2),
        pos=(0.5, 0, 0.5),
        rgba=(0.2, 0.8, 0.2, 1.0),
    ),
)

scene.build()

for i in range(3000):
    scene.step()
    
    if i % 100 == 0:
        soft_pos = soft_cube.get_pos()
        rigid_pos = rigid_cube.get_pos()
        print(f"Step {i}: Soft = {soft_pos}, Rigid = {rigid_pos}")
```
