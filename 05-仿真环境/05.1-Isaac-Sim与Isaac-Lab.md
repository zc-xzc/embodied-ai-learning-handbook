## 1. Isaac Sim 概述与安装

### 1.1 什么是 Isaac Sim

NVIDIA Isaac Sim 是基于 Omniverse 平台构建的机器人仿真器，它利用 RTX 光线追踪技术提供高保真度的物理仿真和传感器模拟。Isaac Sim 的核心优势包括：

- **物理仿真**：基于 PhysX 5 的高精度刚体/柔体动力学
- **光线追踪渲染**：支持 RTX 光线追踪和路径追踪，生成照片级真实感图像
- **传感器模拟**：高保真相机、LiDAR、IMU、接触传感器
- **合成数据生成**：内置合成数据生成管线（SDG），支持域随机化
- **USD 格式**：使用 Universal Scene Description 作为场景描述标准
- **GPU 加速**：支持大规模并行仿真

### 1.2 系统要求

| 组件 | 最低要求 | 推荐配置 |
|------|---------|---------|
| GPU | RTX 2070 (8GB) | RTX 4090 (24GB+) |
| RAM | 32GB | 64GB+ |
| CPU | Intel i7-7700K | Intel i9-13900K |
| 存储 | 50GB SSD | 100GB NVMe SSD |
| OS | Ubuntu 22.04 / Windows 11 | Ubuntu 22.04 |
| Driver | NVIDIA 535+ | NVIDIA 550+ |

## 2. Isaac Lab 框架介绍

### 2.1 什么是 Isaac Lab

Isaac Lab（前身为 OmniIsaacGymEnvs）是基于 Isaac Sim 构建的统一机器人学习框架，由 NVIDIA 和 ETH Zurich 联合开发。它提供了：

- **模块化环境设计**：基于 Python 的环境配置系统
- **RL 训练集成**：原生支持 RSL-RL、SKRL、Stable Baselines3、RL-Games
- **多机器人支持**：内置 Franka、UR5e、Anymal、Unitree G1/H1 等机器人
- **大规模并行**：单 GPU 可运行数千个并行环境
- **域随机化**：内置物理参数和视觉域随机化工具

### 2.2 架构概览

```
┌─────────────────────────────────────────────┐
│              Isaac Lab 架构                  │
├─────────────────────────────────────────────┤
│  应用层: RL Training / Data Collection      │
├─────────────────────────────────────────────┤
│  管理器层:                                   │
│  ├── Scene Manager (场景管理)               │
│  ├── Robot Manager (机器人管理)              │
│  ├── Environment Manager (环境管理)          │
│  └── Sensor Manager (传感器管理)             │
├─────────────────────────────────────────────┤
│  核心层:                                     │
│  ├── EnvBase (环境基类)                     │
│  ├── RobotBase (机器人基类)                  │
│  ├── Articulation (关节体)                   │
│  └── SensorBase (传感器基类)                │
├─────────────────────────────────────────────┤
│  仿真层: Isaac Sim (PhysX 5 + RTX)          │
└─────────────────────────────────────────────┘
```

## 6. 与 LeRobot 集成

### 6.1 集成概述

Isaac Lab 可以作为 LeRobot 的数据采集后端，利用仿真环境生成大规模训练数据：

```python
# 文件: isaaclab_to_lerobot.py
"""Isaac Lab 仿真数据 -> LeRobot Dataset 转换"""

import numpy as np
import torch
from pathlib import Path
from lerobot.common.datasets.lerobot_dataset import LeRobotDataset

class IsaacLabToLeRobotConverter:
    """将 Isaac Lab 仿真轨迹转换为 LeRobot Dataset 格式"""
    
    def __init__(self, dataset_name: str, repo_id: str):
        self.dataset_name = dataset_name
        self.repo_id = repo_id
        self.episodes = []
    
    def collect_episode(
        self,
        env,
        policy,
        max_steps: int = 300,
        cameras: list[str] = None,
    ):
        """在 Isaac Lab 中收集一条轨迹"""
        obs_list = []
        action_list = []
        reward_list = []
        
        obs, _ = env.reset()
        
        for step in range(max_steps):
            # 获取策略动作
            with torch.no_grad():
                action = policy(obs)
            
            # 记录观测
            frame = {
                "observation.state": obs["policy"]["joint_pos"].cpu().numpy(),
                "action": action.cpu().numpy(),
            }
            
            # 添加相机图像
            if cameras:
                for cam_name in cameras:
                    cam_data = env.scene[cam_name].data
                    frame[f"observation.images.{cam_name}"] = cam_data.output["rgb"].cpu().numpy()
            
            obs_list.append(frame)
            
            # 执行动作
            obs, reward, done, info = env.step(action)
            reward_list.append(reward.cpu().numpy())
            
            if done.any():
                break
        
        return {
            "frames": obs_list,
            "rewards": reward_list,
            "num_steps": len(obs_list),
        }
    
    def save_to_lerobot(self, output_dir: str):
        """保存为 LeRobot Dataset 格式"""
        dataset = LeRobotDataset.create(
            repo_id=self.repo_id,
            fps=20,
            features={
                "observation.state": {
                    "dtype": "float32",
                    "shape": (7,),
                    "names": {"joints": ["joint_1", "joint_2", "joint_3", "joint_4", "joint_5", "joint_6", "gripper"]},
                },
                "observation.images.front": {
                    "dtype": "image",
                    "shape": (480, 640, 3),
                },
                "action": {
                    "dtype": "float32",
                    "shape": (7,),
                    "names": {"joints": ["joint_1", "joint_2", "joint_3", "joint_4", "joint_5", "joint_6", "gripper"]},
                },
            },
        )
        
        for episode in self.episodes:
            for frame in episode["frames"]:
                dataset.add_frame(frame)
            dataset.save_episode()
        
        dataset.save_to_disk(output_dir)
        print(f"数据集已保存到 {output_dir}")
```

### 8.4 常见版本兼容问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| `ModuleNotFoundError: No module named 'omni.isaac'` | 4.x 使用旧包名 | 改为 `isaacsim` 前缀 |
| `ImportError: cannot import name 'SimulationApp'` | pip 包版本不匹配 | 确认 Python 版本与 Isaac Sim 版本对应 |
| CUDA 版本冲突 | Driver 过旧 | 升级 GPU 驱动至要求版本 |
| USD 加载失败 | USD 版本变化 | 使用对应版本的 USD 工具 |
| `TiledCamera` 输出空图像 | RTX 未正确初始化 | 确保非无头模式或启用 Headless RTX |
