## 二、State of Robot Learning 2025 核心洞察

本节基于《State of Robot Learning, December 2025》报告（18658字符），提炼2025年机器人学习领域的关键发现与趋势。

### 2.1 2025年机器人学习技术栈剖析

**核心论断：截至2025年12月，几乎所有机器人学习系统都是纯行为克隆（BC，又称模仿学习）系统。**

BC的基本工作原理：
- 人类提供（近乎）最优的任务演示
- 机器学习模型以监督学习方式训练策略
- 输入：机器人状态（相机图像、关节角度、任务描述文本）
- 输出：预测演示动作（通常是action chunk，如50Hz下的下一秒动作）

报告强调，该文档关注的是**问题形式化和数据来源**，而非模型架构等看似不太重要的细节。这表明在2025年，数据质量和问题定义比模型结构更为关键。

**2025 BC技术栈的核心组成：**
1. 数据采集系统（人类专家演示）
2. 策略模型（通常基于VLM骨干网络）
3. DAgger数据处理流程（处理OOD状态）
4. 评估系统

### 2.2 数据采集方式深度对比

报告详细对比了三种主要数据采集方式：

#### 方式一：Leader-Follower（GELLO, ALOHA）

人类使用控制器（leader）直接遥操作完整的机器人（follower）。

| 维度 | 评价 |
|------|------|
| **优点** | Follower机器人具备完整传感器套件可记录所有数据；所有演示在运动学上是可行的（因为在真实机器人上执行） |
| **缺点** | 通常比人类直接用手操作慢10倍；操作员需要数周练习才能达到可用水平；需要完整机器人在现场——显著的生产和资本要求 |
| **代表系统** | ALOHA（完整机器人副本）、GELLO（缩小轻量版） |

#### 方式二：智能演示手套（Universal Manipulation Interface, UMI）

人类手持设备（如UMI）执行任务，设备的末端执行器与机器人匹配。

| 维度 | 评价 |
|------|------|
| **优点** | 操作员学习更快；演示速度更快；大规模部署更便宜（如Generalist、Sunday） |
| **缺点** | 对本体感知和动作的重建有噪声，引入domain gap；需要从SLAM估计推断本体感知和动作；相机图像中显示人类手臂持设备，但推理时机器人看到的是机器人手臂；不保证运动学可行性 |
| **代表系统** | Universal Manipulation Interface (UMI) |

#### 方式三：直接人类演示（YouTube等视频源）

利用YouTube等大规模视频数据和工厂中人类执行灵巧任务的录制。

| 维度 | 评价 |
|------|------|
| **优点** | 最容易获取的数据源；海量多样化数据；全人类速度 |
| **缺点** | 重建本体感知和动作的gap巨大；状态可能非第一人称视角；动作必须完全从原始数据推断（通过伪标签过程，如骨架追踪器/人手追踪器）；轨迹可能不具备运动学可行性 |
| **适用场景** | 大规模预训练数据来源 |

**关键洞察：** 数据采集方式的选择直接影响策略性能。Leader-Follower提供最干净的数据但最慢最贵；直接人类演示最便宜最丰富但数据质量最低；UMI在中间取得了平衡。

### 2.3 OOD问题的核心挑战

**行为克隆的硬核问题：分布外（OOD）状态**

即使拥有极其干净的演示数据，BC策略仍然会游走到分布外状态。报告列举了三个根本原因：

1. **世界永远不会完美匹配训练数据**：即使在同一工位，光照、背景场景或其他干扰因素的微小变化都会改变状态信息，进而影响动作预测

2. **下一步该做什么存在固有不确定性**：这部分源于状态的部分可观察性（如无法看到皱褶衬衫内部的折叠），以及演示者动作分布的固有的多模态性

3. **模型在动作上有预测误差**：由于模型在顺序决策中，当前动作影响下一状态，误差会递归地在展开过程中复合累积

**关键洞察：** 报告指出，虽然VLM的强视觉先验可以帮助模型泛化到新状态，但仍然存在模型失败的场景。数据分布比建模选择更重要——你需要数据驱动的先验和能处理动作多模态的模型类，但模型训练的数据分布似乎更为关键。

### 2.4 DAgger解决方案

**核心思路：不要只在专家人类数据上简单训练！**

DAgger（Dataset Aggregation）方法的关键要点：

1. **训练模型如何逃离失败状态**：除了直接的任务演示外，关键是要训练模型如何从失败状态中恢复

2. **数据构建的微妙之处**：
   - 你希望训练模型**离开**这些坏状态
   - 但你**不希望**意外训练模型**进入**这些坏状态
   - 否则模型会模仿这些数据并故意访问坏状态
   - 正确做法：仔细策划恢复数据

3. **迭代过程**：
   - 训练模型 → 观察失败模式 → 构建新数据集解决失败 → 重训练 → 重试
   - 这是一个繁琐的过程，需要大量聪明且有判断力的人类时间来"打地鼠"
   - 通常作为预训练策略之上的后训练步骤

4. **挑战**：
   - 基础策略的重新预训练可能完全抹去你在任务迭代中积累的"感觉"
   - 评估耗时随策略改进而增加：如果策略每15秒失败，几分钟评估即可获得信号；如果策略数分钟至数小时才失败，则需要大量评估时间
   - 离线指标（如验证MSE）与真实机器人性能的相关性很差

**关键洞察：** 通过充分的DAgger数据迭代，策略可以变得惊人地鲁棒。但这是一种"艺术"，需要人类的品味和判断力。

### 2.5 RL在机器人学习中的前景与挑战

**理想愿景：自改进的机器人系统**
- 自主收集数据以学习和改进
- 陷入坏状态时能通过探索逃离，并自动学会避免该状态
- 能自动变快，在其具身体上达到超人类表现

**RL在LLM中成功但难以移植到机器人的原因：**

| 维度 | LLM | 机器人 |
|------|-----|--------|
| 状态复制 | 可从相同状态无限次展开 | 无法轻松完美复制杂乱厨房数百次 |
| 基础策略 | 非常强的基础策略 | 基础模型不够强，无法可靠完成任务 |
| 探索 | 可从相同状态展开数千次探索 | 无法从真实状态多次展开 |

**三种RL路径分析：**

1. **RL in Sim（仿真中RL）**
   - 优势：可可靠重建任意多次
   - 挑战：sim-to-real gap巨大——模拟器物理模型简陋、多体碰撞数值估计差、接触模型有取舍、非刚体建模差、视觉差距大
   - Domain randomization有帮助，但除locomotion外成功有限
   - World models（学习型模拟器）是希望所在

2. **RL in Real（真实世界RL）**
   - 优势：避免sim-to-real gap
   - 挑战：需要回答反事实问题（无法从相同状态多次展开）
   - 需要Q函数或V函数——本质上都是world model的变体
   - Physical Intelligence的π0.6展示了minor改进，但不是银弹

3. **World Models（世界模型）**
   - 不需要知道最优动作，只需模拟给定状态和动作的动力学
   - 任何状态-动作转换数据（无论来自最优还是随机策略）都应有助于学习通用动力学
   - 截至2025年12月，尚无接近良好建模灵巧操作环境交互动力学的工作

### 2.6 未来预测与建议

报告给出了以下预测：

| 时间框架 | 预测 |
|---------|------|
| 2年内 | VLA将被视频模型骨干网络取代 |
| 10年内 | World models将能很好模拟通用开放世界交互，策略提取将作为策略训练的一部分 |
| 长期 | 传统模拟器/游戏引擎将成为World Models的数据生成器，但本质上是端到端学习的 |
| 持续重要 | （近乎）专家数据采集仍将重要，用于微调world models |
| 持续重要 | 真实机器人真实世界展开仍将重要，用于达到超人类表现 |

**对"镐和铲"（picks and shovels）创业者的建议：**

1. **数据标注是商品**：本质上是人力套利，不是技术活——需要out-operate Scale AI
2. **预训练数据销售也是运营活**：需要证明数据确实有助于客户模型性能
3. **评估是瓶颈但不能外包**：对模型改进循环太重要，必须in-house
4. **数据平台不是one-size-fits-all**：连自动驾驶领域（传感器大致相同、解决相同问题）都没有统一平台，具身AGI更不会有
5. **唯一坚实的基础：人类演示将继续重要**——如果你构建了减少上述痛点的硬件+软件演示栈（GELLO或UMI），并能展示产出好策略，你将是吸引人的商业伙伴甚至收购目标

## 四、对学习者的建议

### 4.1 系统性学习路径设计

基于以上三大资源，建议按以下五阶段路径进行系统性学习：

**第一阶段：建立认知框架（1-2周）**
1. 精读《State of Robot Learning, December 2025》报告全文
2. 理解BC技术栈、数据采集方式、OOD挑战等核心概念
3. 浏览RoboScholar的"TO READ"清单，了解领域经典论文
4. 阅读awesome-embodied-vla-va-vln中的Survey分类论文

**第二阶段：核心论文阅读（2-4周）**
1. 从awesome-embodied-vla-va-vln中阅读VLA基础论文：OpenVLA、π0、Gemini Robotics
2. 从Awesome-LLM-Robotics中阅读Reasoning和Planning分类的奠基论文
3. 从Paper-List中阅读Robot Foundation Models分类
4. 从Embodied-AI-Paper-TopConf中浏览CVPR 2025和CoRL 2024的VLA论文

**第三阶段：深入特定方向（4-8周）**
根据个人兴趣选择1-2个方向深入：
- **VLA方向**: awesome-embodied-vla-va-vln + Awesome-RL-VLA
- **操作方向**: Awesome-Affordance-Learning + awesome-humanoid-robot-learning
- **视频学习方向**: Awesome-Video-Robotic-Papers
- **LLM+机器人方向**: Awesome-LLM-Robotics + Awesome-Embodied-Robotics-and-Agent

**第四阶段：前沿跟进（持续）**
1. 定期检查Embodied-AI-Paper-TopConf的最新会议更新
2. 关注awesome-embodied-vla-va-vln的最新论文
3. 浏览Paper-List的"Recent Random Papers"
4. 关注Physical Intelligence、Google DeepMind、NVIDIA等关键团队的最新发布

**第五阶段：实践与社区（持续）**
1. 关注本图谱中标注的重点实验室的论文发布
2. 参与awesome仓库的社区贡献（提交PR补充论文）
