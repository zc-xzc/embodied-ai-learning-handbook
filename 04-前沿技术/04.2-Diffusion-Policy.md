# Diffusion Policy

> 本文件详解 Diffusion Policy 的核心思想、与标准扩散模型的区别、动作序列生成、视觉条件扩散、DP3 (3D Diffusion Policy)，以及使用 diffusion_policy 库训练的实践。

---

## 一、Diffusion Policy 核心思想

### 1.1 从图像生成到动作生成

```
标准扩散模型（图像生成）：
  噪声 → [去噪网络] → 图像
  
Diffusion Policy（动作生成）：
  噪声 → [去噪网络（条件=观测）] → 动作序列

核心创新：
  将扩散模型从"生成图像"迁移到"生成机器人动作"

为什么用扩散模型生成动作？
  1. 多模态分布：同一观测可能有多种合理动作
  2. 序列生成：一次生成多步动作（action chunking）
  3. 训练稳定：扩散模型训练比 GAN 稳定
  4. 灵活条件：可以加入各种条件信息
```

### 1.2 Diffusion Policy 工作流程

```python
"""
Diffusion Policy 推理流程

输入：
  1. 当前观测（图像 + 本体感知）
  2. 随机噪声（与动作序列同维度）

过程：
  1. 将观测编码为条件特征
  2. 从纯噪声开始
  3. 迭代去噪 T 次（条件 = 观测特征）
  4. 得到动作序列

输出：
  动作序列 (horizon, action_dim)
  执行前 k 步（receding horizon）
"""
```

## 二、与标准扩散模型的区别

```
标准扩散模型 vs Diffusion Policy

| 维度 | 标准扩散模型 | Diffusion Policy |
|------|-------------|------------------|
| 生成目标 | 图像/音频 | 机器人动作序列 |
| 数据维度 | 高（像素级） | 低（7-30维） |
| 条件 | 类别/文本 | 观测（图像+状态） |
| 去噪网络 | U-Net | U-Net / Transformer |
| 采样步数 | 50-1000 | 10-100 |
| 时间维度 | 无 | 有（动作序列） |
| 执行方式 | 一次性 | Receding horizon |
```

### 2.1 关键区别详解

```python
"""
1. 数据维度不同
   图像扩散：生成 (H, W, C) 高维数据
   动作扩散：生成 (horizon, action_dim) 低维数据
   
   影响：
   - 去噪网络更简单（不需要大 U-Net）
   - 采样更快
   - 可以用 Transformer 代替 U-Net

2. 时间序列结构
   图像扩散：像素间空间关系
   动作扩散：时间步间时序关系
   
   影响：
   - 需要建模时序依赖
   - Action Chunking 减少决策频率

3. 条件方式
   图像扩散：文本/类别（全局条件）
   动作扩散：观测（图像+状态，丰富的条件）
   
   影响：
   - 需要高效的条件注入
   - 视觉条件尤为关键
"""
```

## 三、动作序列生成

### 3.1 动作序列扩散

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math

class DiffusionPolicy(nn.Module):
    """
    Diffusion Policy 完整实现
    
    与 02.3 中的简化版不同，这里包含更完整的细节
    """
    def __init__(self, obs_dim, action_dim, horizon=16,
                 n_obs_steps=2, n_action_steps=8,
                 num_diffusion_steps=100,
                 embed_dim=256, num_heads=4, num_layers=3):
        super().__init__()
        self.action_dim = action_dim
        self.horizon = horizon
        self.n_obs_steps = n_obs_steps
        self.n_action_steps = n_action_steps
        self.num_diffusion_steps = num_diffusion_steps
        
        # 观测编码器
        self.obs_encoder = nn.GRU(obs_dim, embed_dim, batch_first=True)
        
        # 时间步嵌入
        self.time_mlp = nn.Sequential(
            SinusoidalPosEmb(embed_dim),
            nn.Linear(embed_dim, embed_dim * 2),
            nn.Mish(),
            nn.Linear(embed_dim * 2, embed_dim),
        )
        
        # 条件投影
        self.cond_proj = nn.Linear(embed_dim, embed_dim)
        
        # 去噪网络（1D U-Net 简化版）
        self.denoise_net = ConditionalUNet1D(
            action_dim=action_dim,
            horizon=horizon,
            embed_dim=embed_dim,
        )
        
        # 噪声调度
        betas = torch.linspace(1e-4, 0.02, num_diffusion_steps)
        alphas = 1.0 - betas
        alphas_cumprod = torch.cumprod(alphas, dim=0)
        
        self.register_buffer('betas', betas)
        self.register_buffer('alphas_cumprod', alphas_cumprod)
    
    def compute_loss(self, actions, obs_seq):
        """训练损失"""
        B = actions.shape[0]
        
        # 编码观测序列
        obs_embed, _ = self.obs_encoder(obs_seq)  # (B, T_obs, embed_dim)
        cond = obs_embed[:, -1, :]  # 取最后一个观测的特征
        
        # 随机时间步
        t = torch.randint(0, self.num_diffusion_steps, (B,), device=actions.device)
        
        # 随机噪声
        noise = torch.randn_like(actions)
        
        # 前向加噪
        sqrt_alpha = torch.sqrt(self.alphas_cumprod[t]).view(B, 1, 1)
        sqrt_one_minus = torch.sqrt(1 - self.alphas_cumprod[t]).view(B, 1, 1)
        x_t = sqrt_alpha * actions + sqrt_one_minus * noise
        
        # 预测噪声
        time_embed = self.time_mlp(t)
        cond_embed = self.cond_proj(cond)
        
        predicted_noise = self.denoise_net(x_t, time_embed, cond_embed)
        
        # MSE 损失
        loss = F.mse_loss(predicted_noise, noise)
        return loss
    
    def sample(self, obs_seq, num_inference_steps=None):
        """推理：生成动作序列"""
        num_inference_steps = num_inference_steps or self.num_diffusion_steps
        B = obs_seq.shape[0]
        device = obs_seq.device
        
        # 编码观测
        obs_embed, _ = self.obs_encoder(obs_seq)
        cond = obs_embed[:, -1, :]
        cond_embed = self.cond_proj(cond)
        
        # 选择时间步子序列
        step_ratio = self.num_diffusion_steps // num_inference_steps
        timesteps = list(range(0, self.num_diffusion_steps, step_ratio))
        timesteps = list(reversed(timesteps))
        
        # 从噪声开始
        x = torch.randn(B, self.horizon, self.action_dim, device=device)
        
        # DDIM 去噪
        for t in timesteps:
            t_tensor = torch.full((B,), t, device=device)
            time_embed = self.time_mlp(t_tensor)
            
            predicted_noise = self.denoise_net(x, time_embed, cond_embed)
            
            # DDIM 更新
            alpha_t = self.alphas_cumprod[t]
            x0_pred = (x - torch.sqrt(1 - alpha_t) * predicted_noise) / torch.sqrt(alpha_t)
            x = torch.sqrt(alpha_t) * x0_pred + torch.sqrt(1 - alpha_t) * predicted_noise
        
        return x  # (B, horizon, action_dim)


class SinusoidalPosEmb(nn.Module):
    """正弦时间步嵌入"""
    def __init__(self, dim):
        super().__init__()
        self.dim = dim
    
    def forward(self, t):
        half = self.dim // 2
        emb = math.log(10000) / (half - 1)
        emb = torch.exp(torch.arange(half, device=t.device) * -emb)
        emb = t[:, None] * emb[None, :]
        emb = torch.cat([emb.sin(), emb.cos()], dim=-1)
        return emb


class ConditionalUNet1D(nn.Module):
    """简化的条件 1D U-Net"""
    def __init__(self, action_dim, horizon, embed_dim):
        super().__init__()
        input_dim = action_dim + embed_dim * 2  # action + time + cond
        
        self.down1 = nn.Conv1d(input_dim, embed_dim, 3, padding=1)
        self.down2 = nn.Conv1d(embed_dim, embed_dim * 2, 3, padding=1)
        
        self.mid = nn.Conv1d(embed_dim * 2, embed_dim * 2, 3, padding=1)
        
        self.up1 = nn.Conv1d(embed_dim * 4, embed_dim, 3, padding=1)
        self.up2 = nn.Conv1d(embed_dim * 2, embed_dim, 3, padding=1)
        
        self.out = nn.Conv1d(embed_dim, action_dim, 1)
    
    def forward(self, x, time_embed, cond_embed):
        B, H, A = x.shape
        
        # 扩展条件到序列长度
        time_expanded = time_embed.unsqueeze(1).expand(-1, H, -1)
        cond_expanded = cond_embed.unsqueeze(1).expand(-1, H, -1)
        
        # 拼接
        x_in = torch.cat([x, time_expanded, cond_expanded], dim=-1)  # (B, H, A+2E)
        x_in = x_in.transpose(1, 2)  # (B, C, H) for Conv1d
        
        # 下采样
        h1 = F.relu(self.down1(x_in))
        h2 = F.relu(self.down2(h1))
        
        # 中间
        h = F.relu(self.mid(h2))
        
        # 上采样 + skip connection
        h = F.relu(self.up1(torch.cat([h, h2], dim=1)))
        h = F.relu(self.up2(torch.cat([h, h1], dim=1)))
        
        out = self.out(h)
        return out.transpose(1, 2)  # (B, H, A)


# 测试
policy = DiffusionPolicy(
    obs_dim=14, action_dim=7, horizon=16,
    n_obs_steps=2, n_action_steps=8,
    num_diffusion_steps=100
)

# 训练
obs_seq = torch.randn(8, 2, 14)   # (batch, obs_steps, obs_dim)
actions = torch.randn(8, 16, 7)   # (batch, horizon, action_dim)
loss = policy.compute_loss(actions, obs_seq)
print(f"训练损失: {loss.item():.4f}")

# 推理
sampled = policy.sample(obs_seq, num_inference_steps=20)
print(f"采样动作: {sampled.shape}")
```

### 4.1 视觉条件注入

"""
Diffusion Policy 中的视觉条件

方式1：视觉特征作为全局条件
  image → CNN/ViT → 全局特征 → 拼接到去噪网络输入

### 4.2 带视觉条件的 Diffusion Policy

```python
class VisionConditionedDiffusionPolicy(nn.Module):
    """带视觉条件的 Diffusion Policy"""
    def __init__(self, image_encoder, policy):
        super().__init__()
        self.image_encoder = image_encoder  # 预训练 CLIP/DINOv2
        self.policy = policy
        
        # 将视觉特征投影到条件空间
        self.vision_proj = nn.Linear(768, 256)  # CLIP 768 → embed 256
    
    def forward(self, images, obs_seq, actions=None):
        # 编码图像
        with torch.no_grad():
            visual_features = self.image_encoder(images)  # (B, 768)
        
        # 投影
        visual_cond = self.vision_proj(visual_features)  # (B, 256)
        
        # 将视觉条件加入观测序列
        visual_cond_expanded = visual_cond.unsqueeze(1)  # (B, 1, 256)
        # 拼接到观测序列
        enhanced_obs = torch.cat([obs_seq, visual_cond_expanded], dim=1)
        
        if actions is not None:
            loss = self.policy.compute_loss(actions, enhanced_obs)
            return loss
        else:
            sampled = self.policy.sample(enhanced_obs)
            return sampled
```

class SimplePointNet(nn.Module):
    """简化版 PointNet"""
    def __init__(self, in_dim=3, feat_dim=256):
        super().__init__()
        self.mlp = nn.Sequential(
            nn.Linear(in_dim, 64),
            nn.ReLU(),
            nn.Linear(64, 128),
            nn.ReLU(),
            nn.Linear(128, feat_dim),
        )
        self.max_pool = nn.AdaptiveMaxPool1d(1)
    
    def forward(self, x):
        """
        x: (B, N, in_dim) 点云
        return: (B, feat_dim) 全局特征
        """
        B, N, _ = x.shape
        features = self.mlp(x)  # (B, N, feat_dim)
        features = features.transpose(1, 2)  # (B, feat_dim, N)
        global_feat = self.max_pool(features).squeeze(-1)  # (B, feat_dim)
        return global_feat
