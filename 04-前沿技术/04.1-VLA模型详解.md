# VLA 模型详解

> 本文件详解 VLA（Vision-Language-Action）模型的发展、架构分析、动作空间设计、训练方法，以及 OpenVLA、GR00T、π0 的深度分析和评测 benchmark。

## 一、VLA 模型发展历程

### 1.1 从 RT-1 到 GR00T

```
VLA 模型发展脉络：

RT-1 (2022, Google)
  ├── 首个大规模 Transformer 机器人策略
  ├── 将动作离散化为 token
  └── 在真实机器人上工作

RT-2 (2023, Google)
  ├── 将 VLM（PaLI-X）转化为 VLA
  ├── 动作 token 复用语言 token 空间
  └── 继承了 VLM 的语义理解能力

OpenVLA (2024, Stanford)
  ├── 开源 7B VLA 模型
  ├── 基于 Prismatic VLM（SigLIP + LLaMA 2）
  └── 在 Open X-Embodiment 上训练

π0 (Pi-0) (2024, Physical Intelligence)
  ├── 流匹配（Flow Matching）生成动作
  ├── 3B 参数，通用操作策略
  └── 支持 5 种机器人平台

GR00T N1/N1.5/N1.6 (2025, NVIDIA)
  ├── 人形机器人基础模型
  ├── 支持 Isaac Lab 仿真
  └── 视频-动作-语言三模态
```

| 模型 | 参数量 | 视觉编码器 | LLM 骨干 | 动作输出 | 开源 |

## 三、动作空间设计

### 3.1 离散 token（RT-1, RT-2, OpenVLA）

```python
"""
将连续动作离散化为 token

方法：
  每个动作维度离散化为 256 个 bin
  7 维动作 → 7 个 token
  
  action = [0.1, -0.3, 0.5, 0.0, 0.0, 0.0, 1.0]
  → tokens = [128, 89, 191, 128, 128, 128, 255]

优点：
  - 可以直接用 LLM 的 token 预测头
  - 复用语言模型的训练方法
  - 表达能力足够

缺点：
  - 离散化损失
  - 推理时需要逐 token 生成（慢）
"""
class ActionTokenizer:
    """动作离散化/反离散化"""
    def __init__(self, action_dim=7, num_bins=256, 
                 action_min=-1.0, action_max=1.0):
        self.action_dim = action_dim
        self.num_bins = num_bins
        self.min = action_min
        self.max = action_max
    
    def encode(self, action):
        """连续动作 → token ids"""
        # 归一化到 [0, num_bins-1]
        normalized = (action - self.min) / (self.max - self.min)
        binned = np.clip((normalized * (self.num_bins - 1)).astype(int), 0, self.num_bins - 1)
        return binned.tolist()
    
    def decode(self, tokens):
        """token ids → 连续动作"""
        normalized = np.array(tokens) / (self.num_bins - 1)
        action = normalized * (self.max - self.min) + self.min
        return action

# 使用
tokenizer = ActionTokenizer(action_dim=7, num_bins=256)
action = np.array([0.1, -0.3, 0.5, 0.0, 0.0, 0.0, 1.0])
tokens = tokenizer.encode(action)
reconstructed = tokenizer.decode(tokens)
print(f"原始动作: {action}")
print(f"Token IDs: {tokens}")
print(f"重建动作: {np.round(reconstructed, 4)}")
print(f"重建误差: {np.max(np.abs(action - reconstructed)):.6f}")
```

### 3.2 连续输出（Octo）

```python
"""
直接输出连续动作值

方法：
  LLM 隐藏状态 → MLP → 连续动作值

优点：
  - 无离散化损失
  - 推理更快（一次前向传播）
  - 更精确

缺点：
  - 需要单独的动作头
  - 不能直接复用 LM 的训练方法
"""

class ContinuousActionHead(nn.Module):
    """连续动作头"""
    def __init__(self, hidden_dim=4096, action_dim=7):
        super().__init__()
        self.mlp = nn.Sequential(
            nn.Linear(hidden_dim, 256),
            nn.ReLU(),
            nn.Linear(256, action_dim),
            nn.Tanh()  # [-1, 1]
        )
    
    def forward(self, hidden_states):
        """取最后一个 token 的隐藏状态"""
        return self.mlp(hidden_states[:, -1, :])
```

### 3.3 流匹配（π0）

```python
"""
流匹配（Flow Matching）：
  π0 使用的技术，类似扩散但更高效

原理：
  学习从噪声分布到动作分布的"流"
  通过 ODE 求解器生成动作

优势：
  - 比扩散模型采样更快
  - 能建模多模态分布
  - 训练稳定

过程：
  1. 从噪声 z_0 采样
  2. 学习速度场 v(z_t, t, condition)
  3. 通过 ODE: dz/dt = v(z_t, t, condition) 生成动作
"""
```

## 四、训练方法

### 4.1 SFT（监督微调）

```python
"""
VLA 的 SFT 流程

1. 准备数据
   (image, instruction, action) 三元组
   
2. 处理输入
   image → 视觉 token
   instruction → 文本 token
   拼接：[视觉 token] + [文本 token] + [action token]

3. 训练目标
   预测 action token（交叉熵损失）
   或回归 action（MSE 损失）

4. 训练方式
   - 全量微调
   - LoRA 微调
   - 冻结视觉+LLM，只训练动作头
"""
```

### 4.2 RLHF（强化学习人类反馈）

```python
"""
RLHF 在 VLA 中的应用

1. SFT：先用 BC 数据训练
2. 奖励模型：训练一个判断动作好坏的模型
3. RL 微调：用 PPO 等算法优化策略

挑战：
  - 机器人 RL 的奖励设计困难
  - 在线交互成本高
  - 安全性问题
"""
```

### 4.3 流匹配训练

```python
"""
流匹配训练（π0）

训练目标：
  最小化预测速度场与真实速度场的差异

z_t = (1-t) * noise + t * action  (线性插值)
v_target = action - noise  (目标速度)

loss = ||v_pred(z_t, t, condition) - v_target||²
"""
```

## 五、OpenVLA 详细分析

### 5.1 架构详解

```python
"""
OpenVLA 架构

1. 视觉编码器：SigLIP（冻结）
   输入：224x224 RGB 图像
   输出：视觉 token（通常 256 个 patch token + 1 个 CLS token）

2. 投影层：MLP
   将视觉特征投影到 LLM 嵌入空间
   vision_dim (768) → lang_dim (4096)

3. LLM 骨干：LLaMA 2 7B
   输入：[视觉 token] + [本体感知 token] + [指令 token]
   输出：隐藏状态

4. 动作头：LM Head（复用）
   将隐藏状态映射为 action token（256 个类别 × 7 维）
   
训练数据：Open X-Embodiment（970K episodes）
训练方式：LoRA 微调（r=64）
"""

# OpenVLA 推理示例
def openvla_inference_example():
    """
    OpenVLA 推理代码示例
    """
    from transformers import AutoModelForVision2Seq, AutoProcessor
    from PIL import Image
    import torch
    
    # 加载模型
    processor = AutoProcessor.from_pretrained(
        "openvla/openvla-7b",
        trust_remote_code=True
    )
    model = AutoModelForVision2Seq.from_pretrained(
        "openvla/openvla-7b",
        trust_remote_code=True,
        torch_dtype=torch.bfloat16,
        low_cpu_mem_usage=True,
    ).to("cuda:0")
    
    # 准备输入
    image = Image.open("robot_scene.jpg")
    prompt = "In: What action should the robot take to pick up the red block?\nOut:"
    
    inputs = processor(prompt, image).to("cuda:0", dtype=torch.bfloat16)
    
    # 推理
    action = model.predict_action(
        **inputs,
        unnorm_key="bridge_orig",  # 数据集归一化键
        do_sample=False
    )
    
    # action 是 7 维向量
    # [dx, dy, dz, droll, dpitch, dyaw, gripper]
    return action
```

### 8.2 评测代码框架

```python
class VLAEvaluator:
    """VLA 模型评测框架"""
    def __init__(self, model, processor, env):
        self.model = model
        self.processor = processor
        self.env = env
    
    def evaluate_task(self, instruction, num_episodes=20, max_steps=200):
        """评测单个任务"""
        successes = 0
        step_counts = []
        
        for ep in range(num_episodes):
            obs = self.env.reset()
            done = False
            steps = 0
            
            while not done and steps < max_steps:
                # 获取当前帧
                image = self.env.render()
                
                # VLA 预测
                prompt = f"In: What action should the robot take to {instruction}?\nOut:"
                inputs = self.processor(prompt, image).to("cuda")
                action = self.model.predict_action(**inputs, do_sample=False)
                
                # 执行
                obs, _, done, info = self.env.step(action)
                steps += 1
            
            if info.get("success"):
                successes += 1
                step_counts.append(steps)
        
        return {
            "task": instruction,
            "success_rate": successes / num_episodes,
            "avg_steps": np.mean(step_counts) if step_counts else max_steps,
            "num_episodes": num_episodes,
        }
    
    def evaluate_suite(self, tasks):
        """评测任务套件"""
        results = []
        for task in tasks:
            result = self.evaluate_task(task)
            results.append(result)
            print(f"  {task}: {result['success_rate']:.1%}")
        
        avg_success = np.mean([r["success_rate"] for r in results])
        print(f"\n平均成功率: {avg_success:.1%}")
        return results
```
