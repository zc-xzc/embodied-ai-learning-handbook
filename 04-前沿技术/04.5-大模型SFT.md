## 1. 监督微调基础

### 1.1 什么是监督微调（SFT）

监督微调（Supervised Fine-Tuning, SFT）是指在预训练模型的基础上，使用带标注的数据集进行有监督的训练，使模型学会特定任务或遵循指令。在具身智能领域，SFT是将通用大模型适配为机器人控制策略的关键步骤。

**SFT在具身智能中的角色：**

```
预训练阶段（大量数据）     →    SFT阶段（高质量数据）    →    RLHF/部署阶段
┌─────────────────────┐    ┌─────────────────────┐    ┌──────────────────┐
│  LLM/VLM 预训练      │    │  机器人示教数据微调   │    │  真机部署/在线学习 │
│  - 互联网文本/图像    │ →  │  - (视觉, 语言, 动作) │ →  │  - 持续优化       │
│  - 学习通用表示       │    │  - 学习任务特定行为   │    │  - 安全约束       │
└─────────────────────┘    └─────────────────────┘    └──────────────────┘
```

### 1.2 SFT的数学 formulation

给定预训练模型参数 $\theta_{pre}$，SFT通过最小化以下损失函数来更新参数：

$$\mathcal{L}_{SFT}(\theta) = -\frac{1}{N}\sum_{i=1}^{N}\sum_{t=1}^{T_i} \log p_\theta(a_{i,t} | o_{i,t}, l_i, a_{i,<t})$$

其中：
- $N$ 是样本数量
- $T_i$ 是第 $i$ 个轨迹的长度
- $a_{i,t}$ 是第 $i$ 个轨迹第 $t$ 步的动作
- $o_{i,t}$ 是对应的视觉观测
- $l_i$ 是语言指令
- $a_{i,<t}$ 是之前的动作历史

### 1.3 SFT vs 预训练 vs RLHF

| 特性 | 预训练 | SFT | RLHF |
|------|--------|-----|------|
| 数据类型 | 无标注 | 有标注（示教） | 偏好数据 |
| 数据量 | 极大（TB级） | 中等（GB级） | 小（MB级） |
| 目标 | 学习通用表示 | 学习特定任务 | 对齐人类偏好 |
| 计算成本 | 极高 | 中等 | 较高 |
| 在具身智能中 | VLA骨干预训练 | 动作策略学习 | 安全性/效率优化 |

## 3. LoRA原理与实现

### 3.1 LoRA核心思想

LoRA（Low-Rank Adaptation）假设模型权重的更新具有低秩特性，即 $\Delta W$ 可以分解为两个小矩阵的乘积：

$$W' = W + \Delta W = W + BA$$

其中：
- $W \in \mathbb{R}^{d \times k}$ 是原始权重（冻结）
- $B \in \mathbb{R}^{d \times r}$，$A \in \mathbb{R}^{r \times k}$ 是可训练矩阵
- $r \ll \min(d, k)$ 是秩（rank）

```
原始前向传播:         LoRA前向传播:
                     ┌──────────────┐
x ──→ [W] ──→ y      x ──→ [W] ──────────────────→ y
                     │                         │(+)
                     └─→ [A: r×k] → [B: d×r] ──┘
                         (可训练)   (可训练)
                     
参数量: d×k           参数量: r×(d+k) << d×k
```

### 3.2 LoRA的数学细节

**初始化策略：**
- $A$ 使用高斯随机初始化
- $B$ 初始化为零矩阵
- 这样初始时 $\Delta W = BA = 0$，模型初始行为与预训练一致

**缩放因子：**
$$h = Wx + \frac{\alpha}{r} BAx$$

其中 $\alpha$ 是缩放超参数，通常 $\alpha = 2r$ 或 $\alpha = r$。

```python
import torch
import torch.nn as nn
import math

class LoRALinear(nn.Module):
    """LoRA线性层的完整实现"""
    
    def __init__(self, in_features, out_features, r=8, alpha=16, dropout=0.0):
        """
        Args:
            in_features: 输入维度
            out_features: 输出维度
            r: LoRA秩
            alpha: 缩放因子
            dropout: dropout概率
        """
        super().__init__()
        
        self.in_features = in_features
        self.out_features = out_features
        self.r = r
        self.alpha = alpha
        self.scaling = alpha / r  # 缩放因子
        
        # 原始权重（冻结）
        self.weight = nn.Parameter(
            torch.zeros(out_features, in_features), requires_grad=False
        )
        self.bias = nn.Parameter(
            torch.zeros(out_features), requires_grad=False
        )
        
        # LoRA参数
        # A: 降维矩阵 (r, in_features)
        self.lora_A = nn.Parameter(torch.zeros(r, in_features))
        # B: 升维矩阵 (out_features, r)
        self.lora_B = nn.Parameter(torch.zeros(out_features, r))
        
        # Dropout
        self.dropout = nn.Dropout(dropout) if dropout > 0 else nn.Identity()
        
        # 初始化
        nn.init.kaiming_uniform_(self.lora_A, a=math.sqrt(5))
        nn.init.zeros_(self.lora_B)  # B初始化为0，保证初始输出不变
    
    def forward(self, x):
        """
        前向传播: y = Wx + (alpha/r) * B(Ax)
        """
        # 原始路径
        original_output = nn.functional.linear(x, self.weight, self.bias)
        
        # LoRA路径
        lora_output = self.dropout(x)
        lora_output = lora_output @ self.lora_A.T  # (batch, r)
        lora_output = lora_output @ self.lora_B.T  # (batch, out_features)
        lora_output = lora_output * self.scaling
        
        return original_output + lora_output
    
    def merge_weights(self):
        """将LoRA权重合并到原始权重中（推理时使用）"""
        self.weight.data += self.scaling * (self.lora_B @ self.lora_A)
        # 合并后可以删除LoRA参数释放显存


# 使用示例
if __name__ == "__main__":
    # 模拟一个大型线性层: 4096 -> 4096
    layer = LoRALinear(4096, 4096, r=8, alpha=16)
    
    # 参数量对比
    original_params = 4096 * 4096
    lora_params = 8 * (4096 + 4096)
    print(f"原始参数量: {original_params:,}")
    print(f"LoRA参数量: {lora_params:,}")
    print(f"参数比例: {lora_params/original_params*100:.3f}%")
    
    # 前向传播测试
    x = torch.randn(4, 128, 4096)  # batch=4, seq=128, dim=4096
    y = layer(x)
    print(f"输入形状: {x.shape}")
    print(f"输出形状: {y.shape}")
```

## 4. QLoRA：量化+LoRA

### 4.1 QLoRA原理

QLoRA将预训练权重量化到4-bit，然后在其上应用LoRA。核心创新：

1. **4-bit NormalFloat (NF4)**：一种信息论最优的4-bit数据类型
2. **Double Quantization**：对量化常数本身进行量化，进一步节省显存
3. **Paged Optimizer**：使用NVIDIA统一内存避免显存溢出

```
标准LoRA:                      QLoRA:
┌──────────────────────┐      ┌──────────────────────┐
│  原始权重 (fp16)      │      │  量化权重 (4-bit NF4) │
│  7B * 2 = 14GB       │      │  7B * 0.5 = 3.5GB    │
├──────────────────────┤      ├──────────────────────┤
│  LoRA参数 (fp16)     │      │  LoRA参数 (fp16)     │
│  ~20MB               │      │  ~20MB               │
├──────────────────────┤      ├──────────────────────┤
│  优化器状态           │      │  优化器状态 (paged)  │
│  ~1-2GB              │      │  ~1-2GB              │
├──────────────────────┤      ├──────────────────────┤
│  激活值              │      │  激活值              │
│  ~2-3GB              │      │  ~2-3GB              │
├──────────────────────┤      ├──────────────────────┤
│  总计: ~18GB         │      │  总计: ~7GB          │
└──────────────────────┘      └──────────────────────┘
   需要24GB GPU                 单卡16GB即可
```

### 4.2 QLoRA实现

```python
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer, BitsAndBytesConfig

def load_model_qlora(model_name="meta-llama/Llama-2-7b-hf"):
    """使用QLoRA加载模型（4-bit量化）"""
    
    # 4-bit量化配置
    bnb_config = BitsAndBytesConfig(
        # 4-bit量化
        load_in_4bit=True,
        # 使用NF4数据类型（推荐）
        bnb_4bit_quant_type="nf4",
        # 使用双重量化
        bnb_4bit_use_double_quant=True,
        # 计算时反量化为bfloat16
        bnb_4bit_compute_dtype=torch.bfloat16,
    )
    
    # 加载量化模型
    model = AutoModelForCausalLM.from_pretrained(
        model_name,
        quantization_config=bnb_config,
        device_map="auto",
        trust_remote_code=True,
    )
    
    # 启用梯度检查点（进一步节省显存）
    model.gradient_checkpointing_enable()
    
    # 准备模型用于k-bit训练
    from peft import prepare_model_for_kbit_training
    model = prepare_model_for_kbit_training(model)
    
    tokenizer = AutoTokenizer.from_pretrained(model_name)
    if tokenizer.pad_token is None:
        tokenizer.pad_token = tokenizer.eos_token
    
    return model, tokenizer
```

```python
import os
import json
import cv2
import numpy as np
from pathlib import Path
from typing import List, Dict, Tuple
import h5py

class VLADataProcessor:
    """VLA数据集处理器：从原始示教数据到SFT训练格式"""
    
    def __init__(self, output_dir: str, image_size: Tuple[int, int] = (224, 224)):
        self.output_dir = Path(output_dir)
        self.image_size = image_size
        self.output_dir.mkdir(parents=True, exist_ok=True)
        
        # 创建子目录
        (self.output_dir / "images").mkdir(exist_ok=True)
        (self.output_dir / "actions").mkdir(exist_ok=True)
    
    def process_hdf5_episode(self, hdf5_path: str, episode_id: str) -> Dict:
        """
        处理HDF5格式的示教数据（如LeRobot格式）
        
        Args:
            hdf5_path: HDF5文件路径
            episode_id: episode唯一标识
        Returns:
            处理后的数据条目
        """
        with h5py.File(hdf5_path, 'r') as f:
            # 读取数据
            images = f['observations/camera_rgb'][:]  # (T, H, W, 3)
            actions = f['actions'][:]  # (T, action_dim)
            instructions = f['language_instruction'][()]
            joint_pos = f['observations/joint_pos'][:] if 'observations/joint_pos' in f else None
            
            # 处理指令（可能是bytes）
            if isinstance(instructions, bytes):
                instructions = instructions.decode('utf-8')
            
            # 保存图像
            image_paths = []
            for i, img in enumerate(images):
                img_path = self.output_dir / "images" / f"{episode_id}_frame_{i:04d}.jpg"
                # 调整大小
                img_resized = cv2.resize(img, self.image_size)
                cv2.imwrite(str(img_path), cv2.cvtColor(img_resized, cv2.COLOR_RGB2BGR))
                image_paths.append(str(img_path))
            
            # 保存动作
            action_path = self.output_dir / "actions" / f"{episode_id}_actions.npy"
            np.save(action_path, actions)
            
            return {
                "episode_id": episode_id,
                "language_instruction": instructions,
                "image_paths": image_paths,
                "action_path": str(action_path),
                "num_frames": len(images),
                "action_dim": actions.shape[1],
                "episode_length": len(actions),
                "joint_positions": joint_pos.tolist() if joint_pos is not None else None,
            }
    
    def create_sft_dataset(self, episode_files: List[str]) -> List[Dict]:
        """
        从多个episode文件创建SFT数据集
        
        Args:
            episode_files: HDF5文件路径列表
        Returns:
            SFT格式的数据集
        """
        dataset = []
        
        for i, hdf5_path in enumerate(episode_files):
            episode_id = f"episode_{i:04d}"
            try:
                entry = self.process_hdf5_episode(hdf5_path, episode_id)
                dataset.append(entry)
                print(f"  处理完成: {episode_id} ({entry['num_frames']} frames)")
            except Exception as e:
                print(f"  处理失败: {episode_id}, 错误: {e}")
        
        return dataset
    
    def save_dataset(self, dataset: List[Dict], filename: str = "sft_dataset.json"):
        """保存数据集为JSON文件"""
        output_path = self.output_dir / filename
        with open(output_path, 'w', encoding='utf-8') as f:
            json.dump(dataset, f, ensure_ascii=False, indent=2)
        print(f"数据集已保存: {output_path}")
        print(f"  总episode数: {len(dataset)}")
        print(f"  总帧数: {sum(d['num_frames'] for d in dataset)}")
    
    def create_hf_dataset(self, dataset: List[Dict]):
        """转换为HuggingFace datasets格式"""
        from datasets import Dataset, Features, Value, Sequence
        
        # 构建数据
        data = {
            "image_paths": [d["image_paths"] for d in dataset],
            "actions": [np.load(d["action_path"]).tolist() for d in dataset],
            "instructions": [d["language_instruction"] for d in dataset],
            "episode_ids": [d["episode_id"] for d in dataset],
        }
        
        hf_dataset = Dataset.from_dict(data)
        return hf_dataset
```

```python
import torch
import torchvision.transforms as T
import numpy as np
from PIL import Image
import random

class VLADataAugmentation:
    """VLA数据增强器"""
    
    def __init__(self, image_size=224, augment_prob=0.5):
        self.augment_prob = augment_prob
        
        # 图像增强
        self.image_augment = T.Compose([
            T.ColorJitter(
                brightness=0.2,
                contrast=0.2,
                saturation=0.2,
                hue=0.1
            ),
            T.RandomGrayscale(p=0.1),
        ])
        
        # 几何增强（需要同步变换动作）
        self.geometry_augment = T.Compose([
            T.RandomResizedCrop(
                image_size,
                scale=(0.8, 1.0),
                ratio=(0.9, 1.1)
            ),
        ])
    
    def augment_image(self, image: Image.Image) -> Image.Image:
        """增强图像"""
        if random.random() < self.augment_prob:
            image = self.image_augment(image)
        return image
    
    def augment_action(self, action: np.ndarray, aug_type: str = "noise") -> np.ndarray:
        """
        增强动作（谨慎使用，可能影响任务语义）
        
        Args:
            action: 原始动作
            aug_type: 增强类型
        Returns:
            增强后的动作
        """
        if aug_type == "noise":
            # 添加小幅高斯噪声
            noise = np.random.normal(0, 0.01, action.shape)
            return action + noise
        elif aug_type == "smooth":
            # 时序平滑（需要上下文）
            return action  # 在batch级别处理
        return action
    
    def augment_instruction(self, instruction: str) -> str:
        """
        语言指令增强（同义改写）
        
        注意：需要LLM辅助或预定义模板
        """
        # 简单的模板替换
        replacements = {
            "pick up": ["grab", "take", "grasp"],
            "place": ["put", "drop", "set"],
            "move": ["shift", "relocate"],
            "the red cup": ["the red mug", "the red glass"],
        }
        
        augmented = instruction
        for original, synonyms in replacements.items():
            if original in augmented.lower():
                augmented = augmented.replace(
                    original, 
                    random.choice(synonyms)
                )
                break  # 每次只替换一个
        
        return augmented


class MultiCameraFusion:
```

### 6.4 数据加载器

```python
from torch.utils.data import Dataset, DataLoader
import torch
import numpy as np
from PIL import Image
import json
from pathlib import Path

class VLADataset(Dataset):
    """VLA SFT训练数据集"""
    
    def __init__(self, 
                 data_file: str,
                 image_processor=None,
                 tokenizer=None,
                 action_chunk_size: int = 16,
                 max_episode_length: int = 200):
        """
        Args:
            data_file: JSON数据文件路径
            image_processor: 图像处理器
            tokenizer: 文本tokenizer
            action_chunk_size: 动作块大小
            max_episode_length: 最大episode长度
        """
        with open(data_file, 'r') as f:
            self.data = json.load(f)
        
        self.image_processor = image_processor
        self.tokenizer = tokenizer
        self.action_chunk_size = action_chunk_size
        self.max_episode_length = max_episode_length
        
        # 展开数据：每个时间步作为一个样本
        self.samples = self._expand_samples()
    
    def _expand_samples(self):
        """将episode展平为单步样本"""
        samples = []
        for episode in self.data:
            num_frames = min(
                episode["num_frames"],
                self.max_episode_length
            )
            for t in range(num_frames):
                samples.append({
                    "episode_id": episode["episode_id"],
                    "frame_idx": t,
                    "image_path": episode["image_paths"][t],
                    "action_path": episode["action_path"],
                    "instruction": episode["language_instruction"],
                    "total_frames": num_frames,
                })
        return samples
    
    def __len__(self):
        return len(self.samples)
    
    def __getitem__(self, idx):
        sample = self.samples[idx]
        
        # 加载图像
        image = Image.open(sample["image_path"]).convert("RGB")
        if self.image_processor:
            image = self.image_processor(image, return_tensors="pt")
            image = image["pixel_values"][0]
        
        # 加载动作序列
        actions = np.load(sample["action_path"])
        t = sample["frame_idx"]
        
        # 获取动作块 (action chunk)
        end_idx = min(t + self.action_chunk_size, len(actions))
        action_chunk = actions[t:end_idx]
        
        # 填充到固定长度
        if len(action_chunk) < self.action_chunk_size:
            padding = np.tile(
                action_chunk[-1:],
                (self.action_chunk_size - len(action_chunk), 1)
            )
            action_chunk = np.concatenate([action_chunk, padding], axis=0)
        
        # 创建注意力掩码
        attention_mask = np.zeros(self.action_chunk_size)
        attention_mask[:end_idx - t] = 1.0
        
        # 处理语言指令
        if self.tokenizer:
            text_inputs = self.tokenizer(
                sample["instruction"],
                padding="max_length",
                max_length=64,
                truncation=True,
                return_tensors="pt"
            )
            input_ids = text_inputs["input_ids"][0]
            attention_mask_text = text_inputs["attention_mask"][0]
        else:
            input_ids = torch.zeros(64, dtype=torch.long)
            attention_mask_text = torch.ones(64, dtype=torch.long)
        
        return {
            "image": image,
            "input_ids": input_ids,
            "attention_mask_text": attention_mask_text,
            "actions": torch.FloatTensor(action_chunk),
            "action_mask": torch.FloatTensor(attention_mask),
            "instruction": sample["instruction"],
        }


def create_vla_dataloader(
    data_file: str,
    image_processor=None,
    tokenizer=None,
    batch_size: int = 8,
    shuffle: bool = True,
    num_workers: int = 4,
    action_chunk_size: int = 16,
):
    """创建VLA训练数据加载器"""
    
    dataset = VLADataset(
        data_file=data_file,
        image_processor=image_processor,
        tokenizer=tokenizer,
        action_chunk_size=action_chunk_size,
    )
    
    dataloader = DataLoader(
        dataset,
        batch_size=batch_size,
        shuffle=shuffle,
        num_workers=num_workers,
        pin_memory=True,
        drop_last=True,
    )
    
    print(f"数据集大小: {len(dataset)}")
    print(f"批次大小: {batch_size}")
    print(f"每个epoch的批次数: {len(dataloader)}")
    
    return dataloader
```

```python
class InstructionGenerator:
    """自动生成多样化的指令数据"""
    
    def __init__(self):
        # 动作词库
        self.actions = {
            "抓取": ["pick up", "grab", "grasp", "take", "hold"],
            "放置": ["place", "put", "drop", "set", "release"],
            "移动": ["move", "shift", "slide", "push", "pull"],

            "打开": ["open", "unfold", "expand"],

        self.objects = {
            "容器": ["cup", "mug", "glass", "bowl", "plate", "box", "jar"],
            "工具": ["pen", "pencil", "spoon", "fork", "knife", "brush"],
            "积木": ["block", "cube", "brick", "piece"],
            "食物": ["apple", "banana", "bread", "bottle"],
        }
        
        # 颜色
        self.colors = ["red", "blue", "green", "yellow", "white", "black"]
        
        # 空间关系
        self.spatial = ["on", "next to", "in front of", "behind", "inside", "above"]
    
    def generate_instruction(self, task_type: str = "pick_place") -> str:
        """生成单条指令"""
        
        if task_type == "pick_place":
            action = random.choice(self.actions["抓取"])
            color = random.choice(self.colors)
            obj = random.choice(self.objects["容器"])
            spatial = random.choice(self.spatial)
            ref_obj = random.choice(self.objects["容器"])
            
            return f"{action} the {color} {obj} and place it {spatial} the {ref_obj}"
        
        elif task_type == "simple_grasp":
            action = random.choice(self.actions["抓取"])
            color = random.choice(self.colors)
            obj = random.choice(list(self.objects.values())[0])
            
            return f"{action} the {color} {obj}"
        
        elif task_type == "sequential":
            steps = []
            for _ in range(random.randint(2, 3)):
                action = random.choice(self.actions["抓取"] + self.actions["放置"])
                obj = random.choice(self.objects["积木"])
                steps.append(f"{action} the {obj}")
            
            return "First " + ", then ".join(steps[:-1]) + f", finally {steps[-1]}"
        
        return ""
    
    def generate_dataset(self, n: int = 1000) -> List[str]:
        """生成指令数据集"""
        instructions = []
        task_types = ["pick_place", "simple_grasp", "sequential"]
        weights = [0.5, 0.3, 0.2]  # 任务类型权重
        
        for _ in range(n):
            task_type = random.choices(task_types, weights=weights)[0]
            instructions.append(self.generate_instruction(task_type))
        
        return instructions
```

```python
import numpy as np
from typing import List, Dict, Optional
import time

class VLAEvaluator:
    """VLA模型评测器"""
    
    def __init__(self, model, tokenizer, image_processor, device="cuda"):
        self.model = model
        self.tokenizer = tokenizer
        self.image_processor = image_processor
        self.device = device
        self.model.eval()
    
    @torch.no_grad()
    def predict_action(self, image, instruction: str) -> np.ndarray:
        """预测动作"""
        # 处理图像
        if self.image_processor:
            image_inputs = self.image_processor(image, return_tensors="pt")
            pixel_values = image_inputs["pixel_values"].to(self.device)
        
        # 处理指令
        text_inputs = self.tokenizer(
            instruction,
            return_tensors="pt",
            padding=True,
            truncation=True,
        )
        input_ids = text_inputs["input_ids"].to(self.device)
        attention_mask = text_inputs["attention_mask"].to(self.device)
        
        # 推理
        start_time = time.time()
        outputs = self.model(
            pixel_values=pixel_values,
            input_ids=input_ids,
            attention_mask=attention_mask,
        )
        inference_time = time.time() - start_time
        
        predicted_actions = outputs["actions"].cpu().numpy()
        
        return predicted_actions, inference_time
    
    def evaluate_accuracy(self, dataset, max_samples: int = 100) -> Dict:
        """评估动作精度"""
        mse_errors = []
        l1_errors = []
        inference_times = []
        
        for i in range(min(len(dataset), max_samples)):
            sample = dataset[i]
            
            # 获取预测
            image = sample["image"]
            instruction = sample["instruction"]
            gt_actions = sample["actions"].numpy()
            
            pred_actions, inf_time = self.predict_action(image, instruction)
            
            # 计算误差
            mse = np.mean((pred_actions - gt_actions) ** 2)
            l1 = np.mean(np.abs(pred_actions - gt_actions))
            
            mse_errors.append(mse)
            l1_errors.append(l1)
            inference_times.append(inf_time)
        
        return {
            "mse": float(np.mean(mse_errors)),
            "mse_std": float(np.std(mse_errors)),
            "l1": float(np.mean(l1_errors)),
            "l1_std": float(np.std(l1_errors)),
            "avg_inference_time_ms": float(np.mean(inference_times) * 1000),
            "fps": float(1.0 / np.mean(inference_times)),
            "num_samples": len(mse_errors),
        }
    
    def evaluate_trajectory_quality(self, pred_trajectory, gt_trajectory) -> Dict:
        """评估轨迹质量"""
        # DTW距离
        dtw_dist = self._compute_dtw(pred_trajectory, gt_trajectory)
        
        # 轨迹平滑度
        smoothness_pred = self._compute_smoothness(pred_trajectory)
        smoothness_gt = self._compute_smoothness(gt_trajectory)
        
        # 轨迹长度比
        length_pred = self._trajectory_length(pred_trajectory)
        length_gt = self._trajectory_length(gt_trajectory)
        
        return {
            "dtw_distance": dtw_dist,
            "smoothness_pred": smoothness_pred,
            "smoothness_gt": smoothness_gt,
            "smoothness_ratio": smoothness_pred / max(smoothness_gt, 1e-8),
            "length_ratio": length_pred / max(length_gt, 1e-8),
        }
    
    def _compute_dtw(self, seq1, seq2):
        """计算DTW距离"""
        n, m = len(seq1), len(seq2)
        dtw_matrix = np.full((n+1, m+1), np.inf)
        dtw_matrix[0, 0] = 0
        
        for i in range(1, n+1):
            for j in range(1, m+1):
                cost = np.linalg.norm(seq1[i-1] - seq2[j-1])
                dtw_matrix[i, j] = cost + min(
                    dtw_matrix[i-1, j],
                    dtw_matrix[i, j-1],
                    dtw_matrix[i-1, j-1]
                )
        
        return float(dtw_matrix[n, m])
    
    def _compute_smoothness(self, trajectory):
        """计算轨迹平滑度（二阶差分的L2范数）"""
        if len(trajectory) < 3:
            return 0.0
        accel = np.diff(trajectory, n=2, axis=0)
        return float(np.mean(np.linalg.norm(accel, axis=1)))
    
    def _trajectory_length(self, trajectory):
        """计算轨迹长度"""
        if len(trajectory) < 2:
            return 0.0
        diffs = np.diff(trajectory, axis=0)
        return float(np.sum(np.linalg.norm(diffs, axis=1)))
    
    def evaluate_generalization(self, 
                                  in_domain_dataset, 
                                  out_domain_dataset,
                                  max_samples: int = 50) -> Dict:
        """评估泛化能力"""
        in_domain_metrics = self.evaluate_accuracy(in_domain_dataset, max_samples)
        out_domain_metrics = self.evaluate_accuracy(out_domain_dataset, max_samples)
        
        # 泛化差距
        generalization_gap = {
            "mse_gap": out_domain_metrics["mse"] - in_domain_metrics["mse"],
            "l1_gap": out_domain_metrics["l1"] - in_domain_metrics["l1"],
            "generalization_ratio": (
                out_domain_metrics["mse"] / max(in_domain_metrics["mse"], 1e-8)
            ),
        }
        
        return {
            "in_domain": in_domain_metrics,
            "out_domain": out_domain_metrics,
            "generalization_gap": generalization_gap,
        }


# 评测报告生成
def generate_evaluation_report(metrics: Dict) -> str:
    """生成评测报告"""
    report = []
    report.append("=" * 60)
```

```python
"""
使用PEFT库对大语言模型进行LoRA微调的完整流程
"""
import torch
from transformers import (
    AutoModelForCausalLM,
    AutoTokenizer,

# 1. 配置
# ============================================================
class SFTConfig:

    lr_scheduler_type = "cosine"
    logging_steps = 10
    save_steps = 500
    save_total_limit = 3
    
    # 混合精度
    fp16 = True
    bf16 = False  # A100使用bf16, V100使用fp16
    
    # 梯度检查点
    gradient_checkpointing = True
    
    # 数据
    max_seq_length = 512
    data_file = "./data/sft_dataset.json"


# ============================================================
# 2. 加载模型和Tokenizer
# ============================================================
def load_model_and_tokenizer(config: SFTConfig):
    """加载模型和tokenizer"""
    
    print(f"正在加载模型: {config.model_name}")
    
    tokenizer = AutoTokenizer.from_pretrained(config.model_name)
    if tokenizer.pad_token is None:
        tokenizer.pad_token = tokenizer.eos_token
        tokenizer.pad_token_id = tokenizer.eos_token_id
    
    model = AutoModelForCausalLM.from_pretrained(
        config.model_name,
        torch_dtype=torch.float16 if config.fp16 else torch.bfloat16,
        device_map="auto",
        trust_remote_code=True,
    )
    
    # 启用梯度检查点
    if config.gradient_checkpointing:
        model.gradient_checkpointing_enable()
        model.enable_input_require_grads()
    
    print(f"模型加载完成")
    print(f"  参数量: {sum(p.numel() for p in model.parameters()):,}")
    
    return model, tokenizer


# ============================================================
# 3. 应用LoRA
# ============================================================
def apply_lora(model, config: SFTConfig):
    """应用LoRA适配器"""
    
    lora_config = LoraConfig(
        r=config.lora_r,
        lora_alpha=config.lora_alpha,
        lora_dropout=config.lora_dropout,
        bias="none",
        task_type=TaskType.CAUSAL_LM,
        target_modules=config.target_modules,
    )
    
    model = get_peft_model(model, lora_config)
    
    # 打印可训练参数
    model.print_trainable_parameters()
    
    return model


# ============================================================
# 4. 数据处理
# ============================================================
def prepare_dataset(tokenizer, config: SFTConfig):
    """准备训练数据"""
    
    # 加载数据
    dataset = load_dataset("json", data_files=config.data_file, split="train")
    
    def format_instruction(sample):
        """格式化指令数据"""
        # Alpaca格式
        if "instruction" in sample:
            prompt = f"""Below is an instruction that describes a task. Write a response that appropriately completes the request.

### Instruction:
{sample['instruction']}

### Response:
{sample['output']}"""
        else:
            prompt = sample.get("text", "")
        
        return {"text": prompt}
    
    dataset = dataset.map(format_instruction)
    
    def tokenize_function(samples):
        """Token化"""
        result = tokenizer(
            samples["text"],
            truncation=True,
            max_length=config.max_seq_length,
            padding="max_length",
        )
        result["labels"] = result["input_ids"].copy()
        return result
    
    dataset = dataset.map(
        tokenize_function,
        batched=True,
        remove_columns=dataset.column_names,
    )
    
    print(f"数据集大小: {len(dataset)}")
    print(f"示例长度: {len(dataset[0]['input_ids'])}")
    
    return dataset


# ============================================================
# 5. 训练
# ============================================================
def train(config: SFTConfig):
    """完整训练流程"""
    
    # 初始化W&B
    wandb.init(
        project="vla-sft",
        name=f"lora_r{config.lora_r}_alpha{config.lora_alpha}",
        config=vars(config),
    )
    
    # 加载模型
    model, tokenizer = load_model_and_tokenizer(config)
    
    # 应用LoRA
    model = apply_lora(model, config)
    
    # 准备数据
    dataset = prepare_dataset(tokenizer, config)
    
    # 数据整理器
    data_collator = DataCollatorForLanguageModeling(
        tokenizer=tokenizer,
        mlm=False,
    )
    
    # 训练参数
    training_args = TrainingArguments(
        output_dir=config.output_dir,
        num_train_epochs=config.num_train_epochs,
        per_device_train_batch_size=config.per_device_train_batch_size,
        gradient_accumulation_steps=config.gradient_accumulation_steps,
        learning_rate=config.learning_rate,
        warmup_ratio=config.warmup_ratio,
        lr_scheduler_type=config.lr_scheduler_type,
        logging_steps=config.logging_steps,
        save_steps=config.save_steps,
        save_total_limit=config.save_total_limit,
        fp16=config.fp16,
        bf16=config.bf16,
        gradient_checkpointing=config.gradient_checkpointing,
        report_to="wandb",
        save_safetensors=True,
        optim="adamw_torch",
        weight_decay=0.01,
        max_grad_norm=1.0,
        seed=42,
    )
    
    # 创建Trainer
    trainer = Trainer(
        model=model,
        args=training_args,
        train_dataset=dataset,
        data_collator=data_collator,
        tokenizer=tokenizer,
    )
    
    # 开始训练
    print("\n" + "=" * 60)
    print("开始LoRA微调训练")
    print("=" * 60)
    
    trainer.train()
    
    # 保存模型
    model.save_pretrained(f"{config.output_dir}/final")
    tokenizer.save_pretrained(f"{config.output_dir}/final")
    
    print(f"\n模型已保存到: {config.output_dir}/final")
    
    wandb.finish()
    
    return model, tokenizer


# ============================================================
# 主程序
# ============================================================
if __name__ == "__main__":
    config = SFTConfig()
    model, tokenizer = train(config)
```

```python
class OpenVLADataset(torch.utils.data.Dataset):
    """OpenVLA训练数据集"""
    
    def __init__(self, data_dir: str, processor, config: OpenVLAConfig):
        self.data_dir = Path(data_dir)
        self.processor = processor
        self.config = config
        
        # 加载数据索引
        index_file = self.data_dir / "index.json"
        with open(index_file, 'r') as f:
            self.index = json.load(f)
        
        # 展开为单步样本
        self.samples = self._expand_samples()
    
    def _expand_samples(self):
        samples = []
        for episode in self.index:
            num_frames = min(
                episode["num_frames"],
                self.config.max_episode_length
            )
            for t in range(num_frames):
                samples.append({
                    "image_path": episode["image_paths"][t],
                    "action_path": episode["action_path"],
                    "instruction": episode["language_instruction"],
                    "frame_idx": t,
                    "total_frames": num_frames,
                })
        return samples
    
    def __len__(self):
        return len(self.samples)
    
    def __getitem__(self, idx):
        sample = self.samples[idx]
        
        # 加载图像
        image = Image.open(sample["image_path"]).convert("RGB")
        image = image.resize(self.config.image_size, Image.Resampling.LANCZOS)
        
        # 加载动作
        actions = np.load(sample["action_path"])
        t = sample["frame_idx"]
        action = actions[t]  # 当前帧的动作
        
        # 动作离散化（OpenVLA使用token化动作）
        discretized_action = self._discretize_action(action)
        
        # 使用processor处理输入
        inputs = self.processor(
            text=sample["instruction"],
            images=image,
            return_tensors="pt",
            padding=True,
        )
        
        # 移除batch维度
        for key in inputs:
            inputs[key] = inputs[key].squeeze(0)
        
        # 添加动作token
        inputs["action_tokens"] = torch.LongTensor(discretized_action)
        inputs["action_labels"] = torch.LongTensor(discretized_action)
        
        return inputs
    
    def _discretize_action(self, action: np.ndarray) -> np.ndarray:
        """将连续动作离散化为token"""
        # 假设动作范围 [-1, 1]
        bins = self.config.action_bins
        normalized = np.clip((action + 1) / 2, 0, 1)  # 归一化到 [0, 1]
        discretized = (normalized * (bins - 1)).astype(int)
        return discretized

class OpenVLATrainer:
    """OpenVLA LoRA训练器"""
    
    def __init__(self, config: OpenVLAConfig):
        self.config = config
        self.device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
        
        # 设置随机种子
        torch.manual_seed(config.seed)
        np.random.seed(config.seed)
    
    def load_model(self):
        """加载OpenVLA模型"""
        print(f"加载模型: {self.config.model_name}")
        
        self.processor = AutoProcessor.from_pretrained(
            self.config.model_name,
            trust_remote_code=True,
        )
        
        self.model = AutoModelForVision2Seq.from_pretrained(
            self.config.model_name,
            torch_dtype=torch.float16 if self.config.fp16 else torch.bfloat16,
            device_map="auto",
            trust_remote_code=True,
            low_cpu_mem_usage=True,
        )
        
        # 启用梯度检查点
        if self.config.gradient_checkpointing:
            self.model.gradient_checkpointing_enable()
        
        # 冻结视觉编码器
        self._freeze_vision_encoder()
        
        # 应用LoRA
        self._apply_lora()
        
        # 打印参数统计
        self.model.print_trainable_parameters()
    
    def _freeze_vision_encoder(self):
        """冻结视觉编码器参数"""
        for name, param in self.model.named_parameters():
            if "vision_encoder" in name or "visual" in name:
                param.requires_grad = False
        print("视觉编码器已冻结")
    
    def _apply_lora(self):
        """应用LoRA适配器"""
        lora_config = LoraConfig(
            r=self.config.lora_r,
            lora_alpha=self.config.lora_alpha,
            lora_dropout=self.config.lora_dropout,
            bias="none",
            task_type=TaskType.CAUSAL_LM,
            target_modules=self.config.target_modules,
        )
        self.model = get_peft_model(self.model, lora_config)
        print(f"LoRA已应用 (r={self.config.lora_r}, alpha={self.config.lora_alpha})")
    
    def prepare_data(self):
        """准备训练数据"""
        self.train_dataset = OpenVLADataset(
            data_dir=self.config.data_dir,
            processor=self.processor,
            config=self.config,
        )
        
        self.train_dataloader = DataLoader(
            self.train_dataset,
            batch_size=self.config.per_device_train_batch_size,
            shuffle=True,
            num_workers=4,
            pin_memory=True,
            drop_last=True,
        )
        
        print(f"训练数据集: {len(self.train_dataset)} 样本")
        print(f"批次大小: {self.config.per_device_train_batch_size}")
        print(f"梯度累积: {self.config.gradient_accumulation_steps}")
        print(f"有效batch size: {self.config.per_device_train_batch_size * self.config.gradient_accumulation_steps}")
    
    def train(self):
        """训练循环"""
        # 初始化W&B
        wandb.init(
            project="openvla-lora",
            config=vars(self.config),
            name=f"lora_r{self.config.lora_r}_lr{self.config.learning_rate}",
        )
        
        # 优化器
        optimizer = torch.optim.AdamW(
            [p for p in self.model.parameters() if p.requires_grad],
            lr=self.config.learning_rate,
            weight_decay=self.config.weight_decay,
        )
        
        # 学习率调度器
        from transformers import get_cosine_schedule_with_warmup
        total_steps = len(self.train_dataloader) * self.config.num_train_epochs
        scheduler = get_cosine_schedule_with_warmup(
            optimizer,
            num_warmup_steps=self.config.warmup_steps,
            num_training_steps=total_steps,
        )
        
        # 训练循环
        global_step = 0
        best_loss = float('inf')
        
        self.model.train()
        
        for epoch in range(self.config.num_train_epochs):
            epoch_loss = 0.0
            num_batches = 0
            
            for batch_idx, batch in enumerate(self.train_dataloader):
                # 移动到设备
                batch = {k: v.to(self.device) for k, v in batch.items()}
                
                # 前向传播
                with torch.cuda.amp.autocast(enabled=self.config.fp16):
                    outputs = self.model(
                        input_ids=batch.get("input_ids"),
                        attention_mask=batch.get("attention_mask"),
                        pixel_values=batch.get("pixel_values"),
                        labels=batch.get("action_labels"),
                    )
                    loss = outputs.loss
                    loss = loss / self.config.gradient_accumulation_steps
                
                # 反向传播
                loss.backward()
                
                epoch_loss += loss.item()
                num_batches += 1
                
                # 梯度累积
                if (batch_idx + 1) % self.config.gradient_accumulation_steps == 0:
                    # 梯度裁剪
                    torch.nn.utils.clip_grad_norm_(
                        self.model.parameters(),
                        self.config.max_grad_norm,
                    )
                    
                    # 更新参数
                    optimizer.step()
                    scheduler.step()
                    optimizer.zero_grad()
                    global_step += 1
                    
                    # 日志
                    if global_step % 10 == 0:
                        avg_loss = epoch_loss / num_batches
                        lr = scheduler.get_last_lr()[0]
                        
                        wandb.log({
                            "loss": avg_loss,
                            "learning_rate": lr,
                            "epoch": epoch,
                            "step": global_step,
                        })
                        
                        print(f"Epoch {epoch+1}/{self.config.num_train_epochs} | "
                              f"Step {global_step} | "
                              f"Loss: {avg_loss:.4f} | "
                              f"LR: {lr:.2e}")
                
                # 保存检查点
                if global_step % 500 == 0 and global_step > 0:
                    self.save_checkpoint(global_step, epoch_loss / num_batches)
            
            # Epoch结束
            avg_epoch_loss = epoch_loss / num_batches
            print(f"\nEpoch {epoch+1} 完成 - 平均Loss: {avg_epoch_loss:.4f}")
            
            if avg_epoch_loss < best_loss:
                best_loss = avg_epoch_loss
                self.save_checkpoint(global_step, avg_epoch_loss, is_best=True)
        
        # 保存最终模型
        self.save_checkpoint(global_step, best_loss, is_final=True)
        
        wandb.finish()
        print(f"\n训练完成! 最佳Loss: {best_loss:.4f}")

        with open(save_path / "training_state.json", 'w') as f:
            json.dump(state, f, indent=2)
        
        print(f"  检查点已保存: {save_path}")
```

```python
import torch
from transformers import AutoModelForVision2Seq, AutoProcessor
from peft import PeftModel
import numpy as np
from PIL import Image
import time

class VLAInference:
    """VLA模型推理器"""
    
    def __init__(self, 
                 base_model_name: str,
                 lora_weights_path: str,
                 device: str = "cuda"):
        """
        Args:
            base_model_name: 基础模型名
            lora_weights_path: LoRA权重路径
            device: 推理设备
        """
        self.device = device
        
        # 加载基础模型
        print(f"加载基础模型: {base_model_name}")
        self.processor = AutoProcessor.from_pretrained(
            base_model_name, trust_remote_code=True
        )
        self.model = AutoModelForVision2Seq.from_pretrained(
            base_model_name,
            torch_dtype=torch.float16,
            device_map="auto",
            trust_remote_code=True,
        )
        
        # 加载LoRA权重
        print(f"加载LoRA权重: {lora_weights_path}")
        self.model = PeftModel.from_pretrained(self.model, lora_weights_path)
        
        # 合并权重（可选，提升推理速度）
        print("合并LoRA权重...")
        self.model = self.model.merge_and_unload()
        
        self.model.eval()
        print("模型加载完成")
    
    @torch.no_grad()
    def predict(self, image: Image.Image, instruction: str) -> np.ndarray:
        """
        预测动作
        
        Args:
            image: 输入图像
            instruction: 语言指令
        Returns:
            预测的动作 (7-DOF)
        """
        # 处理输入
        inputs = self.processor(
            text=instruction,
            images=image,
            return_tensors="pt",
        )
        
        # 移动到设备
        inputs = {k: v.to(self.device) for k, v in inputs.items()}
        
        # 推理
        start_time = time.time()
        outputs = self.model(**inputs)
        inference_time = time.time() - start_time
        
        # 解析动作
        if hasattr(outputs, "action_tokens"):
            # 离散token输出
            action_tokens = outputs.action_tokens
            action = self._undiscretize_action(action_tokens)
        else:
            # 连续输出
            action = outputs.logits[:, -1, :].cpu().numpy()
            action = action.squeeze(0)
        
        return action, inference_time
    
    def _undiscretize_action(self, tokens: torch.Tensor) -> np.ndarray:
        """将离散token转换为连续动作"""
        bins = 256
        normalized = tokens.float() / (bins - 1)
        action = normalized * 2 - 1  # [-1, 1]
        return action.cpu().numpy().squeeze(0)
    
    def predict_batch(self, 
                      images: list, 
                      instructions: list) -> list:
        """批量预测"""
        results = []
        for img, inst in zip(images, instructions):
            action, t = self.predict(img, inst)
            results.append({"action": action, "time": t})
        return results


class VLARealTimeController:
    """VLA实时控制器"""
    
    def __init__(self, 
                 inference_engine: VLAInference,
                 control_frequency: float = 10.0):
        """
        Args:
            inference_engine: VLA推理引擎
            control_frequency: 控制频率 (Hz)
        """
        self.engine = inference_engine
        self.control_period = 1.0 / control_frequency
        self.is_running = False
    
    def run(self, camera, robot, task_instruction: str):
        """
        运行实时控制循环
        
        Args:
            camera: 相机接口
            robot: 机器人接口
            task_instruction: 任务指令
        """
        self.is_running = True
        print(f"开始实时控制 (任务: {task_instruction})")
        print(f"控制频率: {1.0/self.control_period:.1f} Hz")
        
        try:
            while self.is_running:
                loop_start = time.time()
                
                # 1. 获取观测
                image = camera.get_frame()
                
                # 2. 推理动作
                action, inference_time = self.engine.predict(
                    image, task_instruction
                )
                
                # 3. 安全检查
                if self._safety_check(action):
                    # 4. 执行动作
                    robot.send_action(action)
                else:
                    print("警告: 动作未通过安全检查，跳过执行")
                
                # 5. 检查任务完成
                if self._check_task_complete(robot):
                    print("任务完成!")
                    break
                
                # 6. 控制频率
                elapsed = time.time() - loop_start
                if elapsed < self.control_period:
                    time.sleep(self.control_period - elapsed)
                
        except KeyboardInterrupt:
            print("\n用户中断")
        finally:
            self.is_running = False
            robot.stop()
            print("控制循环已停止")
    
    def _safety_check(self, action: np.ndarray) -> bool:
        """安全检查"""
        # 关节限位检查
        joint_limits = {
            "min": np.array([-2.9, -1.8, -2.9, -3.4, -2.9, -0.2, -2.9]),
            "max": np.array([2.9, 1.8, 2.9, -0.1, 2.9, 3.8, 2.9]),
        }
        
        if np.any(action < joint_limits["min"]) or \
           np.any(action > joint_limits["max"]):
            return False
        
        # 动作幅度检查
        max_change = 0.1  # 单步最大变化
        if np.any(np.abs(action) > max_change):
            return False
        
        return True

        """检查任务是否完成"""
        # 实际实现需要根据具体任务定义
        return False
    
    def stop(self):
        """停止控制"""
        self.is_running = False
```

```python
   - 检查学习率 (LoRA: 1e-4 ~ 5e-4, QLoRA: 1e-4 ~ 3e-4)
   - 验证数据格式 (input_ids, labels 对齐)
   - 增加LoRA秩 (r=8 → r=16 → r=32)
   - 检查target_modules是否覆盖关键层

2. 显存不足 (OOM)
   ────────────────
   原因: batch_size过大，序列过长，未使用梯度检查点
   解决:
   - 减小batch_size (或增大gradient_accumulation_steps)
   - 使用QLoRA (4-bit量化)
   - 启用gradient_checkpointing
   - 减小max_seq_length
   - 使用CPU offloading

3. 过拟合
   ────────────
   原因: 数据量不足，训练轮数过多，LoRA秩过高
   解决:
   - 增加数据增强
   - 减少epoch数 (通常3-10)
   - 降低LoRA秩
   - 增加dropout (0.05 → 0.1)
   - 早停 (early stopping)

4. 分布偏移 (Distribution Shift)
   ──────────────────────────────
   原因: 训练数据与测试场景不一致
   解决:
   - 增加多样化的训练数据
   - 使用DAgger收集在线数据
   - 域随机化训练
   - 数据增强

5. 动作输出异常
   ────────────────
   原因: 动作归一化错误，离散化范围不当
   解决:
   - 检查动作归一化 (确保[-1,1]范围)
   - 验证离散化/反离散化逻辑
   - 检查动作维度和顺序

6. 推理速度慢
   ────────────────
   原因: 模型未优化，未合并LoRA权重
   解决:
   - 合并LoRA权重 (merge_and_unload)
   - 使用ONNX/TensorRT加速
   - KV Cache优化
   - 量化推理 (INT8)

7. 多任务冲突
   ────────────────
   原因: 不同任务的数据分布差异大
   解决:
   - 任务平衡采样
   - 任务特定LoRA适配器
   - 按任务类型分组训练
"""

print(common_issues)
```
